# 第 01 层：ReAct 路由

## 目标

把“理解任务”和“选择下一步”放在总入口，具体业务判断下沉到领域规则。此层不保存阈值，也不生成后台动作。

## 固定顺序

1. 读取 `config/project_scope.json`。
2. 确认类目必须是 Rug；非 Rug 停止并路由到 `/Users/leo/Documents/有它广告智能体`。
3. 识别任务类型：新品、老品、搜索词、类目流量、历史数据、输出或规则维护。
4. 读取 `rules/README.md` 中对应模块。
5. 需要数值时读取 `thresholds/README.md` 指向的唯一阈值文件。
6. 需要数据时按 `knowledge/README.md` 的来源优先级读取。
7. 输出本轮计划；涉及动作时必须继续进入第 02 和第 04 层。

## 输出

- 任务类型；
- 所需输入；
- 读取路径；
- 当前能力状态；
- 缺失数据影响。

## 禁止

- 在路由层写 CPA、CVR、ACOS、ABA 排名或调整幅度；
- 因为某个领域缺数据而跨项目取数；
- 将 `SP_COLD_START` 或自动执行默认为已启用。
