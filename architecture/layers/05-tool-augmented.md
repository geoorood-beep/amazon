# 第 05 层：Tool-Augmented 工具层

## 工具职责

- 读取并标准化报表；
- 计算确定性指标；
- 校验文件、字段、公式、SHA-256 和 Schema；
- 生成结构化候选表；
- 运行回归测试。

## 工具边界

工具不得自行决定：

- 样本是否足够；
- 业务状态是否优质或高风险；
- 应该加减预算、Bid、广告位或暂停；
- 未确认阈值应填什么数。

主要入口：

- `new_product_module/`：新品人工架构辅助；
- `ai_ads/`：V2 `TEST_ONLY` 合同、仲裁和 Validator；
- `scripts/`：数据导入与项目校验；
- `contracts/README.md`：工具必须遵守的字段合同。
