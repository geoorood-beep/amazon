# AGENT: ABA 类目流量结构与打法判断

本 AGENT 用于通过一份 ABA 报告判断某个类目的流量入口数量、头部集中度、滑动排名梯度，并输出适合的广告打法。

本 AGENT 只判断“类目流量结构”和“广告架构打法方向”，不替代新品选词、不替代老品优化、不替代历史出单词复用。

## 适用范围

适用：

- 用户提供一份 ABA 报告，并要求判断该类目属于哪种流量结构。
- 用户要求判断“这个类目适合大词打法、长尾打法、头部词打法、分散覆盖打法还是 ASIN/类目补流量打法”。
- 用户只提供 ABA 和类目核心词，需要先做类目级判断。
- 标品类目需要结合竞争对手词表和 ABA 表判断流量层级。
- 新品推广前，需要先判断类目流量结构，再进入 `agents/new-product-promotion.md` 做产品级选词。

不适用：

- 判断当前链接 ACOS、CPA、CVR、预算、Bid、广告位是否合理。此时读 `agents/old-product-promotion.md`。
- 判断历史出单搜索词是否复用、迁移、否定或放大。此时读 `agents/search-term-reinvestment.md` 和 `agents/category-history-data.md`。
- 只凭 ABA 判断某个具体 SKU 一定能承接哪些词。产品级承接必须结合产品信息。

### 只做类目级判断

至少需要：

- ABA 报告。
- 目标类目核心词，例如 `pet water fountain`、`runner rug`、`area rug`、`clothes rack`。
- 类目是标品、半标品还是非标品。如果用户未说明，先按产品一致性和属性差异判断。

只输入 ABA 时，相关性只能定义为“类目级相关”，不能定义为“产品级相关”。

### 标品类目补充输入

标品类目必须尽量补充竞争对手词表，再结合 ABA 表判断流量层级。

竞争对手词表可来自：

- 竞品 Listing 标题 / 五点 / A+ / 后台关键词。
- 竞品广告跑出的搜索词。
- 竞品自然排名词。
- 类目前 10-20 个核心 ASIN 的高频词根。

竞争对手词表建议字段：

- 竞品 ASIN。
- 竞品标题或搜索词。
- 词根 / 关键词。
- 来源位置：标题 / 五点 / Search Term / 广告搜索词 / 自然排名。
- 出现频次或覆盖 ASIN 数。
- 是否与 ABA 词匹配。

### 做具体产品打法判断

除 ABA 报告外，还必须提供产品信息：

- 类目 / 产品类型。
- 尺寸 / 容量 / 规格。
- 颜色 / 材质 / 功能 / 场景 / 风格 / 适用人群或宠物。
- 是否有同类历史出单词。

此时先用本 AGENT 判断类目流量结构，再转入新品或搜索词模块判断产品能承接哪些入口。

## ABA 字段要求

优先读取：

- 搜索词。
- 搜索频率排名 / ABA 排名。
- 点击量最高的 ASIN / 品牌 / 品类。
- 点击份额。
- 转化份额。

如果只有搜索词和 ABA 排名，也可以做基础判断，但不能判断头部 ASIN / 品牌垄断度，数据置信度降为中或低。

## 标品 / 非标品判断

在做流量入口判断前，必须先判断类目标准化程度。

| 类型 | 判断特征 | 竞对词表权重 |
|---|---|---|
| 标品 | 产品形态、功能、尺寸规格、核心卖点高度一致；买家主要在同类商品之间比较；竞品词根可迁移性强 | 高，必须结合竞对词表和 ABA 共同判断 |
| 半标品 | 产品功能一致，但材质、容量、场景、适配对象有明显分层 | 中，竞对词表用于确认核心词和属性词，不直接替代 ABA |
| 非标品 | 属性差异大，风格、颜色、尺寸、场景、审美和使用方式分散；竞品词容易过宽、过泛或不适合当前商品 | 低，竞对词表只做弱参考，不能用来扩充普通入口 N |

标品例子：

- 宠物喂水器、滤芯、收纳架、衣架、电子配件、规格明确的小家电。

非标品例子：

- 地毯、家具、装饰品、服饰、审美属性强的家居产品。

判断禁区：

- 不要因为某个非标品竞品用了某个大词，就把该词当成当前产品可投词。
- 不要把非标品竞品标题词全部合并成类目入口；非标品的产品属性差异会让入口虚高。
- 标品不能只看 ABA，因为标品入口少、产品一致性高，竞对共用词往往就是真实流量层。

## 相关性定义

ABA 表里有流量，不等于和目标类目相关。必须先做类目级相关性过滤。

### 类目级相关入口

计入类目普通入口 `N_core` 的词必须满足：

1. 搜索词语义属于目标类目本体或同义表达。
2. 如果有 ABA 品类字段，Top 品类不能明显跑偏。
3. 如果有 Top ASIN / 商品名，点击商品应主要是同类商品。
4. 不属于配件、耗材、替代品、教程、清洁用品、品牌独占词或明显相邻类目。

`N_core` 是判断类目入口数量的主指标。

### 单独拆分但不计入普通 N 的入口

| 类型 | 说明 | 处理 |
|---|---|---|
| 配件 / 耗材入口 `N_accessory` | 滤芯、泵、替换件、垫子、清洁刷等 | 单独标记，不计入本体普通入口 |
| 竞品 / 品牌入口 `N_competitor` | 品牌词、竞品型号词、品牌独占词 | 单独标记，不计入普通入口，可做隔离测试 |
| 相邻 / 替代入口 `N_adjacent` | 普通水碗、水瓶、食盆、配件、非本体商品 | 单独标记，不计入普通入口 |
| 不确定入口 `N_uncertain` | 语义不完整、商品指向不清、需人工确认 | 不直接计入普通入口 |

最终：

```text
N = N_core
```

不要把 ABA 全表行数当作 N。否则配件、品牌、替代品会把类目入口数量虚高。

## 标品类目：ABA + 竞对词表联合判断

标品类目流量入口少、产品一致性高，单看 ABA 容易漏掉竞对共用词、自然排名词和广告可承接词。因此标品必须按以下顺序判断：

1. 从 ABA 表筛出 `N_core`，得到类目普通入口。
2. 从竞争对手词表抽取高频词根，统计覆盖 ASIN 数或出现频次。
3. 将竞对词根与 ABA 搜索词做词根匹配。
4. 按 ABA 排名 + 竞对覆盖度，把流量入口分层。
5. 用分层结果修正打法，而不是只用 `N_core` 和 `G` 下结论。

### 标品流量层分层

| 流量层 | 判定 | 含义 | 动作 |
|---|---|---|---|
| L1 共同核心流量 | ABA 排名靠前，且竞对词表高频出现 / 多个竞品 ASIN 覆盖 | 类目主流量，竞价通常高，排名价值高 | 单独建组，单独控预算和 Bid；不要和长尾混投 |
| L2 共性属性流量 | ABA 有排名，竞对词表也出现，但排名低于 L1 | 标品差异化承接入口，如容量、材质、功能、适配对象 | Phrase / Exact 验证，按属性拆组 |
| L3 ABA 有流量但竞对弱 | ABA 有排名，但竞对词表低频或无覆盖 | 可能是泛词、相邻词、非主流需求或采集误差 | 低预算测试或观察，先校验相关性 |
| L4 竞对高频但 ABA 弱 / 无 | 多个竞品都使用，但 ABA 排名弱或缺失 | 可能是 Listing SEO 词、自然排名词、低频转化词 | 不作为主广告入口；可用于 Listing 或低预算验证 |
| L5 品牌 / ASIN / 竞品专属流量 | 品牌词、竞品型号、竞品 ASIN 词 | 防守或截流入口，不是普通类目入口 | 单独隔离测试，不并入普通词组 |

### 标品打法修正

| ABA 结构 | 竞对词表表现 | 最终判断 |
|---|---|---|
| `N_core < 150` 且 `G > 3.5` | L1 词被多数竞品覆盖 | 少入口 + 头部集中 + 竞对一致性高；主战场在少数核心词和共性属性词 |
| `N_core < 150` 且 `G <= 3.5` | 竞对词集中在少数词根 | ABA 排名看似平滑，但实际竞对争夺仍集中；按 L1/L2 分层投放 |
| `N_core >= 150` | 竞对词也高度集中 | 入口数量不代表可投入口多；优先压缩到竞对共用词和强属性词 |
| ABA 和竞对词重合低 | 竞对词表可信 | 需要复核 ABA 采集词、类目核心词或竞对词表来源；不直接下强结论 |

标品输出必须包含：

- `竞对词表是否使用`。
- `竞对覆盖 ASIN 数` 或 `竞对词出现频次`。
- `ABA + 竞对匹配层级`：L1 / L2 / L3 / L4 / L5。
- `是否修正原 ABA 判断`。

## 非标品类目：竞对词表弱参考

非标品类目属性差异太大，竞对词容易过宽、过泛，不能直接当作当前类目的普通入口。

非标品使用竞对词表时只做三件事：

1. 验证大词是否是类目共识词。
2. 发现可参考的属性方向，如尺寸、场景、风格、材质。
3. 排除明显不适合当前产品的竞对属性词。

非标品不得做以下处理：

- 不得把竞对词表高频词直接加入 `N_core`。
- 不得因为多个竞品投某个词，就判定当前产品适合投。
- 不得把竞品的大词、泛词、风格词直接用于主预算。

非标品的流量层判断仍以 ABA 的类目相关入口、产品属性匹配和阶段承接能力为主。

## 核心指标

### 入口数量 N

```text
N = 类目普通入口数量 = N_core
```

判断：

| N_core | 入口数量判断 |
|---:|---|
| `<150` | 入口少 |
| `150-500` | 入口中等 |
| `>500` | 入口多 |

这里的 `150` 指 150 个相关流量入口，不是 ABA 排名 150 名。

### 流量基数

按 `N_core` 中的 ABA 排名升序排序，排名越小代表流量越大。

重点看：

- Top 1 ABA 排名。
- Top 3 ABA 排名。
- Top 10 ABA 排名分布。

### 滑动排名梯度 G

用于判断流量是否集中在头部词。

```text
G = 第 4-6 个 N_core 词的 ABA 排名合计 / 第 1-3 个 N_core 词的 ABA 排名合计
```

判断：

| G | 流量集中度 |
|---:|---|
| `>3.5` | 头部集中 |
| `<=3.5` | 排名平滑 |

如果 `N_core < 6`，不能计算 G，只能输出“入口样本不足，无法判断集中度”。

### 头部 ASIN / 品牌垄断度

如果 ABA 报告包含点击份额、Top ASIN、Top 品牌，可辅助判断垄断度：

| 表现 | 判断 |
|---|---|
| Top 1 ASIN 点击份额很高，或 Top 3 ASIN / 品牌长期重复 | 头部垄断强 |
| 多个 ASIN / 品牌分散拿点击 | 头部垄断弱 |
| 缺少点击份额 / ASIN 字段 | 不判断垄断度 |

垄断度只用于修正打法，不改变 `N_core` 和 `G` 的基础判断。

## 类目流量结构类型

| 类型 | 判定条件 | 类目特征 | 适合打法 |
|---|---|---|---|
| 多入口 + 头部集中 | `N_core > 500` 且 `G > 3.5` | 流量入口很多，但头部词吃掉主要流量，红海特征明显 | 核心大词单独建组、单独控预算；中尾词和 ASIN / 类目分散测试；避免全部预算烧在头部大词 |
| 多入口 + 排名平滑 | `N_core > 500` 且 `G <= 3.5` | 非标属性多，长尾丰富，流量分布平滑 | 大词、中词、长尾都投；Phrase + Broad 分层拓词；建立词根库，覆盖更多流量入口 |
| 中入口 + 头部集中 | `150 <= N_core <= 500` 且 `G > 3.5` | 入口数量中等，但头部词明显强 | 核心词单独控预算；属性词低预算验证；防止大词吃完预算 |
| 中入口 + 排名平滑 | `150 <= N_core <= 500` 且 `G <= 3.5` | 半标品或带非标属性，多个入口都有流量 | 属性词、场景词、尺寸词分组测试；中尾词可以作为主要验证入口 |
| 少入口 + 头部集中 | `N_core < 150` 且 `G > 3.5` | 流量少且集中，头部词 / 头部竞对吃大部分流量 | 抓头部关键词和头部竞对；小词补充；重点观察自然排名，不适合大面积拓词 |
| 少入口 + 排名平滑 | `N_core < 150` 且 `G <= 3.5` | 蓝海或小类目，小词也能获得流量 | 覆盖所有有效层级；精准词、词组词、类目 / ASIN 都可小预算测试；重点查漏补缺 |

## 打法输出规则

输出时必须至少包含：

| 字段 | 说明 |
|---|---|
| 类目核心词 | 用户指定或从 ABA 推断的类目 |
| ABA 总词数 | 去重后的 ABA 搜索词数量 |
| N_core | 类目本体普通入口数量 |
| N_accessory | 配件 / 耗材入口数量 |
| N_competitor | 品牌 / 竞品入口数量 |
| N_adjacent | 相邻 / 替代入口数量 |
| Top 1 / Top 3 本体排名 | 用于判断流量基数 |
| 滑动排名梯度 G | 用于判断集中度 |
| 流量入口类型 | 多入口 / 中入口 / 少入口 |
| 流量集中度 | 头部集中 / 排名平滑 / 样本不足 |
| 类目结构类型 | 如“少入口 + 头部集中” |
| 推荐打法 | 广告架构方向 |
| 不建议打法 | 明确说明不要做什么 |
| 数据置信度 | 高 / 中 / 低 |

## 数据置信度

| 置信度 | 条件 |
|---|---|
| 高 | 有搜索词、ABA 排名、Top ASIN / 品类 / 点击份额，且类目核心词明确 |
| 中 | 有搜索词和 ABA 排名，但缺 Top ASIN / 点击份额 |
| 低 | 类目核心词不明确、ABA 表混杂多个类目、或大量词需要人工确认 |

## 判断禁区

- 不要把 ABA 全表行数当作流量入口数量。
- 不要把“在 ABA 表上”直接等同于“相关”。
- 不要把配件、品牌、替代品、相邻品类计入普通入口 `N_core`。
- 不要只凭 ABA 给某个具体产品强行选词；产品级判断必须调用新品或搜索词模块。
- 不要把本 AGENT 的类目打法判断当作 ACOS、CPA、CVR 阈值判断。
- 不要因为头部词流量大就直接高预算主投；必须结合新品阶段、历史出单证据、产品承接能力和广告目标。
