# Category Traffic Reference Data

本目录用于存放“ABA 类目流量结构与打法判断”所需的基础数据。

它不同于 `reference/category-history/`：

- `category-traffic/`：ABA、竞对词表、Top ASIN / 点击份额等类目流量结构数据。
- `category-history/`：历史出单搜索词数据，只做选词参考。

`category-traffic/` 下的数据不能替代当前链接 / 当前 Campaign / 当前广告组的真实广告报表，不能直接用于老品预算、Bid、广告位、否词、暂停或放量动作。
