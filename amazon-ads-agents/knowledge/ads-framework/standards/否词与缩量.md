# 标准：否词与缩量

### R-NEG-01 无单搜索词默认精准否定　【标准】
- 触发：同一广告组内单个搜索词点击 ≥15 且 0 单，或花费达到品类“花费<2单”高风险线且 0 单。
- 动作：默认 `Negative Exact`；ASIN 搜索词用否定商品。不用 Negative Phrase，除非整个词根明显不相关或持续浪费。
- 出处：UTA 用户规则（`agents/search-term-reinvestment.md`）
- 落地：**引擎已实现**

### R-NEG-02 自有品牌词不否定　【标准】
- 动作：含自有品牌词（各品类 `category.md`，目前 meandu、pokpet）的搜索词只观察或单独控竞价。
- 出处：用户确认 2026-11-17
- 落地：**引擎已实现**

### R-NEG-03 竞品品牌词：可投放、不自动否定、不进 Listing　【标准】
- 动作：竞品品牌词可以作为广告投放词，但默认不进手动词表，单独标为"允许投放的广告选项"，由负责人决定是否单独开活动；不得写进 Listing 标题或后台 Search Terms；引擎不自动否定、不自动加词。
- 出处：`decisions/竞品品牌词使用规则.md`（口径 docs/07）
- 落地：**引擎已实现**（品类 `engine.json` 的 `competitor_brand_terms`）

### R-NEG-04 错词直接否，数据不足先观察　【标准】
- 动作：属性或意图明显与产品冲突的搜索词直接否定（例如替换件、耗材意图出现在整机广告里）；有曝光点击但数据不足的保留在原触发路径观察；重新获得有效证据前不恢复已否定的词。
- 出处：总纲 §11.2 ST0、ST5；`agents/search-term-reinvestment.md`
- 落地：数字触发部分引擎已实现；语义相关性由分析方复核

### R-NEG-05 零转化不一刀切　【标准】
- 触发：投放词达到停止线但没出单。
- 动作：先看同一关键词在精准 / 词组 / 广泛的出单分布——别的匹配方式出单 → 停本匹配，把预算转到出单的匹配；都不出单 → 降竞价；词根在搜索词里仍有出单 → 只降价观察，不停。
- 出处：`decisions/运营方法论_领星西柚.md` §3（口径 docs/09）
- 落地：**引擎已实现**；词根频次由分析方复核

### R-CUT-01 按问题选缩量动作　【标准】
| 问题 | 动作 | 必查 |
|---|---|---|
| 方向对，但成本要收或有效时间过长 | 小步降预算 | 会不会丢掉高价值时段 |
| CPC 或高位竞拍太贵 | 小步降基础竞价 | 曝光会不会断崖下跌 |
| 持续低效、明显错词、没有承接价值 | 关闭投放词 / 广告组 / 活动 | 是否误关有效搜索词来源 |
| 流量不足、数据太散 | 合并同目的同层级的活动 | 合并后会不会重新组内抢量 |
| 上级词太宽、花费失控，下级已能承接 | 降低或关闭上级 | 流量是否平稳转移 |
| 某广告位持续低效 | 降基础竞价、只给有效位置溢价 | 是否破坏关键词竞价层级 |
- 出处：总纲 §9.1、§13.10
- 落地：降竞价、暂停引擎已实现；合并、关上级、位置收缩为人工复核

### R-CUT-02 缩量不只看 ACOS　【标准】
- 动作：同时看点击和花费（测试成本够不够）、订单和 CVR（能不能转化）、CPA 和 ACOS（是否超财务目标）、搜索词相关性（结构问题还是错流量）、自然位和广告位（缩量会不会破坏现有承接）。
- 出处：总纲 §9.1；UTA 总原则
- 落地：引擎按品类阈值的点击 / 花费停止线和 CPA 分级判断，不单看 ACOS

### R-CUT-03 下级没接住前不关上级　【标准】
- 动作：要关闭或大降上级词（自动、一级广泛）之前，先确认下级词或精准层已稳定承接；小步降，比较调整前后的总流量、订单、成本，确认不是只在活动之间搬家。
- 出处：总纲 §13.9 W2–W4
- 落地：人工复核

### R-CUT-04 压价以目标 CPA 为准，不追最低 CPC　【标准】
- 出处：总纲 §13.10 D5
- 落地：引擎降价公式按 `目标 CPA × CVR`
