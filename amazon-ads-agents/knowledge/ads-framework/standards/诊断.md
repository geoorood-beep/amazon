# 标准：诊断

### R-DIAG-01 曝光低先排查，最后才提价　【标准】
- 触发：投放词曝光明显偏低，或订单不足想加量。
- 动作：按顺序排查——① 搜索量本来就低吗（低搜索量词不按大词标准判断）→ ② 预算是否提前花完（先解决预算时长）→ ③ 组内其他词是否抢走预算和曝光（拆组、限词、重分预算）→ ④ 广告位分布是否把展示压住（查基础竞价和溢价）→ ⑤ 商品是否收录且相关（修词、修页面或停投）→ ⑥ 前五项都排除后，才小步提价并观察新增流量。
- 出处：总纲 §13.6
- 落地：方案报告检查项；提价建议必须附排查结论

### R-DIAG-02 曝光 / CTR / CVR / CPA / 利润分层诊断　【标准】
| 异常层 | 表现 | 先查 | 不要直接做 |
|---|---|---|---|
| 曝光 | 曝光低 | 搜索量、预算、组内竞争、广告位、收录、竞价 | 直接认定竞价不够 |
| CTR | 有曝光、点击少 | 主图、价格、评分、折扣、搜索词相关性 | 只加预算 |
| CVR | 有点击、转化低 | 商品承接、变体、价格、流量准确性 | 和 CTR 问题用同一个动作 |
| CPA | 获客成本高 | CPC 和 CVR 的共同影响 | 只压一个指标 |
| 利润 | ACOS 可以但整体利润差 | TACOS、自然单、促销、毛利 | 只看活动内 ACOS |
- 出处：总纲 §13.14
- 落地：方案报告检查项

### R-DIAG-03 账户诊断的优先顺序　【标准】
- 动作：每次诊断按顺序看——① 花费最高的投放词 → ② 花费最高的搜索词 → ③ 同账户重复投放 → ④ 各层加价是否打乱层级 → ⑤ 高价值词的花费路径 → ⑥ 竞价结构是否符合词根和匹配层级 → ⑦ CVR 异常的根因（重复、偏词、位置偏移）→ ⑧ 放量资格 → ⑨ 缩量资格。前两项默认各看前 10 个（数量可调）。
- 出处：总纲 §13.11
- 落地：方案报告按此顺序组织；引擎已按花费排序输出

### R-DIAG-04 看搜索词的花费路径，不只看投放词名　【标准】
- 动作：同一个搜索词可能被多个投放词、多种匹配方式同时承接。诊断时查实际搜索词由哪个活动 / 投放词花钱买到，不能只看投放词名称下结论。
- 出处：总纲 §7.3
- 落地：方案报告检查项

### R-DIAG-05 搜索词优化前四项检查　【标准】
- 动作：① 大头花费是否集中在高竞价层 → ② 自动 / 广泛有没有反超精准、一级有没有反超下级高价值词 → ③ 高价值搜索词有没有被宽泛截流 → ④ 不同广告是否在抢同一个词。
- 出处：总纲 §11.1
- 落地：② 引擎竞价层级检查已覆盖；其余为方案检查项

### R-DIAG-06 广告带动自然位要四个前提都成立　【标准】
- 动作：判断"广告在推自然位"前，确认——投放词与商品真实相关、CTR / CVR / 价格承接为正、有效订单量足以影响目标词、目标词还没到当前链接瓶颈。结果分为正向干预（保持并查成本）、无效干预（补数据、修流量或停止加量）、反向干预（缩量并查相关性和承接）、无法判断（延长观察、恢复控制变量）。
- 出处：总纲 §6.5
- 落地：人工复核（观察周期见 `suggestions.md` S-09）

### R-DIAG-07 用行业基准判断问题出在哪一环　【标准】
- 触发：搜索词同时出现在品牌分析 SQP 里，且我们点击、市场点击都达到 S-15 的最低样本。
- 动作：我们的 CVR 明显低于该词市场 CVR → 问题在页面、价格、评价、变体承接，先修承接，不靠提价解决；我们的 CTR 明显低于市场 CTR → 先查主图、价格、标题、广告位；CVR 明显高于市场 → 记为有放量基础，放量仍按引擎和成熟度。市场 CTR 含自然流量，只做方向对比，不做等式比较。
- 出处：用户确认 2026-11-17（V1.5 行业基准方案）；思路同总纲 §6 诊断分层
- 落地：引擎已实现（方案报告“本周搜索词对比市场”）

### R-DIAG-08 行业基准和自有历史只给方向和复核，不直接触发动作　【标准】
- 触发：任何引用【行业基准】【自有历史】数字的判断。
- 动作：不据此生成否词、暂停、降价、提价、加预算；新词起始竞价参考（目标 CPA × 市场 CVR）只在新建广告时参考，加词仍需引擎 + 成熟度 + 审批；自有分布偏离现行阈值时只出“阈值复核建议”，负责人审批后才改 `thresholds.md` + `engine.json` 并升版本。自有品牌词不计入市场均值。
- 出处：用户确认 2026-11-17
- 落地：引擎已实现（`engine/benchmarks.py`，阈值文件只读）
