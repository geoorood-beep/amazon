# 标准：广告位

**执行边界：本文件的规则只用于给方向和人工复核。** 广告位"表现好 / 差"的判断指标、调价最低数据量、曝光倍数算法等仍待补（`pending.md` P-17–P-22），所以引擎的广告位动作一律不进执行指令单（`placement_manual_review = true`）。

### R-PLC-01 整体达标不动广告位　【标准】
- 动作：活动整体效果达到品类标准时，不分析、不调整广告位；整体不达标时才看 TOS / ROS / PP 的花费占比、订单、CPA、CVR 和样本量。
- 出处：`agents/old-product-promotion.md` 广告位诊断
- 落地：引擎已实现（只对整体不达标的活动出方向）

### R-PLC-02 位置调整不得打乱关键词竞价层级　【标准】
- 动作：见 `竞价.md` R-BID-06。
- 出处：总纲 §10.1

### R-PLC-03 所需溢价用门槛倒推　【标准】
- 动作：先估计 PP、ROS、TOS 的正常曝光竞价门槛，决定基础竞价落在哪一档、哪个位置加溢价：`所需位置溢价 = 目标有效竞价 ÷ 基础有效竞价 − 1`。
- 出处：总纲 §10.4
- 落地：人工复核

### R-PLC-04 位置控制的思路　【标准】
- 动作：三个位置表现接近时主要靠基础竞价分层；某位置明显更好时放大该位置并检查低层是否反超；某位置明显差时用低基础竞价＋好位置溢价把差位置抛出；只要一个位置时让基础竞价低于非目标位置门槛；PP 主要靠基础竞价，不为了 PP 抬高其他位置。想要更多 PP：降基础竞价、TOS / ROS 溢价降到 0。
- 出处：总纲 §10.4；`agents/old-product-promotion.md`
- 落地：人工复核

### R-PLC-05 "基于规则"竞价不使用　【标准】
- 动作：广告位"基于规则"的倍率在新版框架里是空白，旧版的倍率不能抄来用；在补充前不使用该方式。
- 出处：口径 docs/02 §4；总纲 §10.3
- 落地：人工复核
