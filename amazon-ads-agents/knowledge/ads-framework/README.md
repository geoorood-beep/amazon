# 通用广告方法论（ads-framework）

本目录是 UTA-amazon-ads 的**通用知识层**：跨品类适用的广告打法规则。内容由《亚马逊广告推广架构总纲 V2.0》、两份 Soju 导图和 2026-11-14 / 11-15 负责人口径**分解改写**而成（2026-11-17），用我们自己的话写成可执行规则；课程原文不放入本仓库，留在原仓库 `geoorood-beep/pet-supplies-amazon-ads`（公开，已归档） 的 `source/` 备查，规则里只写出处章节号。

## 三级规则

| 等级 | 含义 | Grok / 引擎怎么用 | 文件 |
|---|---|---|---|
| **【标准】** | 负责人已确认，或逻辑明确、不依赖未定数字 | 直接执行：写进引擎检查或作为方案的硬约束；违反时必须说明理由 | `standards/` |
| **【建议】** | 方向明确，但数字是变量，按品类实测 | 进方案作为建议，需用户审批；用数据验证后可升级为【标准】 | `suggestions.md` |
| **【待补】** | 总纲第十四章 30 条尚未定义的规则 | 只提示、交人工；不进执行指令单 | `pending.md` |

数字从哪里来：品类阈值（CPA / CVR / ACOS、停止线）一律取 `categories/<品类>/thresholds.md`；本目录的规则只给逻辑和顺序，不给全类目常数。

## 美国站宠物类目选词入口

做宠物类广告选词或推广方案时，先查[最新版 H10 六品类准词表](../../reference/category-traffic/pet_supplies/H10%E7%AB%9E%E5%93%81%E5%85%B3%E9%94%AE%E8%AF%8D%E5%8F%8D%E6%9F%A5_%E5%87%86%E8%AF%8D%E8%A1%A8_2026-11-22_%E6%90%9C%E7%B4%A2%E5%8D%A0%E6%AF%94%E5%88%86%E7%BA%A7_%E9%99%84%E6%89%93%E6%B3%95.xlsx)的对应品类工作表，参考准词等级、搜索占比和表头打法。只作选词和方案参考，不直接当作执行清单、预算比例或老品调整依据。方法参见[准词／范词推广打法](decisions/h10-keyword-mix-promotion.md)。

## 每条规则的格式

```text
### R-XXX-NN 规则名　【等级】
- 触发：什么情况下适用
- 动作：做什么 / 不做什么
- 出处：总纲 §x.x / 口径 docs/02 等（只写章节号）
- 落地：引擎已实现 / 方案报告检查项 / 人工复核
```

## 升级与修改

- 【建议】升级为【标准】：在 `categories/<品类>/ops/execution/change-history.csv` 有足够改动记录（默认 ≥30 条带 14 天效果）验证，或负责人明确确认；在 `changelog.md` 记录日期、依据、品类范围。
- 【待补】补充后：先进 `suggestions.md`，验证后再升【标准】。
- 品类专属的数字放 `categories/<品类>/`，不写进本目录。
