# H10 × 极目：按准词、范词搜索体量选择推广打法

口径记录：2026-11-22。用于选词和方案判断，补充 [R-ARCH-01](../standards/目标与架构.md)，不替代现有 ABA 类目入口和排名梯度规则，也不直接生成广告执行指令。

## 先判准词与范词

1. 同一站点、产品范围和批次内，先选 5 个可比竞品 ASIN，保留 H10 原始「竞品表现得分（CPS）」「竞品排名（平均）」和各竞品自然排名。排名分歧大的词进入人工复核，不把缺失排名填成 0。
2. 初筛优先看 CPS ≥6：8–10 分看作准词候选，6–7 分看作范词候选，保留原始分数，不以分数替代验证。分别取 **8 分档、6 分档月搜索量最高的词**，核对其 H10 竞品平均排名是否进入该词的极目目标排位区间（含端点）。平均排名落入有效区间是准词依据；样本缺失、不一致或两档同样命中时，不强行画统一分数线。
3. CPS 低于 5 且有排名的竞品少，先列为疑似错词，不直接否词。多家竞品均有排名但排位普遍靠后时，可列范词候选，再看词义和实际承接。相同极目区间重复出现不是额外的独立证据。
4. 用同一口径、同一品类的 H10 月搜索量比较准词和范词；同一个词不得两边重复计入。记录实际样本与复核项，不把搜索份额直接当预算份额。什么比例算「各半」或「特别少」，没有适用于所有品类的固定数值。

## 三种打法

| 准词与范词的搜索体量 | 推广打法 |
| --- | --- |
| 准词为主 | **砸大词**：聚焦相关核心准词，不指望靠范词拉开体量差距。 |
| 准词与范词各占一半 | **先推准词，再带动范词**。 |
| 准词特别少、范词多且搜索体量差距大 | **用 Deal 等方式带量，不直接推范词**。可按项目选择站外、盈利型广告、相关 ASIN 投放或低价。 |

推广洞察表将准词表与实际搜索词汇总结合。CPC 调研可用麦精的关键词转化率作为参考，不以外部指标代替店铺实际转化和利润。本文仅备份通用打法，不含实际品类结果、词表、广告账户或经营数据。
