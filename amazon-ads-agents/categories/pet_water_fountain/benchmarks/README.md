# 宠物喂水器 行业基准与自有历史

V1.5 起，规则引擎每次运行都会刷新本目录（**自动生成，不要手改**）：

| 文件 | 内容 |
|---|---|
| `基准线_<型号>.md` | 市场 / 自有 / 现行阈值三列对比、阈值复核建议、自有周序列、SQP 市场词表 |
| `latest_<型号>.json` | 同样的数字，给程序和下次对比用 |

## 数字从哪来

- **【行业基准】**：`ops/weekly/<周>/raw/搜索查询表现_*.csv`（卖家后台品牌分析 SQP，Grok 每周导出）。每个搜索词的全市场展示、点击、购买 → 市场 CTR、市场 CVR、我们品牌的点击份额。自有品牌词不计入市场均值。
- **【自有历史】**：同一目录下累积的 `SP搜索词-按词-汇总`（没有就用每日明细），按活动 / 广告组名称里的型号（如 `10L`）区分型号 → CTR、CVR、CPC、CPA 的周序列和关键词分布（P25 / P50 / P75）。名称里没有型号的行不计入。
- 推算市场 CPA = 自有 CPC ÷ 市场 CVR（市场没有公开 CPA）。
- 滚动窗口和样本门槛见 `engine.json` 的 `benchmark`（`knowledge/ads-framework/suggestions.md` S-15）。

## 能用来做什么

- 诊断方向：某词我们 CVR / CTR 明显低于市场 → 先查承接或主图，不靠提价（R-DIAG-07）。
- 新建广告时的起始竞价参考：目标 CPA × 市场 CVR。
- 阈值复核：自有分布偏离现行阈值时出建议，**负责人审批后**才改 `thresholds.md` + `engine.json` 并升版本。

## 不能用来做什么

不据此否词、暂停、降价、提价、加预算；引擎不会自动改阈值（R-DIAG-08）。
