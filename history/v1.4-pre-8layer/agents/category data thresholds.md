# AGENT: Category Data Thresholds

> 项目作用域：本文件只保留并执行 Rug / 地毯阈值。非 Rug 阈值不在本项目维护。

本 AGENT 管理不同品类广告诊断阈值。先确认品类/型号/尺寸，再套用阈值；禁止跨品类套用。

简写：`O=广告订单`，`C=点击`，`S=花费`。阈值列顺序均为：`优质 | 正常 | 警戒 | 高风险`。`O<2` 默认只能标记观察；只有同时满足 V1.4 唯一停止例外的 `O=0` 数据，才可生成 `APPROVAL_REQUIRED` 的强收缩候选。

## Rug 尺寸类型自动识别与分析阈值路由

Rug 广告分析必须先根据产品目标尺寸识别产品类型，再调用该类型的 CPA / CVR / ACOS 阈值。不得先看广告表现后反推类型，也不得把 Area Rug、Runner Rug、门垫或圆形的阈值互相混用。

尺寸映射来源为 `reference/rug-aba/area_rug_ABA关键词库_202605_v8.xlsx` 的 `广告词库` sheet，使用 `尺寸标签` 与 `地毯类型` 两列汇总。ABA 词库更新后应重新汇总映射；下列用户确认覆盖规则优先于词库多数结果。

### 尺寸标准化与判定顺序

1. 先统一尺寸写法和方向：`5×7`、`7x5`、`5 x 7` 统一为 `5x7`；矩形尺寸按短边在前、长边在后保存。
2. 明确含 `round` / `circle` / `circular` / `oval` 的尺寸或产品形状先判为 `圆形`；例如 `6x6 round` 归一为 `6ft round`。圆形优先级高于矩形宽度规则。
3. 用户确认的长条覆盖尺寸固定为：`2x4`、`3x6`、`3x7`、`4x10`、`4x12`。这些尺寸即使 ABA 词库中同时出现区域或门垫记录，也统一判为 `长条`。
4. 所有标准化后短边为 `2.5`、长边大于 `2.5` 的矩形尺寸均判为 `长条`，例如 `2.5x6`、`2.5x8`、`2.5x10`。`2.5ft round` 不适用本规则。
5. 其余尺寸按下方固定映射判定。尺寸未命中映射时输出 `地毯类型待确认`，不得自动调用 CPA / CVR / ACOS 阈值。
6. 父体包含多个尺寸时必须逐尺寸识别、逐尺寸调用阈值；不得用一个尺寸的类型和阈值覆盖整个父体。

### 类型到阈值的路由

```text
产品尺寸
→ 自动识别 长条 / 门垫 / 区域 / 圆形
→ 选择该类型的阈值档案
→ 用对应 CPA / CVR / ACOS 判断广告表现
```

- `长条`：所有长条尺寸统一调用本文件的 `长条` 阈值；当前阈值来源保留为原 `2x5 长条` 数据标准，但使用范围升级为长条类型。
- `门垫`：所有识别为门垫的尺寸调用 `门垫` 阈值。
- `区域`：先计算矩形面积。面积 `<=57.5 平方英尺` 调用 `小区域` 阈值，面积 `>57.5 平方英尺` 调用 `大区域` 阈值；`57.5` 是现有 `5x7=35` 与 `8x10=80` 两个阈值锚点的中间值。输入使用英寸或其他单位时必须先换算为平方英尺。
- `圆形`：当前没有独立 CPA / CVR / ACOS 阈值，统一输出 `圆形阈值待配置`；不得借用区域、门垫或长条阈值。
- 阈值必须应用到已经映射到该产品尺寸 / ASIN / SKU 的广告数据。无法把 Campaign / Ad Group 对应到产品尺寸时，输出 `【缺失数据】无法确认产品尺寸类型，CPA/CVR/ACOS 阈值不可可靠调用`。
- `O<2` 时仍只能观察，不能因为已经识别类型就绕过订单样本门槛。

## 标准最低日预算使用规则

输出新品广告方案、老品新增广告组或重建广告组时，单广告组标准最低日预算按本文件中对应类目 / 型号 / 尺寸的 CPA 正常线上限设置：

```text
单广告组标准最低日预算 = CPA 正常线上限
```

如果用户明确给出单广告组目标订单数 `N`：

```text
单广告组标准最低日预算 = CPA 正常线上限 × N
```

执行要求：

- 先确认产品类目、型号、尺寸或容量，再调用对应 CPA 阈值；禁止跨类目套用。
- 预算字段必须说明使用了哪个类目 / 尺寸 / 型号的 CPA 正常线上限。
- 预算低于 CPA 正常线上限时，只能标为观察预算或拓词预算，不能标为标准最低日预算。
- 新品阶段可以用 CPA 正常线上限设置预算底线，但不得用短期 CPA / CVR / ACOS 直接强判暂停、否词或放量。
- 若新增类目缺少 CPA 阈值，预算写 `待补CPA阈值` 或 `待人工配置`，不得编造。

当前已维护 CPA 正常线上限对应的单广告组标准最低日预算：

| 类目 / 型号 / 尺寸 | CPA 正常区间 | 标准最低日预算 |
|---|---:|---:|
| 地毯 门垫 | `$10-$13` | `$13/日` |
| 地毯 长条（基准来源：2x5） | `$9-$13` | `$13/日` |
| 地毯 5x7 小区域 | `$15-$22` | `$22/日` |
| 地毯 8x10 大区域 | `$15-$24` | `$24/日` |

## 高流量核心隔离阈值

新品 Auto / Broad / Phrase 广告用于低预算验证或拓词时，可以用高流量核心词精准否定隔离，防止头部大词抢预算。该规则是流量隔离，不是判断该词低相关或表现差。

执行要求：

- 只使用当前类目已维护的隔离阈值，禁止跨类目套用。
- 未维护隔离阈值的类目，不得自动生成高流量核心隔离否词，只能输出 `该类目高流量核心隔离阈值待配置`。
- 隔离方式默认只用 `Negative Exact`，不得用 `Negative Phrase`，除非整个词根明确不相关或用户明确要求。
- 仍需先通过产品属性、合规状态、动物图案类型等匹配规则；属性冲突或动物类型不匹配的词，不作为高流量核心隔离词处理。
- 某词已被方案投放不是精准否定理由。同一个广告组不得精否自己的主投放词或组内正在投放的词，避免自我否定。
- 只有当前 Auto Close / Broad / Phrase 广告组确实可能触达的高流量核心词，才可写入该组的精准否定；不得把阈值词库整表机械复制到所有广告组。
- 阶段外词、受限测试词、观察词、配件词、不相关词和品牌 / 竞品风险词默认做“不展示 / 不投放 / 隔离复核”，不因被排除而自动成为精准否定词。
- 只有用户明确要求“输出否词清单”时，才单独生成否词表。

当前已维护阈值：

| 类目 | 适用广告类型 | 推荐层级 | ABA 排名阈值 | 否定方式 | 说明 |
|---|---|---|---:|---|---|
| Rug / 地毯 | Auto Close / Broad / Phrase | `P1` / `P2` | `<=11000` | `Negative Exact` | 还需合规安全、产品属性不冲突、当前广告组可触达且不是本组投放对象；`>11000` 不得作为新品默认精否词 |
