# AGENT: 新品推广选词与广告架构搭建

> 项目作用域：本文件在“陆遥广告智能体”中只处理 Rug / 地毯。不得调用喂水器、办公椅或项目外数据；固定来源以 `config/project_scope.json` 为准。

本 AGENT 用于 Amazon 地毯新品推广阶段的选词、词根归并、ABA 阶段匹配、广告架构搭建和人工审批输出。

新品阶段只输出建议和广告架构表，不直接执行 Amazon Ads API 操作，不自动调预算、Bid、广告位或否词。

## 适用范围

适用：

- 新 ASIN / 新 SKU / 新父体推广。
- 当前链接没有稳定广告数据、搜索词数据、广告位数据和趋势数据。
- 任务目标是新品选词、首轮广告架构搭建、低预算验证、ABA 阶段匹配。

不适用：

- 当前链接已有稳定广告表现，需要判断预算、Bid、广告位、搜索词否定或趋势变化。此时读 `agents/old-product-promotion.md`。
- 任务只做历史出单词再投放和词根聚合。此时同时读 `agents/search-term-reinvestment.md`。

`reference/rug-aba/`

固定文件：

- `area_rug_ABA关键词库_202605_v8.xlsx`

- `kitchen_rugs_ABA关键词库_202605_v2.xlsx`
- `outdoor_rug_ABA关键词库_202605_v2.xlsx`

调用这些文件时，只读取 `广告词库` sheet。不得读取或合并 `说明`、`汇总`、`Listing词库`、`否定禁用`、`类型_*` 等其他 sheet，除非用户明确要求检查源表结构。

旧 `reference/通用地毯类目ABA关键词库_202605_v2.xlsx` 仅作历史备份，不再作为默认地毯 ABA 调用入口。除非用户在当前任务提供新的地毯 ABA 表，否则默认使用 `reference/rug-aba/` 下对应场景文件。用户提供新 ABA 表时，以用户新表优先。

非地毯类目不要调用该表。

Rug 类目历史出单词 / 效果词库：

`reference/category-history/rug/`

当地毯新品推广、新广告搭建或搜索词复用任务需要同类历史成交证据时，必须读取 `agents/category-history-data.md`，再读取 Rug 历史库的 `metadata.md` 和标准化文件。该历史库来自冬豚 / 岚风关键词分析汇总，只能作为选词和候选词参考，不得替代当前链接真实广告报表。

## 新品阈值边界

新品一般没有稳定 CPA / CVR / ACOS 阈值参考，因为它是重新开始推。

只有以下情况可以引用阈值：

1. 用户提供同类历史产品数据，并明确可作为参考。
2. 用户手动给出新品测试目标，如目标 CPA、目标 ACOS、最低 CVR。
3. 当前链接已经有稳定广告数据、搜索词数据、广告位数据和趋势数据，此时应转入 `agents/old-product-promotion.md`，不再按新品模块判断。

没有上述参考时，不能直接用 CPA / CVR / ACOS 判定“高风险 / 不达标 / 暂停”。新品阶段只能输出低预算验证、继续观察、人工确认或不建议投放。

`agents/category data thresholds.md` 不作为新品默认强判标准，只能在用户明确要求、或有同类历史数据对照时辅助参考。

## 输入要求

Rug 类目新品输入字段以 `新品基础信息输入模版_Rug类目` 的 `产品信息表` 为准。用户问“新品广告需要输入哪些信息”时，只展示模板字段，不要把 ABA 系统字段、功能、场景、人群/宠物、是否冷启动等泛化字段列为默认必填。

`产品信息表` 字段：

| 字段 | 要求 | 用途 |
|---|---|---|
| `ASIN/SKU` | 必填 | 确认推广对象 |
| `运营` | 建议填 | 用于广告组命名；智能体输出默认 `lulu` |
| `地毯区域` | 可选复核 | 系统必须先按尺寸自动识别区域 / 长条 / 室内进门垫 / 圆形；人工值只用于冲突复核，不得跳过尺寸识别 |
| `尺寸` | 必填 | 本次任务的目标推广尺寸；自动判断地毯类型、CPA / CVR / ACOS 阈值档案、ABA 文件和关键词尺寸硬冲突 |
| `材质` | 有特殊材质才填 | 常规仿羊绒不需要填写 |
| `颜色` | 有明确颜色才填 | 用于匹配颜色词 |
| `风格` | 有明确风格才填 | 如 vintage / modern / boho / abstract / solid |
| `预算（USD/日）` | 建议填 | 与 CPA 标准最低日预算对比 |
| `目标订单阶段` | 必填 | 决定 ABA 排名区间 |
| `图案动物类型` | 条件必填 | 产品图案是具体动物时必须填写或由图片识别确认 |

`ASIN/SKU` 中如果包含款号 / 产品代号，可用于广告组命名中的 `SPU`；如果无法识别款号，命名时按统一规则写 `SPU待补`，不要额外把 `SPU` 列为 Rug 模板默认必填字段。

信息缺失时，不要补造属性。输出“待人工确认”，并说明缺失字段会影响哪个判断。

如果用户提供或项目中存在类目历史出单词数据，先读 `agents/category-history-data.md`，再判断这些历史词能否作为当前新品的同类参考。ABA 表和类目历史出单词表必须分开读取，不得把 ABA 词库当作历史出单数据。

## Rug 产品属性硬匹配与冲突过滤

Rug 新品必须先判断产品属性，再判断历史成交、ABA 阶段、排名和综合分。产品属性硬冲突的词直接剔除，不能因历史出单、ABA 排名高、推荐层级高或综合分高而保留。

执行顺序：

1. `尺寸` 字段表示本次任务的目标推广尺寸，不等同于父体下全部可售尺寸。父体有多个尺寸时，按每个目标尺寸分别筛词、分别建组；不同尺寸不得混在同一广告组。
2. 先把尺寸表达标准化，再比较数值。`5x7`、`5 x 7`、`5×7`、`7x5` 可归为同一矩形尺寸；`5x7` 与 `3x5`、`4x6`、`5x8`、`6x9` 不得视为近似匹配。
3. 关键词含明确尺寸时，必须命中当前目标尺寸。目标为 `5x7` 时，`3x5 washable rug`、`5x8 area rug` 等直接判定 `尺寸硬冲突`，不得进入 `ABA选词表`、`新广告设置表`或广告组名称。
4. 关键词未写尺寸时，不因缺尺寸自动剔除，但不能获得“尺寸匹配”加分；仍须通过地毯类型、形状、材质、颜色、风格、场景和图案动物类型检查。
5. 关键词明确写出与产品冲突的地毯类型、形状、材质、颜色、风格或图案动物类型时，判定对应属性硬冲突并剔除。例如蓝色产品不得推荐 `red rug`，vintage 产品不得推荐 `modern rug`，Area Rug 不得推荐明确的 `runner rug`。
6. 场景属性只有在用户或产品资料明确“不适用”时才作为硬冲突；未明确排除的 living room / bedroom 等通用场景按匹配强弱评分，不自动互斥。
7. 属性同义词可以归一后比较，例如 `gray/grey`；没有维护同义词或无法确认属性时，标记 `待人工确认`，不得猜测为匹配。
8. 输出表只展示最终需要投放的词。被尺寸或其他属性硬冲突剔除的词不另做“受限测试”，也不自动写入精准否定；只在 `判断依据与设计逻辑` 中汇总说明已执行属性冲突过滤。

属性判断优先级：

```text
目标推广尺寸标准化
→ 按尺寸自动识别地毯类型与分析阈值档案
→ 关键词目标尺寸硬匹配
→ 形状 / 材质 / 颜色 / 风格 / 图案动物类型冲突
→ 场景适配
→ 历史成交证据
→ ABA 阶段与排名
→ 综合分与广告分组
```

## Rug 图案动物类型强匹配规则

如果 Rug 产品图案是具体动物，必须使用 `图案动物类型` 作为强约束。该字段可以由用户手动输入，也可以根据用户提供的产品图片识别；图片识别置信度不足或无法确认具体动物时，输出 `图案动物类型待确认`。

执行规则：

1. `图案动物类型` 有具体值时，ABA 候选词必须精准匹配该动物名称或明确同义表达。
2. 不得因为 `风格=animal`、`animal print` 或“动物风格”就推荐任意动物关键词。
3. 不同动物之间不能互相泛化替代，例如 tiger 不能替代 leopard / zebra / cow，cow 不能替代 zebra / tiger。
4. 如果 `风格` 字段里写了具体动物词，应归一到 `图案动物类型` 使用；若 `风格` 与 `图案动物类型` 冲突，必须人工确认。
5. 产品不是动物图案，或动物类型为空且图片也不能识别时，默认不推荐具体动物关键词；除非用户明确确认。

示例：

- `图案动物类型=tiger`：可匹配 `tiger rug`、`tiger print rug`；不得推荐 `leopard rug`、`zebra rug`、`cowhide rug`。
- `图案动物类型=cow`：可匹配 `cow print rug`、`cowhide rug`；不得推荐 `tiger rug`、`leopard rug`、`zebra rug`。
- `图案动物类型待确认`：所有具体动物词只能列为待确认候选，不进入默认 `ABA选词表` 或 `新广告设置表`。

## 地毯类型识别

地毯类型识别的唯一完整规则源是 `agents/category data thresholds.md` 的 `Rug 尺寸类型自动识别与分析阈值路由`。新品收到产品尺寸后必须先执行该规则，不再要求用户先手工决定地毯类型。

固定边界：

- `2x4`、`3x6`、`3x7`、`4x10`、`4x12` 统一判为长条。
- 所有标准化后短边为 `2.5`、长边大于 `2.5` 的矩形统一判为长条。
- `2x3` 判为门垫；`3x5` 按当前 ABA 尺寸映射判为区域，不得再仅凭尺寸判成门垫。
- 明确圆形标记优先于矩形尺寸规则。
- 父体有多个尺寸时逐尺寸识别；例如 `2x6=长条`、`5x7=区域`，必须分别筛词、分别建组、分别调用阈值。
- 尺寸未命中固定映射时标记 `地毯类型待确认`，不得根据标题或场景词擅自套用 CPA / CVR / ACOS 阈值。标题和场景只用于复核类型或选择辅助 ABA 文件。

类型识别完成后，新品可以用对应类型的 CPA 正常线上限设置标准最低日预算；新品短期 CPA / CVR / ACOS 仍不得用于强判暂停、否词或放量。已有稳定广告数据时转入老品推广，并按同一尺寸类型调用完整分析阈值。

## ABA 表字段使用规则

必须读取以下字段：

- `搜索词`
- `搜索量排名`
- `地毯类型`
- `详细分类`
- 类目判断字段：`类目判断` 或以类目命名的 `*类目判断`
- `推荐层级`
- `相关度等级`
- `合规状态`
- `Listing状态`
- `广告状态`
- `综合优先级`
- `广告用途`
- `否定/隔离类型`
- `尺寸标签`
- `场景标签`
- `功能标签`
- `风格图案标签`
- `颜色标签`
- `材质结构标签`
- `形状标签`
- `人群宠物标签`
- `判断原因`
- `来源文件`
- `前三点击份额`
- `前三转化份额`

其中 `搜索量排名` 是 ABA 排名。排名越小代表流量越大，但不能因为 ABA 排名高就直接主投。

`综合优先级` 只用于同类型、同阶段、同合规状态下排序，不能替代 ABA 排名，也不能覆盖合规判断。

输出表必须把词的标签合并成一列 `对应标签`。标签来源为 `尺寸标签`、`场景标签`、`功能标签`、`风格图案标签`、`颜色标签`、`材质结构标签`、`形状标签`、`人群宠物标签`。格式为：

`尺寸:8x10；场景:living room；功能:washable, soft；风格:vintage；颜色:neutral`

没有值的标签不写，不要用空标签占位。

## 推荐层级处理

- `P0 核心词`：类目核心词。新品早期不直接高预算主投，必须通过阶段匹配和产品承接能力判断。
- `P1 优先词`：新品优先验证词，适合 Phrase 或拆组测试。
- `P2 扩展词`：适合关键词 Broad / Phrase 小预算扩词；Broad 只能作为关键词匹配方式，不等同于自动广告的 Loose match。
- `P3 观察/否定候选`：不进核心广告，只能隔离观察。
- `风险/隔离`：品牌、竞品、风险词，必须单独复核。
- `P4 完全不相关`：否定候选，不投放。

`合规状态=安全` 才能进入常规广告候选池。促销/价格词、品牌/竞品词、完全不相关词不得混入新品核心广告组。

## 地毯新品阶段 ABA 主投门槛与强匹配例外

地毯新品广告方案只展示“实际需要投放的词”。不展示未投放的阶段外低相关词、观察词或否定候选词；只有已决定执行的低预算隔离测试词，才可以进入 `ABA选词表` 和 `新广告设置表`，并必须标明 `推荐动作=低预算隔离测试`、`主投=否`。

没有用户提供链接目标广告订单量时，默认按 `0-15 单/日` 新品冷启动阶段处理。

`0-15 单/日` 的主投规则和例外规则：

| 地毯类型 | 主投 ABA 排名门槛 | 强匹配低预算隔离测试 | 默认主投关键词类型与匹配度 | 首轮数量控制 |
|---|---:|---|---|---|
| Area Rug / 区域地毯 | `>=60,000` | `20,000-<60,000`：仅尺寸、场景、风格颜色或材质结构与产品强匹配时可测试；`<20,000` 默认隔离观察，只有具体尺寸/场景/属性组合词具备明确产品承接和测试预算时才可单词单组小预算测试，不含头部类目词 | 长尾词、尺寸词、场景词、属性组合词；主投词通常 `>=90%` 匹配 | 每个流量入口 `3-5` 个词；总词数按日预算、尺寸/场景入口数和可承接广告组数确定 |
| Runner Rug / 长条地毯 | `>=50,000` | `20,000-<50,000`：仅尺寸、场景、风格颜色或材质结构与产品强匹配时可测试；`<20,000` 默认隔离观察，只有具体尺寸/场景/属性组合词具备明确产品承接和测试预算时才可单词单组小预算测试，不含头部类目词 | 长尾词、尺寸词、场景词、属性组合词；主投词通常 `>=90%` 匹配 | 每个流量入口 `3-5` 个词；总词数按日预算、尺寸/场景入口数和可承接广告组数确定 |

强匹配必须至少命中产品类型，并同时命中尺寸、场景、风格/颜色、材质结构中的一项以上；具体动物图案仍须先满足 `图案动物类型` 强匹配。匹配度只是进入测试的资格，不能覆盖订单阶段承接能力或把高流量词自动转入主预算。

头部词必须单独控制：

- `rug`、`rugs`、`area rug`、`runner rug`、`rugs for living room` 不得和中尾词或长尾词混组；必须单词单组、单独预算、单独复盘。
- `area rug`、`rugs for living room` 在链接达到 `50+ 单/日` 后，可在产品强匹配时做低预算隔离测试；不是自动进入主预算。
- `rug`、`rugs` 默认延后至链接达到 `100+ 单/日` 后，才允许单词单组、小预算测试；不能因匹配度高或 ABA 排名高提前进入主投。

执行优先级：

1. 先按目标尺寸自动识别产品类型，再判断 Area Rug / Runner Rug 入口和当前订单阶段；两类不得共用同一排名区间。
2. 再判断候选词是否进入该类型的主投区间；进入主投区间且合规、匹配充分的词，进入主预算候选池。
3. 未进入主投区间但命中强匹配例外时，判断是否有独立测试预算；有预算才以单独广告组进入低预算隔离测试，没有预算则隔离观察，不进入输出表。
4. 未命中主投或强匹配例外的词直接剔除；不要为了说明风险而把未投放词、普通受限测试词或否定候选词放进方案表。
5. 如果一个商品同时覆盖 Area Rug 和 Runner Rug，例如 `8x10/5x7 + 2x6`，先分别筛选和分组，再按预算决定每个入口的投放数量。
6. 大词单词单组；中尾词只能按同一流量入口、同一搜索意图和同一属性组合为 `2-5` 个词一组。不能把头部词、尺寸词、风格词和拓词词根混组。

`搜索量排名 <=20,000`、低于主投门槛或明显超出阶段承接能力的词，不因“风险高”自动成为精准否定词。除非该词是非头部的具体尺寸/场景/属性组合词，且已决定执行低预算隔离测试，或命中已有高流量核心隔离规则，否则默认不展示。只有用户明确要求输出否词清单时，才单独生成否词表。

## 选词流程

按顺序执行：

1. 确认本次推广对象和目标尺寸，按 `agents/category data thresholds.md` 自动识别地毯类型和分析阈值档案，再核对形状、材质、颜色、风格、目标订单阶段和图案动物类型；父体多尺寸时按目标尺寸拆开处理。
2. 按地毯类型读取对应 ABA 文件，并且只读取该文件的 `广告词库` sheet；如需补充，只能读取辅助文件的 `广告词库` sheet。
3. 标准化关键词和产品的尺寸、地毯类型、形状、材质、颜色、风格和图案动物类型；先执行硬冲突过滤。目标 `5x7` 时，任何明确写出 `3x5`、`5x8` 等其他尺寸的词均直接剔除。
4. 如果存在具体 `图案动物类型`，对动物关键词做强匹配过滤；不匹配该动物的具体动物词直接剔除或待确认。
5. 从 `广告词库` 过滤 `P0/P1/P2 + 安全` 词，并从 `否定观察` 排除 `P4`、促销价格词、品牌风险词和不相关词。
6. 用 `词根归并` 把搜索词聚合成规范词根，保留代表词和全部变体；词根归并不得把已被属性硬冲突剔除的词重新带回候选池。
7. 如果有同类历史成交词，优先从历史出单词根开始，再匹配 ABA；历史证据不得覆盖产品属性硬冲突。
8. 如果没有历史成交词，则按 ABA 阶段、产品匹配度和低预算测试逻辑选词。
9. 按地毯类型和当前订单阶段先做主投门槛筛选，再判断是否命中强匹配低预算隔离例外；未投放的阶段外词直接剔除，不展示。
10. 对进入主投或已批准执行低预算隔离测试、且通过全部产品属性与合规过滤的词，按流量入口和预算输出广告架构，不做自动执行。

不要把“ABA 词根”直接等同于“应该投放的词”。ABA 主要用于判断市场容量、稳定流量和长期排名机会；实际投放优先级必须结合新品阶段、产品匹配、历史成交证据和合规状态。

## 同类历史成交词规则

如果用户提供同类历史成交搜索词，优先级高于通用 ABA。

类目历史出单词固定从 `reference/category-history/` 读取。读取、入库、字段映射和置信度规则见 `agents/category-history-data.md`。

历史词进入候选池需满足：

- 搜索词与当前新品类型、尺寸、场景或属性相关。
- 不是明显偶然单；优先选择历史订单 `>=2` 或多日期成交词。
- 如果有历史 CVR / CPA / ACOS，只能作为同类历史参考，不能直接当当前新品强判线。
- 若历史词与 ABA 表匹配到 `P4`、品牌风险、促销价格词，必须人工复核，不得直接投放。

没有同类历史数据时，输出“无历史阈值参考”，按 ABA 与产品属性做低预算验证。

## ABA 阶段匹配

用父体或链接目标广告订单量判断阶段，再用 `搜索量排名` 过滤。

| 目标阶段 | 区域 / 门垫 / 圆形参考 | 长条参考 | 选词方向 |
|---|---:|---:|---|
| 0-15 单/日 | 主投 `>=60,000`；`20,000-<60,000` 强匹配低预算隔离；`<20,000` 默认观察或单词单组小预算测试 | 主投 `>=50,000`；`20,000-<50,000` 强匹配低预算隔离；`<20,000` 默认观察或单词单组小预算测试 | 尺寸词、场景词、属性长尾；例外词不得进入主预算 |
| 15-30 单/日 | 30,000-180,000 | 20,000-200,000 | 中流量成熟入口 |
| 30-50 单/日 | 8,000-100,000 | 10,000-120,000 | 中高流量排名投资词 |
| 50+ 单/日 | 2,000-60,000；`area rug`、`rugs for living room` 仅强匹配单词单组低预算测试 | 2,000-80,000；头部 `runner rug` 仅单词单组低预算测试 | 核心词、防守词、放量词；头部词不自动进入主预算 |
| 100+ 单/日 | 500-30,000；`rug`、`rugs` 才允许单词单组小预算测试 | 500-50,000 | 头部词、类目词、竞品词隔离测试 |

新品早期不要因为 `outdoor rug`、`bathroom rugs`、`rug` 这类 ABA 排名高的词流量大就直接主投。强匹配例外只允许实际执行的低预算隔离测试进入输出表，且必须单独广告组、单独预算、明确 `主投=否`；普通阶段外词仍直接剔除。

新品执行优先级：阶段主投门槛高于 `综合优先级`、`推荐层级` 和单项属性匹配；强匹配例外只能改变“是否可做低预算隔离测试”，不能改变“不得进入主预算”。

`受限测试` 不属于默认广告方案输出动作。只有经产品强匹配、独立预算和单独广告组确认后，结论明确为 `低预算隔离测试` 的词才进入输出表；其余 `受限测试`、观察词和后续升级词仍默认剔除。

## 匹配评分

评分只用于排序，不用于替代人工审批。

建议结构：

- 历史证据：0-60 分。有同类历史成交词才计算；无历史数据则标记“无历史参考”，不强行给满分。
- ABA 阶段匹配：0-20 分。依据 `搜索量排名` 是否进入当前目标阶段主投区间；强匹配例外只标记为低预算隔离资格，不补足主投分。
- 产品属性匹配：0-20 分。仅对已经通过硬冲突过滤的候选词评分；尺寸、风格、颜色、材质、形状和图案动物类型匹配越明确，分数越高。目标尺寸或其他明确属性发生冲突时直接剔除，不靠扣分、历史成交或 ABA 排名保留。

结论分层：

- 建议投放：历史或 ABA 阶段证据明确，产品属性匹配强，合规安全。默认进入输出表。
- 低预算拓词：通过阶段 ABA 区间、匹配度和合规过滤，但角色是拓词。默认可以进入输出表。
- 低预算隔离测试：未进入主投区间，但命中强匹配例外、拥有独立测试预算且单独建组。可以进入输出表，必须标记 `主投=否`。
- 受限测试：有一定相关性，但无独立测试预算、样本弱、ABA 阶段偏大或偏小，或未满足强匹配例外。默认不进入输出表。
- 继续观察：相关但证据不足。默认不进入输出表。
- 不建议投放：P4、不相关、明显品牌风险、促销价格词、产品属性冲突，或完全超出新品阶段。默认不进入输出表。

## 新品广告架构规则

地毯类目新品阶段允许：

- Phrase
- Broad
- Auto Close

地毯类目新品阶段禁止：

- Auto Loose / 自动宽泛匹配。
- Auto Substitutes。
- Auto Complements。
- ASIN 匹配广告 / ASIN 商品投放，包括竞品 ASIN、自有 ASIN、单 ASIN 定向。
- Product Targeting ASIN 广告组。
- Exact。Exact 只在搜索词已经稳定出单、或产品进入老品优化阶段后再单独承接。

地毯新品首轮方案默认只生成 Phrase、关键词 Broad 和 Auto Close。自动广告只保留紧密匹配 `Close match`，不跑自动宽泛匹配 `Loose match`，也不跑 `Substitutes`、`Complements`。除非用户明确要求测试类目投放，否则不生成 Product Targeting；即使测试类目投放，也只能是类目维度，不能放 ASIN。

广告组命名必须调用 `agents/promo-output-templates.md` 的统一规则：

```text
SPU-广告产品-定向维度-匹配方式-场景分类-尺寸-运营名
```

智能体输出时运营名统一写 `lulu`。单关键词广告组且 ABA 排名可确认时，定向维度写大致 ABA 排名，例如 `runner rug(4k)`；多个关键词、词根、类目、Auto 或 ASIN 定向不得写 ABA 排名。

结构示例：

- `RG1005-SP-runner rug(4k)-词组-长条-2.5x6-lulu`
- `RG1005-SP-runner rug词根-广泛-长条-2.5x6-lulu`
- `RG1005-SP-Auto Close-Auto Close-长条-2.5x6-lulu`

除单关键词广告组、头部词和低预算隔离测试词外，每个广告组放 `3-5` 个同入口、同词根或同场景关键词。

Phrase 承接稳定短语和属性长尾。关键词 Broad 用于低 Bid 拓词。Auto 只用 Close match 补充紧密搜索词流量。地毯新品不使用自动 Loose match，也不使用 ASIN 商品投放拓量。

## 新品标准最低日预算

新品广告组预算必须按 `agents/promo-output-templates.md` 的标准最低日预算规则执行：先确认类目和尺寸，自动识别地毯类型，再调用 `agents/category data thresholds.md` 中该类型的 CPA 正常线上限。

规则：

- 单广告组标准最低日预算 = 对应类目 / 型号 / 尺寸的 CPA 正常线上限。
- 若用户明确给出单广告组目标订单数 `N`，单广告组标准最低日预算 = CPA 正常线上限 × `N`。
- 对应类目 CPA 阈值缺失时，预算写 `待补CPA阈值` 或 `待人工配置`，不能编数。
- 用户预算低于 CPA 正常线上限时，只能定义为观察预算或拓词预算，不能定义为可判断出单的标准预算。
- 新品可以用 CPA 正常线上限设置预算底线，但不能用短期 CPA / CVR / ACOS 直接强判暂停、否词或放量。

## 关键词 ABA 排名分组规则

新品广告方案给关键词分组时，必须先看单个关键词的 ABA 排名，再决定是否单独建组。

- 单个关键词 `ABA排名 <= 30,000`：该词必须单独建广告组，不得和其他关键词混在同一个广告组里。
- 单个关键词 `30,000 < ABA排名 <= 100,000`：建议按同对象、同词根、同属性放在同一个广告组，每组 `2-5` 个词。
- 单个关键词 `ABA排名 > 100,000`：按同对象、同词根、同属性低预算拓词；如果和更高流量词混组会干扰判断，应单独拆组或只与同层级长尾词合并。

执行细节：

1. `ABA排名 <= 30,000` 的词即使属于同一词根，也要单词单组。
2. `30,000 < ABA排名 <= 100,000` 的词可以合并，但必须语义一致，不能把猫用、狗用、通用宠物、尺寸、材质、颜色等不同入口硬塞在一起。
3. 同一个广告组不能混入不同层级目的明显不同的词，例如核心大词、属性词、容量词和拓词词根混在一起。
4. 如果预算不足以承载所有广告组，优先保留主投区间内、匹配度最高、产品承接最强的词；低预算隔离测试词最后保留。不要为了省广告组数量而把头部词或单词单组词混入其他组。

## 匹配方式规则

推荐 Phrase：

- 词序稳定。
- 搜索词围绕同一个短语扩展。
- 适合尺寸词、场景词、功能词组合。
- ABA 表 `广告用途` 为“优先词组投放；新品阶段不优先精准”。

推荐关键词 Broad：

- 用户表达分散，修饰词位置不固定。
- ABA 表 `广告用途` 为“广泛或同词根合并低预算测试”。
- 关键词 Broad 只能低 Bid、小预算拓词，不承担主预算收割。
- 输出表中可以写 `Broad` 或 `Phrase + Broad`，但必须明确这是关键词匹配，不是 Auto Loose。

禁止自动宽泛：

- 地毯新品自动广告只保留 `Close match`。
- 不生成 `Auto Loose`、`Loose match`、自动宽泛匹配。
- 不生成 `Auto Substitutes` 或 `Auto Complements`。

禁止 ASIN 匹配广告：

- 地毯新品方案中，不生成竞品 ASIN、自有 ASIN、单 ASIN 定向广告组。
- 输出表中 `投放策略` 不得写 `Product Targeting ASIN`、`ASIN Targeting`、`竞品 ASIN`、`自有 ASIN`。
- 输出表中 `投放词 / 词根 / 类目` 不得放具体 ASIN。

不推荐 Exact：

- 新品无稳定搜索词表现。
- 没有足够广告订单和转化稳定性。
- 只是因为词精准，不足以建立 Exact。

## 否定与隔离边界

新品首轮不要因为短期点击无单就激进否词。否词必须结合样本量、相关性和是否属于 P4 / 风险词。

可直接排除且默认不展示：

- 阶段 ABA 区间外且未批准强匹配低预算隔离例外的新品候选词。
- 结论为 `受限测试` 的候选词。
- `推荐层级=P4 完全不相关`。
- `否定/隔离类型=完全不相关否定`。
- 明显非地毯品类、配件、清洁工具、耗材等无关词。

必须隔离复核：

- 品牌/竞品词。
- 促销/价格词。
- `P3 观察/否定候选`。
- ABA 表里标记风险或隔离的词。

### 高流量核心词精准否定隔离

新品 Auto / Broad / Phrase 广告必须先检查当前类目是否在 `agents/category data thresholds.md` 中维护了高流量核心隔离阈值。未维护阈值的类目，不得套用 Rug 阈值，不自动生成高流量核心隔离否词，只输出 `该类目高流量核心隔离阈值待配置`。

Rug 当前隔离阈值：

```text
推荐层级=P1/P2
且 ABA排名<=11000
且 合规状态=安全
且 与当前产品地毯区域、尺寸、材质、颜色、风格、图案动物类型不冲突
```

命中的词定义为 `高流量核心隔离词`。该否定是流量隔离，不是低相关否定；默认只做 `Negative Exact`，不得做 `Negative Phrase`。

执行规则：

1. Auto Close：只从当前产品对应广告词库中筛选命中阈值、会被该 Auto Close 触达、且不是本广告组主动投放对象的 `高流量核心隔离词`，加入该广告组的 `Negative Exact`。
2. Broad：先判断投放词 Broad 可能匹配出的搜索词集合，包括同词根乱序词、同义词、缺词 / 加词变体、属性扩展词和类目大词；再从可能匹配词中筛选 `高流量核心隔离词`，加入该 Broad 广告组的 `Negative Exact`。
3. Phrase：先判断投放词 Phrase 可能匹配出的搜索词集合，即完整包含投放短语且词序不变，只允许前后加词；再从可能匹配词中筛选 `高流量核心隔离词`，加入该 Phrase 广告组的 `Negative Exact`。
4. 同一个广告组不得把自己的主投放词或组内正在投放的词加入 `Negative Exact`；命中隔离阈值也不能覆盖此禁令。
5. 如果产品有具体 `图案动物类型`，必须先执行动物类型强匹配；例如 tiger 产品不得把 `leopard rug`、`zebra rug`、`cowhide rug` 当作高流量核心隔离词。
6. 默认只在 `新广告设置表` 的对应广告组行写入实际需要执行的隔离词。只有用户明确要求“输出否词清单”时，才单独生成否词表。

### 新品精准否定规则

新品方案里的 `精准否定词` 不是“不相关词清单”，也不是“已投放词清单”。默认只用于命中当前类目高流量核心隔离阈值、会被当前广告组触达且不会造成自我否定的 `Negative Exact` 隔离。

执行规则：

1. Rug 新品 Auto / Broad / Phrase 只有同时满足 `推荐层级=P1/P2`、`ABA排名<=11000`、`合规状态=安全`且与当前产品地毯区域、目标尺寸、材质、颜色、风格、图案动物类型不冲突的词，才有资格写入 `精准否定词`。
2. 某词已出现在本方案 `投放词 / 词根 / 类目` 中，不因“已投放”自动进入 `精准否定词`。若 `ABA排名>11000`，即使是 `P1/P2`，也不得作为 Rug 新品默认精否词。
3. 同一个广告组不得精否自己的主投放词或本组内正在投放的词，避免自我否定。该禁令优先于隔离阈值。
4. Auto Close 只可写入命中高流量核心隔离阈值、会被该 Auto Close 触达、且不是本组投放对象的核心词。
5. Broad / Phrase 只可写入命中高流量核心隔离阈值、可能被该广告组匹配到、且不是本组投放对象的核心词；不得把本组投放词直接照抄为精否词。
6. 阶段外词、受限测试词、观察词、配件词、不相关词、品牌 / 竞品风险词默认不写入 `精准否定词`；这些词只做“不展示 / 不投放 / 隔离复核”处理。
7. 只有用户明确要求“输出否词清单”时，才单独生成否词表。默认方案不为解释排除原因而附加独立否词表。

例子：

- Phrase 广告组正在投放 `5x7 washable rug` 时，不得在同一广告组把 `5x7 washable rug` 写入 `精准否定词`，即使它命中隔离阈值。
- Rug Auto Close 中，`runner rug` 若为 `P1`、`ABA排名<=11000`、产品属性匹配且会被 Auto Close 触达，可以作为高流量核心隔离词写入 `精准否定词`；如果该词同时是本组主动投放对象，则不得精否。
- 某 Rug 关键词为 `P1` 但 `ABA排名=12000`，不满足 `<=11000`，不得作为新品默认精否词。

新品阶段不要把同词根下个别低表现搜索词直接做 Negative Phrase，避免误杀后续长尾。

## 冲突检查

输出前必须检查：

- 产品类型是否和 ABA 文件一致，且是否只读取了 `广告词库` sheet。
- 目标推广尺寸是否与关键词明确尺寸一致；例如目标 `5x7` 是否误收了 `3x5`、`5x8` 等尺寸词。
- 地毯类型、形状、材质、颜色、风格、图案动物类型是否与关键词发生明确冲突。
- 是否把 P3 / P4 / 风险词混进核心广告组。
- 是否在 `图案动物类型` 已确认时推荐了其他动物关键词。
- 是否在动物类型未确认时把具体动物关键词放进默认 `ABA选词表` 或 `新广告设置表`。
- 是否把高流量大词放进新品首轮主预算。
- 是否未按当前类目隔离阈值执行 Auto / Broad / Phrase 的高流量核心词精准否定隔离。
- 是否把 Rug 的 `P1/P2 + ABA<=11000` 阈值套用到未配置隔离阈值的其他类目。
- 是否把高流量核心隔离词做成 `Negative Phrase`。
- 是否把 `ABA排名>11000` 的 Rug 词作为新品默认精准否定词。
- 是否把广告组自己的主投词或组内投放词写入同组 `精准否定词`，造成自我否定。
- 是否在未确认 Auto Close / Broad / Phrase 可触达该核心词时直接写入精准否定。
- 是否把未命中强匹配例外、或未批准独立测试预算的阶段外词放进输出表。
- 是否把普通受限测试词、观察词、未投放的低排名大词或否词候选词展示在新品广告方案表格里。
- 是否把低预算隔离测试词标明 `推荐动作=低预算隔离测试`、`主投=否`，并放入单独广告组、单独预算。
- 是否把未投放且未命中高流量核心隔离规则的词写进 `新广告设置表` 的 `精准否定词` 列。
- 是否把配件词、不相关词、品牌/竞品风险词当成默认精准否定词，而不是剔除或隔离复核。
- 是否把 `ABA排名 <= 30,000` 的关键词和其他词混在同一个广告组里。
- 是否把 `30,000 < ABA排名 <= 100,000` 的关键词超出 `2-5` 个词强行合并，或与语义不一致的词混组。
- 是否没有按 `SPU-广告产品-定向维度-匹配方式-场景分类-尺寸-运营名` 生成广告组名称。
- 是否在多个词、词根、类目、Auto 或 ASIN 定向的广告组名称里错误写入 ABA 排名。
- 是否把低于 CPA 正常线上限的预算写成标准最低日预算，而不是观察预算 / 拓词预算。
- 是否在地毯新品方案的自动广告中生成了 Auto Loose / 自动宽泛匹配。
- 是否在地毯新品方案中生成了 Auto Substitutes / Auto Complements。
- 是否在地毯新品方案中生成了 ASIN 匹配广告、竞品 ASIN、自有 ASIN 或单 ASIN 定向。
- 是否在新品阶段创建了 Exact。
- 是否错误调用 `category data thresholds.md` 做新品强判。
- 是否把无历史阈值的 CPA / CVR / ACOS 写成确定性结论。

命中冲突时，输出人工确认，不直接给执行动作。

## 输出要求

新品推广方案默认必须导出表格文件，不能只在对话里给口头方案。用户说“给我广告方案 / 输出广告方案 / 导出方案”时，默认生成 `.xlsx`。

新品推广方案只输出 2 张核心表：

1. `ABA选词表`
2. `新广告设置表`

不要额外输出 `策略摘要表`、`人工确认表`、`来源说明表`。必要的策略、缺失数据、人工确认事项，合并写入两张核心表的 `判断依据 / 备注` 字段。

必须在 `ABA选词表` 下方追加一段 `判断依据与设计逻辑`。该说明只用自然段，不新增表格、不新增 sheet，内容必须说明：

- 本次使用的 ABA 表、产品属性、历史出单词、竞对词或类目流量层证据。
- 当前新品阶段和 ABA 区间如何影响选词。
- 为什么这样拆广告组、采用统一命名、选择 Phrase / Broad / Auto Close、设置标准最低日预算和 Bid。
- 为什么没有选择未投放的阶段外词、普通受限测试词、ASIN 投放、自动宽泛匹配或 Exact；若有强匹配例外，必须说明其为何只进入低预算隔离测试而非主预算。

说明段必须把关键判断按来源标注清楚：

- `【流量结构打法】`：说明是否调用类目流量结构、竞对词表或 ABA 入口层判断，以及它影响了哪些广告组或预算分配。
- `【历史数据】`：说明是否调用同类历史出单词；如果调用，只能作为选词参考和可复用词证据，不能当作当前新品已验证表现。
- `【用户固定规则】`：说明哪些结论来自已固定规则，例如统一广告组命名、单关键词名称可写 ABA 大致排名、CPA 正常线上限作为标准最低日预算、Rug `0-15 单/日` 主投门槛与强匹配低预算隔离例外、Rug 高流量核心隔离阈值、地毯自动广告只保留 Close、不输出 ASIN 投放、ABA<=3W 单词单组、3W-10W 词 2-5 个合组、新品精准否定边界。
- `【ABA/产品属性】`：说明 ABA 排名区间、文件映射、`广告词库` sheet 和产品尺寸 / 颜色 / 风格 / 材质 / 图案动物类型匹配如何决定最终投放词。
- `【人工输入/预算目标】`：说明用户给定预算、产品定位、目标阶段、运营名如何影响预算、Bid 和验证强度。
- `【缺失数据】`：说明没有提供的证据，例如无历史数据、无竞对词表、无目标 ACOS / CPA 时，哪些结论只能做低预算验证或待人工确认。

如果用户明确要求“先预览、不导出”，才可以在对话里输出 Markdown 表格；否则默认给 Excel 表格文件。

### 1. ABA 选词表

字段：

- ABA等级
- 机会类型
- 综合分
- 搜索词
- 规范词根
- ABA排名
- 匹配 ABA 词
- 来源 ABA 文件
- 来源 sheet：固定为 `广告词库`
- 类目判断
- 地毯类型
- 目标推广尺寸
- 对应标签
- 推荐层级
- 相关度等级
- 合规状态
- 广告用途
- 产品匹配点
- 属性冲突检查：通过 / 待人工确认；硬冲突词不得出现在本表
- 建议动作
- 投放角色：主投 / 低预算拓词 / 低预算隔离测试
- 主投：是 / 否
- 建议匹配方式
- 精准否定
- 原因

`对应标签` 必须合并输出该词在 ABA 表中的全部可用标签，包括尺寸、场景、功能、风格图案、颜色、材质结构、形状、人群宠物。

`精准否定` 列必须明确：

- 新品广告方案默认只展示投放词，因此写 `否`。
- 普通受限测试词、观察词、未投放的阶段外词和否定候选词不进入本表；已批准执行的强匹配低预算隔离测试词可以进入，但必须写明 `投放角色=低预算隔离测试`、`主投=否`。
- `ABA选词表` 不承载未投放词的否词清单；只有用户明确要求输出否词清单时，才另行输出 `Negative Exact`。

### 2. 新广告设置表

字段：

- 广告组名称
- ASIN
- 类型：新增广告组 / 加入原组 / 重建 / 不新建
- 预算
- Bid
- 投放策略
- TOS / ROS / PP
- 投放角色 / 主投
- 投放词 / 词根 / 类目
- 精准否定词
- 判断依据

预算优先按对应类目 / 型号 / 尺寸的 CPA 正常线上限设置标准最低日预算；没有对应 CPA 阈值或类目映射时，写 `待补CPA阈值` 或“待人工配置”，不要编数。Bid 没有明确边界时，写“待人工配置”。

`精准否定词` 列执行新品精准否定规则：

- 只允许填写命中当前类目高流量核心隔离阈值、会被当前 Auto / Broad / Phrase 广告组触达且不是本组投放对象的词。
- Rug 词必须同时满足 `P1/P2`、`ABA排名<=11000`、`合规状态=安全`和产品属性不冲突；`ABA排名>11000` 不得作为新品默认精否词。
- 本方案已投放不是精否理由；同一广告组不得精否自己的主投词或本组正在投放的词。
- 配件词、不相关词、阶段外词、品牌/竞品风险词默认剔除或隔离复核，不作为默认精准否定词。
- 如果本广告组没有符合条件的高流量核心隔离词，写 `无` 或留空。

## 判断禁区

- 不要把 ABA 排名高等同于新品应该主投。
- 不要把未命中强匹配例外、或未批准独立测试预算的阶段外词放进新品广告方案输出表。
- 不要在新品广告方案默认输出里展示普通受限测试词、观察词、未投放的低排名大词或否定候选词；只展示实际需要投放的词。已批准执行的强匹配低预算隔离测试词可以展示，但必须标记 `主投=否`。
- 不要因为某词已投放或 ABA 排名处于当前阶段范围就自动写入 `精准否定词`；只有命中当前类目高流量核心隔离阈值、广告组可触达且不会自我否定时才允许写入。
- 不要把 Rug 的高流量核心隔离阈值套用到其他未配置阈值的类目。
- 不要把高流量核心隔离词做 Negative Phrase；默认只允许 Negative Exact。
- 不要把 `综合优先级` 当成唯一排序依据。
- 不要把所有地毯类型混用同一个 ABA 文件，也不要把四个 Rug ABA 文件全量混成一个无场景候选池。
- 地毯新品关键词广告可以输出 Broad，但自动广告只能输出 Auto Close。
- 地毯新品不要输出 Auto Loose / 自动宽泛匹配。
- 地毯新品不要输出 Auto Substitutes / Auto Complements。
- 地毯新品不要输出 ASIN 匹配广告、竞品 ASIN、自有 ASIN 或单 ASIN 定向。
- 不要在新品阶段默认建 Exact。
- 不要用新品短期 CPA / CVR / ACOS 直接判死。
- 不要把 `category data thresholds.md` 当成新品默认阈值。
- 不要把促销/价格词、品牌/竞品词、P4 词混进核心广告组。
- 不要因为产品是动物风格就推荐任意动物词；具体动物关键词必须匹配 `图案动物类型`。
- 不要把历史同类数据当成当前 ASIN 的确定表现，只能作为参考证据。
