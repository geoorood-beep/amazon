# AGENT: 推广输出模板

> 项目作用域：本项目输出对象只允许是 Rug / 地毯。表格中的产品、阈值来源、ABA 来源和历史来源必须全部落在陆遥项目白名单内。

老品推广在报表齐全时必须可执行，不能只给泛泛建议。仅有当前链接历史搜索词时，可输出“有限数据老广告优化方案”，但它必须是词根层候选方案，不得伪装成已知道后台 Campaign、广告组、Bid 或广告位的执行单。

## 老品输入报表命名

老品推广涉及输入表说明、缺失数据说明或交付前检查时，统一使用以下固定报表名称：

必须：

1. `SP搜索词-按词-每日明细`
2. `SP搜索词-按词-汇总`
3. `SP投放对象 / 关键词 / 商品投放报告`
4. `SP广告位报告`
5. `SP广告商品报告`
6. `Campaign / Ad Group 设置表`

建议：

1. `SP广告位-每日明细`
2. `SP关键词-每日明细`
3. `小时预算 / 小时花费报告`
4. `商品业务数据 / 订单目标 / 利润信息`

输出中不得只写 `Search Term Report`、`Placement Report`、`Targeting Report`、`Campaign report` 这类泛化名称；如必须使用英文后台名称，必须同时写出上面的标准名称。

## 产品策略摘要

必须输出：

- ASIN / SKU：明确产品对象与父子体关系。
- 当前订单目标：链接总广告订单目标 / 当前阶段目标订单。
- 核心诊断：用 1-3 句话概括主要问题。
- 总体策略：说明保留、优化、新建和停止方向。
- 数据质量：`DQ_PASS / DQ_WARNING / DQ_BLOCKED`，并说明阻断或警告原因。
- 唯一整体状态：按 V1.4 优先级只写一个状态。
- 数据置信度：高 / 中 / 低，并说明缺失数据。
- Validator 结果：`AUTO_PASS / APPROVAL_REQUIRED / BLOCKED`；没有执行候选时写 `不适用`。
- 已导入报表：按“老品输入报表命名”列出。
- 缺失报表影响：按标准报表名称说明缺失后不能判断什么。

## 仅当前链接历史搜索词时的输出

触发条件：已确认搜索词来自当前链接，且报表至少含观察周期、搜索词、点击、花费、广告订单和广告销售额。如果来自同类历史词库而不是当前链接，不得使用本模板写成老品优化。

第一张核心表使用 `有限数据老广告优化表（词根候选）`，必须包含：

- 规范词根、归属出单搜索词、观察周期、词根聚合点击、订单、花费、广告销售额、CVR、ACOS、平均 CPA。
- 类目阈值命中结果、历史词根优化分、评分等级、词根层建议、匹配方式候选、投放对象映射状态、数据不足说明。
- 高分词根可写 `Phrase复投候选`、`Exact候选`或 `Broad低预算候选`；风险词根可写 `限流 / Negative Exact 候选，待映射`。不得直接写成已执行否词、降 Bid、暂停或加预算。

同时输出“缺失报表影响”，其中 `SP投放对象 / 关键词 / 商品投放报告`、`SP广告位报告`、`SP广告商品报告`、`Campaign / Ad Group 设置表` 缺失时，对应模块必须写 `【缺失数据】数据不足，无法准确判断`。

## 老广告如何优化

标准字段：

- Campaign_ID
- Ad_Group_ID
- 广告组名称
- ASIN
- 预算调整
- 投放策略调整
- Bid 调整
- TOS / ROS / PP 调整
- 活动级别：开启 / 暂停 / 观察 / 重建
- 判断依据：必须包含观察周期、核心指标、命中规则、数据充分度，以及为什么没有选择其他动作。

仅当前链接历史搜索词模式下，如仍使用本表，`Campaign / 广告组名称`、`预算调整`、`Bid 调整`、`TOS / ROS / PP 调整`和`活动级别`统一写 `待投放对象映射 / 数据不足`；只有词根层的“候选动作”可写建议。

### 完整模式执行字段

当一行被定义为“可执行动作”时，必须在同一张 `老广告优化表` 中补齐以下字段；不另加读者侧策略表：

- `Action_ID`
- `Campaign_ID`
- `Ad_Group_ID`
- `Target_ID / Keyword_ID`
- `action_level`
- `current_value`
- `proposed_value`
- `unit`
- `precondition`
- `rollback_value`
- `input_snapshot_id`
- `expected_current_value`
- `generated_at`
- `expires_at`
- `Rule_ID`
- `Threshold_ID`
- `risk_level`
- `approval_status`
- `validator_outcome`
- `validator_findings`

只有方向、百分比或名称而没有不可变 ID、当前值、目标值、回滚值、快照和有效期的行，必须降级为“建议 / 候选”，不能标为可执行。`expected_current_value` 与执行前后台当前值不一致时必须 `BLOCKED`。

### 动作状态与执行边界

- `AUTO_PASS`：规则、数据、映射、字段和冲突校验通过；V1.4 仍需人工确认和实施，不代表 Amazon 后台已执行。
- `APPROVAL_REQUIRED`：高影响、数据警告、低样本停止例外或其他需人工复核的候选。
- `BLOCKED`：不得进入执行清单，只在说明中列出阻断原因。
- 同一对象每批只能保留一个主动作。相反动作不得平均或同时输出；暂停为主动作时，其他同对象主动作撤销。
- 人工执行后必须记录 `EXECUTED / SKIPPED / PARTIAL / FAILED`，并保存执行时间、失败原因和实际回滚结果。

## 新广告如何设置

标准字段：

- 广告组名称
- ASIN
- 类型：新增广告组 / 加入原组 / 重建 / 不新建
- 预算
- Bid
- 投放策略
- TOS / ROS / PP
- 投放词 / 词根 / ASIN
- 判断依据

老品优质出单词跨广告产品拓量时，新广告设置表还必须补充以下字段或在 `判断依据` 中逐项写清：

- 来源广告产品
- 来源 Campaign / Ad Group
- 来源匹配方式
- 原始出单词 / 投放词
- 原订单 / 点击 / 花费 / CPA / ACOS / CVR
- 是否达到优质线
- 建议新增广告产品：SPV / SB / SBV / 其他
- 素材 / 品牌资质检查
- 拓量优先级：A档 / B档 / C档
- 风险控制

同一个词同时新增 SPV、SB、SBV 时，必须拆成多行，不要把多个广告产品混在同一行。

## 广告组命名规则

所有新品广告方案、老品新增广告、重建广告组和需要输出后台可执行设置的广告组，命名必须采用：

```text
SPU-广告产品-定向维度-匹配方式-场景分类-尺寸-运营名
```

字段规则：

- `SPU`：产品 SPU / 款号 / 内部产品代号，如 `RG1005`。缺失时写 `SPU待补`，不要编。
- `广告产品`：Amazon 广告产品类型，如 `SP`、`SPV`、`SB`、`SBV`、`SD`。当前 SP 方案写 `SP`；跨广告产品拓量时按实际新增广告产品写。
- `定向维度`：真实投放对象，可以是单个关键词、词根、类目、`Auto Close`、ASIN 或其他定向对象。
- `匹配方式`：`精准`、`词组`、`广泛`、`Auto Close`、`类目`、`ASIN` 等。
- `场景分类`：按 Rug 产品切换，例如长条、门垫、客厅、厨房、浴室、户外等。
- `尺寸`：按产品实际规格写，例如 `2.5x6`、`5x7`、`10L`。无尺寸产品写 `无尺寸`；缺失写 `尺寸待补`。
- `运营名`：人工方案写用户指定运营名；智能体输出统一写 `lulu`。

单关键词广告组且 ABA 排名可确认时，在 `定向维度` 的关键词后用括号写大致排名：

- `runner rug(4k)` 表示 ABA 约 4,000。
- `area rug(1.8w)` 表示 ABA 约 18,000。
- `washable rug(12w)` 表示 ABA 约 120,000。

千位用 `k`，万位用 `w`，只写大致排名，不写完整数字。若广告组包含多个关键词、词根、类目、Auto、ASIN 或其他非单关键词定向，不得在广告组名称中写 ABA 排名。

示例：

```text
RG1005-SP-runner rug(4k)-广泛-长条-2.5x6-lulu
RG1005-SP-runner rug词根-词组-长条-2.5x6-lulu
RG1005-SP-Auto Close-Auto Close-长条-2.5x6-lulu
RG1005-SPV-area rug(1.8w)-词组-客厅-5x7-lulu
RG1005-SB-area rug(1.8w)-词组-客厅-5x7-lulu
RG1005-SBV-area rug(1.8w)-词组-客厅-5x7-lulu
```

## 标准最低日预算规则

广告组标准最低日预算按对应类目 / 型号 / 尺寸的 CPA 正常线上限设置，不按 CPC 推算：

```text
单广告组标准最低日预算 = 对应类目 / 型号 / 尺寸的 CPA 正常线上限
```

如果用户明确给出单广告组目标订单数 `N`，则：

```text
单广告组标准最低日预算 = CPA 正常线上限 × N
```

执行规则：

- 先确认产品类目、型号、尺寸或容量，再调用 `agents/category data thresholds.md` 中对应 CPA 阈值。Rug 必须先按尺寸自动识别长条 / 门垫 / 区域 / 圆形，再调用该类型阈值。
- 预算字段必须写出具体来源，例如“`2x6` 自动识别为长条，按长条 CPA 正常线上限 `$13` 设置”。
- 本项目只调用 Rug 阈值、产品名称、场景分类、尺寸和运营名；不得跨项目调用其他类目标准。
- 若对应类目 CPA 阈值缺失，预算写 `待补CPA阈值` 或 `待人工配置`，不能编数。
- 若用户给定预算低于 CPA 正常线上限，该预算只能标为 `观察预算` 或 `拓词预算`，不能标为“标准最低日预算”，也不能用该预算跑出的短期结果强判词好坏。
- Phrase、Broad、Auto Close、Exact、类目投放或 ASIN 投放只要被定义为“可判断出单”的广告组，预算都必须达到该类目 CPA 正常线上限；低于该值只能作为观察 / 拓词。

## 表格输出要求

- 1-2 张核心表优先，除非用户要求完整后台动作清单。
- 核心表数量限制不允许隐藏执行安全字段。老品完整模式如包含后台动作，必须在现有 `老广告优化表` 内加入 V1.4 执行字段和 Validator 结果；有限数据模式仍只输出候选字段。
- 搜索词报告核心表必须包含：ABA等级、机会类型、常规机会综合分或（仅当前链接历史搜索词模式）历史词根优化分、词根、ABA排名、匹配ABA词、聚合点击、聚合订单、聚合花费、出单花费占比、未出单词花费占比、ACOS、CVR、平均CPA、近3天CVR、放大判断、跨广告产品拓量判断、建议动作、建议匹配方式、Exact候选词、出单搜索词明细。
- 词根行红色加粗；归属出单词黑色。
- 不得让概览、备注区或辅助信息覆盖核心表字段。

## 广告架构设计说明

无论新品推广还是老品推广，只要输出广告架构设计，必须在现有第一张核心表下方追加一段 `判断依据与设计逻辑`，不要新增表格、不要新增 sheet、不要另做策略摘要表。

导出 `.xlsx` 时，将该说明作为第一张 sheet 表格数据下方的文字说明区；Markdown 预览时，放在第一张表格后面、第二张表格前面。

说明段必须用自然段，不要拆成新表。内容必须覆盖：

- 使用了哪些数据来源：新品写 ABA、产品属性、历史出单词、竞对词或类目流量层；老品写当前链接报表、观察周期、品类阈值、目标 ACOS / CPA / CVR。
- 当前处于新品冷启动、扩大验证、老品优化、重建或收缩阶段的判断。
- 为什么采用当前广告架构：例如核心词单独建组、长尾词合并、自动广告只保留 Close、Exact 暂不创建、老品保留/拆分/合并/重建、优质出单词跨广告产品拓量。
- 广告组命名、标准最低日预算、Bid、广告位或匹配方式的主要依据。
- 为什么没有选择其他架构或动作，例如不跑高流量大词、不建 ASIN 投放、不拆广告位、不暂停、不跨广告产品拓量、不放量。

说明段必须标明关键判断的来源，使用以下标签写在对应判断前或句中：

- `【流量结构打法】`：来自 `agents/category-traffic-strategy.md`、ABA 流量层、竞对词表或类目入口结构，用于解释为什么集中打核心入口、分散打长尾、是否需要防守 / 抢入口 / 拓入口。
- `【历史数据】`：来自 `reference/category-history/` 或用户导入的同类历史搜索词，用于解释哪些词有历史成交证据、哪些词只是候选参考。老品诊断不得用类目历史词替代当前报表。
- `【当前历史搜索词】`：来自当前链接搜索词汇总 / 每日明细，只用于词根历史订单、CVR、ACOS 和历史词根优化分；缺少投放对象报告时不得写成后台实施动作。
- `【用户固定规则】`：来自本 AGENTS 已固定规则，例如广告组命名格式、CPA 正常线上限作为标准最低日预算、地毯自动广告只保留 Close、地毯不做 ASIN 投放、新品精准否定边界、老品广告位先看整体效果、优质出单词跨广告产品拓量边界。
- `【ABA/产品属性】`：来自 ABA 排名、Rug ABA 文件映射、`广告词库` sheet、尺寸 / 颜色 / 风格 / 容量 / 材质 / 人群宠物等匹配。
- `【当前报表】`：老品当前链接 / Campaign / Ad Group 的搜索词、投放对象、广告位、广告商品、预算、趋势和设置表。
- `【人工输入/预算目标】`：来自用户输入的预算、目标订单、目标 ACOS / CPA、产品定位、运营名或人工限制。
- `【缺失数据】`：说明哪些判断没有数据支持，因此只观察、不执行或待人工确认。

如果某个来源没有被使用，不能伪装调用；说明段应直接写“未使用历史数据”或“未提供流量结构判断”。

说明段只解释已经输出的表格方案，不能引入表格里没有执行的新动作。

## 新品推广输出模板

新品推广方案默认导出 `.xlsx` 表格文件。用户说“给我广告方案 / 输出广告方案 / 导出方案”时，不要只在对话里输出文字方案；除非用户明确要求“先预览”。

新品推广方案只输出 2 张核心表：

1. `ABA选词表`
2. `新广告设置表`

不要额外输出 `策略摘要表`、`人工确认表`、`来源说明表`。必要说明合并进两张表的 `原因 / 判断依据`。

必须在 `ABA选词表` 下方追加一段 `判断依据与设计逻辑`。该说明解释本次新品广告架构为什么这样拆组、为什么选择这些词和匹配方式、为什么排除其他词或广告类型；不新增表格或 sheet。

地毯新品广告方案只展示当前阶段实际需要投放的词。主投词必须通过阶段门槛；只有命中强匹配例外、已经分配独立小预算并单独建组的词，才可作为 `低预算隔离测试` 展示并标记 `主投=否`。普通阶段外词、受限测试词、观察词和否定候选词默认不展示；只有用户明确要求输出否词清单、受限测试词或后续升级词时，才另行输出。

在判断 ABA 排名、历史成交和综合分之前，必须先做产品属性硬冲突过滤。`尺寸` 是本次任务的目标推广尺寸；目标为 `5x7` 时，明确含 `3x5`、`5x8` 等其他尺寸的词不得出现在任一输出表。明确冲突的地毯类型、形状、材质、颜色、风格和图案动物类型同样直接剔除，历史成交和 ABA 排名不得覆盖硬冲突。

Rug 输出中的 `地毯类型 / 场景分类 / 阈值来源` 必须来自尺寸自动识别：`2x4`、`3x6`、`3x7`、`4x10`、`4x12` 和所有短边为 `2.5` 的矩形写 `长条`。区域产品还要写明调用 `小区域` 或 `大区域` 阈值；圆形无阈值时写 `圆形阈值待配置`，不得借用区域阈值。

### 地毯新品广告类型限制

地毯类目新品推广方案不得输出以下广告：

- Auto Loose / 自动宽泛匹配。
- Auto Substitutes。
- Auto Complements。
- ASIN 匹配广告 / ASIN 商品投放。
- 竞品 ASIN、自有 ASIN、单 ASIN 定向广告组。

地毯新品关键词广告可以输出 Phrase 和 Broad。自动广告只允许输出 Auto Close / Close match，不跑 Auto Loose / 自动宽泛匹配。若用户明确要求类目投放，只能做类目维度，不得放具体 ASIN。

### ABA选词表字段

必须包含：

- ABA等级
- 机会类型
- 综合分
- 搜索词
- 规范词根
- ABA排名
- 匹配 ABA 词
- 来源 ABA 文件
- 来源 sheet：固定为 `广告词库`
- 类目判断
- 地毯类型
- 目标推广尺寸
- 对应标签
- 推荐层级
- 相关度等级
- 合规状态
- 广告用途
- 产品匹配点
- 属性冲突检查：通过 / 待人工确认；硬冲突词不得出现在本表
- 建议动作
- 投放角色：主投 / 低预算拓词 / 低预算隔离测试
- 主投：是 / 否
- 建议匹配方式
- 精准否定
- 原因

`对应标签` 必须合并 ABA 表中的 `尺寸标签`、`场景标签`、`功能标签`、`风格图案标签`、`颜色标签`、`材质结构标签`、`形状标签`、`人群宠物标签`。

地毯新品默认只保留投放词：

- `建议动作` 只写 `核心验证`、`低预算拓词`、`低预算隔离测试` 等明确投放动作。
- `建议匹配方式` 只写 `Phrase`、`Broad` 或 `Phrase + Broad`。
- `精准否定` 默认写 `否`。
- `受限测试` 不属于默认投放动作；只有已经批准独立预算和单独建组的强匹配例外可改写为 `低预算隔离测试` 并进入本表。
- 普通阶段外词、观察词、否定候选词不得出现在本表。

### 新广告设置表字段

必须包含：

- 广告组名称
- ASIN
- 类型：新增广告组 / 加入原组 / 重建 / 不新建
- 预算
- Bid
- 投放策略
- TOS / ROS / PP
- 投放角色 / 主投
- 投放词 / 词根 / 类目
- 精准否定词
- 判断依据

预算优先按 `标准最低日预算规则` 计算；若对应类目 CPA 阈值缺失，写 `待补CPA阈值` 或 `待人工配置`，不要编数。Bid 没有明确边界时写 `待人工配置`。

新品 `精准否定词` 列只用于当前类目已配置的高流量核心隔离词做 `Negative Exact`，不是风险词、不相关词或“已投放词”清单。

- Rug 只有同时满足 `推荐层级=P1/P2`、`ABA排名<=11000`、`合规状态=安全`且与当前产品地毯区域、目标尺寸、材质、颜色、风格、图案动物类型不冲突的词，才有资格写入 `精准否定词`。
- 某词已出现在本方案 `投放词 / 词根 / 类目` 中，不因“已投放”自动进入精准否定；`ABA排名>11000` 时，即使是 `P1/P2` 也不得作为 Rug 新品默认精否词。
- 同一个广告组不得精否自己的主投放词或本组内正在投放的词。
- Auto Close 只写入命中隔离阈值、会被该 Auto Close 触达且不是本组投放对象的核心词。
- Broad / Phrase 只写入命中隔离阈值、可能被本广告组匹配到且不是本组投放对象的核心词；不得把本组投放词直接照抄为精否词。
- 阶段外词、受限测试词、观察词、配件词、不相关词、品牌 / 竞品风险词默认剔除或隔离复核，不写入默认 `精准否定词`。
- 未配置高流量核心隔离阈值的类目，不得套用 Rug 阈值生成否词。
- 高流量核心隔离词不是低相关词，默认不得做 `Negative Phrase`。
- 只有用户明确要求“输出否词清单”时，才另行输出否词表。

新品关键词分组必须按 ABA 排名拆组：

- `ABA排名 <= 30,000` 的单个关键词必须单独建广告组，`投放词 / 词根 / 类目` 只能放该词。
- `30,000 < ABA排名 <= 100,000` 的关键词建议每组 `2-5` 个词，且必须同对象、同词根或同属性。
- `ABA排名 > 100,000` 的长尾词按同对象、同词根、同属性低预算拓词；不要和 `<=30,000` 的核心词混组。
- `判断依据` 必须写清楚命中的 ABA 分组规则，例如“ABA<=3W，单词单组”或“ABA 3W-10W，同词根 2-5 词合并”。

地毯新品 `投放策略` 可以出现关键词 `Broad`，但不得出现 `Auto Loose`、`Loose match`、自动宽泛匹配、`Auto Substitutes`、`Auto Complements`、`Product Targeting ASIN`、`ASIN Targeting`、`竞品 ASIN`、`自有 ASIN`。`投放词 / 词根 / 类目` 不得填写具体 ASIN。
