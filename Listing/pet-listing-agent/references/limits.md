# 字段上限表

所有数值只在这里和 `scripts/validate.py` 顶部的 `LIMITS` 维护。AGENTS.md 正文不重复写数字。
改上限：先改本表，再改 `LIMITS`，最后跑 `python3 tests/run_tests.py`。

| 字段 | 值 | 性质 | 来源与状态 | 确认日 |
|---|---|---|---|---|
| 标题 | ≤75 字符（含空格），非媒体类目 | 硬 | 用户确认。外部来源（卖家工具商博客）口径一致，生效日 2026-07-27，未见亚马逊原文 | 2026-10-26 |
| 亮点 Item Highlights | ≤125 字符，后台为单输入框，写一条文案 | 硬 | 用户确认字段形态与上限 | 2026-10-26 |
| 五点，每条 | ≤256 字符 | 硬 | 用户确认 | 2026-10-26 |
| 五点，合计 | ≤1000 字符 | 硬 | 用户确认 | 2026-10-26 |
| 详情 | ≤2000 字符 | 硬 | 用户确认 | 2026-10-26 |
| 后台 Search Terms | <250 UTF-8 bytes | 硬（仅在另行要求时） | 沿用 V2.5，未重核 | 未重核 |
| 核心词重复 | 标题 1 次；亮点/五点合计/详情各 2 次 | 硬 | 内部规则，非平台规则；只对标记为 core 的词生效 | — |
| 标题单词重复 | 同一单词 ≤2 次（冠词/介词/连词除外，单复数折叠） | 硬 | 沿用 V2.5 对官方规则的理解 | 未重核 |

## 失效规则

- 确认日超过 30 天，开始新生成前向用户确认标题、亮点、五点、详情的当前限制是否变化，或重新核对 Seller Central 公告与帮助页、目标 product type 的字段定义。服务商博客只能当线索。
- 无法核对：沿用本表，并在简要总结里注明"上限按用户确认值核验，未对照当前后台重核"。不写"已核实最新"。

## 说明

- 五点合计 1000 小于每条上限乘五（1280），所以不能每条都写到 256。分配见 AGENTS.md 第 5 节。
- 上限由用户确认，脚本只按这些数值判断，不代表亚马逊后台验证通过。
