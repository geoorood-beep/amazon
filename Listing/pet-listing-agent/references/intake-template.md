## 品类追加项

**饮水机**：水泵类型；滤材层数与包装内滤棉数量；水位可视方式；水流模式；是否含储水桶与碗分离；出水盘材质。

**自动喂食器**：容量（杯 / 磅 / L）；适用粮型与颗粒大小范围；份量设置方式与精度；供电与断电保护；联网功能；防卡粮结构；碗材质；是否适用湿粮。

**猫砂盆（含自动款）**：适用猫体重与只数；兼容砂类型；入口与内部空间尺寸；感应与安全保护；垃圾袋 / 配件兼容；噪声；APP。

**牵引绳 / 胸背带 / 项圈**：尺寸表（颈围 / 胸围范围）；适用体重；材质与五金部位；是否反光。

**窝垫 / 玩具 / 美容工具**：尺寸；适用体型；材质与填充；清洁方式；是否含易吞咽小件。

**其他品类**：先按"通用"项索取资料，再向用户确认该品类还需要哪些必核字段。不套用饮水机经验。
