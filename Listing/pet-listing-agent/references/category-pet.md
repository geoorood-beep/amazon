# 猫狗用品类目事实

本文件只列"必须有依据才能写"的点和易错点，不含平台政策。遇到未列品类，按 `intake-template.md` 的通用项索取资料，不套用其他品类。

## 范围外

食品、零食、营养补充剂、驱虫与药品类。这类商品监管要求不同，需要单独规则，不要用本文件生成。

## 通用

- 对象：dog / cat / multi-pet、small / large dogs、体重与年龄范围，都必须有型号依据。
- 材质逐部件写。只有局部是金属，不能说整机 stainless steel。
- 单位：美国站买家看 oz、gallon、lb、inch。资料给公制时，换算只用于校验：1 in = 2.54 cm；1 lb ≈ 0.4536 kg；1 L ≈ 33.81 US fl oz；1 US gal = 3.785 L = 128 US fl oz。资料只给一种单位而文案需要另一种时，换算后按资料同等精度取整，并在简要总结里注明"换算值"。
- 噪声：dB 数值必须带测试条件，否则不写数字。quiet、silent、whisper、low-noise 等形容词同样需要依据。
- 电池续航：数值必须带使用条件。
- 认证：只有证书或报告编号、或资料原文，才写 UL / ETL / FCC 等。
- 不写：兽医推荐、对所有宠物安全、疾病预防或缓解、焦虑缓解、保证饮水量或进食量、FDA approved。
- 不写 chew-proof、indestructible、escape-proof、no-pull 之类绝对化表述，除非资料有明确依据和条件。
- BPA-free、food-grade、non-toxic、304 钢等：先看资料和证明文件，无证据省略。词库里出现不能当证明。

## 饮水机 / 配件

- 区分整机、泵、电源、滤棉、滤芯、储水碗。整机含过滤件，不等于商品是 replacement filters。
- 不锈钢碗、出水盘、储水桶分开表述。
- 分清适配器供电、可充电电池、无线泵、无线放置、传感器触发模式。无线泵不自动等于整机 cordless 或 battery-operated。
- 容量、滤材层数、噪声值、电池续航、APP 与传感器、洗碗机适用、防水、户外适用，都需要对应型号证据。
- 包装滤棉数量与销售 SKU 一致。配件兼容必须有型号依据，不自动写 universal。
- 不写无依据的抗菌、杀菌、净化有害物质。
- 五点默认主题：容量与对象；部件与水流结构；供电与模式；加水与清洗；包装、适配与使用边界。

## 自动喂食器

- 容量用资料原单位，必要时按通用规则换算。
- 适用粮型和颗粒大小范围必须有资料。湿粮是否适用，无资料不写。
- 定时、份量精度、断电保护、电池备份、联网、摄像头，都需要型号证据。
- 防卡粮结构只写资料能证明的部分，不写"绝不卡粮"。
- 五点默认主题：容量与适用粮型；份量与定时；供电与断电情况；联网功能（如有）；清洁与包装。

## 猫砂盆（含自动款）

- 适用猫体重、只数、兼容砂类型，都需要依据。
- 区分内部可用空间和外形尺寸。
- 安全保护、感应机制只写资料中有的，不写"保证安全"。
- 垃圾袋与配件兼容需要型号依据。
- 五点默认主题：适用对象与空间；清理方式；安全与感应；噪声与供电；配件与包装。

## 牵引绳 / 胸背带 / 项圈

- 写尺寸表范围（颈围、胸围）和适用体重，与目标 SKU 的尺码一致，不要把所有尺码写进一个子体。
- 材质与五金部位分开写。反光有无按资料。
- 承重数字必须有资料，不凭外观推测。

## 窝垫 / 玩具 / 美容工具

- 尺寸、适用体型、填充材质、清洁方式（可机洗需资料）。
- 玩具的耐咬性和安全性不凭外观写。含小件时，不写适用于所有体型。
