# Rug 类目

仅当当前类目是 `rug` 时使用本文件。

## 词库

使用：

- `amazon-listing-webapp/data/categoryKeywordData.json` -> `rug`

旧版兜底：

- `amazon-listing-webapp/data/keywordData.json`

生成地毯 Listing 时，不能使用 chair 或 pet water fountain 关键词。

## 产品名

选择最准确的产品名：

- `Area Rug`
- `Runner Rug`
- `Entryway Rug`
- `Door Mat`

根据尺寸 / 规格和产品上下文选择，不要把所有地毯都强行写成 `Area Rug`。

## Title 格式

推荐结构：

`Brand Size/Spec Washable Core Product, Color/Pattern Non Slip Scenario Product`

规则：

- Title <= 75 characters。
- 最多 1 个逗号。
- 以品牌名开头。
- `washable` 和 `non slip` 只有在用户选择且可支撑时才能进 Title。
- 不要把大段卖点放进 Title。

## Title 可用短卖点

只有在用户选择且可支撑时，以下短卖点可以出现在 Title：

- `washable`
- `non slip`

其他卖点放到 Item Highlights、五点或 Description。

## 五点主题

1. 产品身份、场景适配、视觉风格。
2. 触感 / 低绒高 / 低门缝使用。
3. 背面和地面放置，用非绝对化表达。
4. 清洁和日常维护。
5. 忙碌空间日常使用、边缘或结构细节，仅在有依据时写。

## 风险注意

不能推断：

- Machine washable。
- Non slip backing。
- TPR backing。
- Stain resistance。
- Fade resistance。
- Pet friendly。
- No shedding。
- Floor protection。
- Anti-curling edge。
- Kid / baby safety。

这些只有在用户选择且产品资料支持时才能写。
