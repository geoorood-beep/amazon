# AGENT: Category Data Thresholds

本 AGENT 管理不同品类广告诊断阈值。先确认品类/型号/尺寸，再套用阈值；禁止跨品类套用。

简写：`O=广告订单`，`C=点击`，`S=花费`。阈值列顺序均为：`优质 | 正常 | 警戒 | 高风险`。订单样本未达到要求时，只能标记观察。

## 喂水器：10L / 5L 不锈钢

图片未提供 CTR；涉及 CTR 时标记“CTR标准未提供”。
