# AGENT: 老品推广优化主流程

本 AGENT 是老品推广上层入口。搜索词再投放只是其中 `5.2.5 搜索词与词根诊断` 子模块。

老品推广方案的数据源必须来自当前链接 / 当前 Campaign / 当前广告组的真实报表。`reference/category-history/` 下的类目历史出单词数据只能作为新增选词或新广告候选词参考，不能作为老品诊断、预算、Bid、广告位、趋势、否词、暂停或放量的数据源。

## 老品输入报表命名标准

以后向用户说明老品推广需要导入哪些表格时，必须使用以下固定报表名称。不要用 `Search Term Report`、`Placement Report`、`Targeting Report` 这类泛化英文名替代，除非同时标注对应的标准中文名称。

### 必须导入

| 优先级 | 报表名称 | 主要用途 | 缺失影响 |
|---|---|---|---|
| 必须 | `SP搜索词-按词-每日明细` | 计算近 3 天 CVR、识别出单搜索词、未出单浪费词、词根聚合、放大判断、精准否定 | 缺失后无法判断近 3 天趋势和是否可放大 |
| 必须 | `SP搜索词-按词-汇总` | 查看完整周期累计表现，与每日明细互相校验 | 可用每日明细汇总代替，但稳定性下降 |
| 必须 | `SP投放对象 / 关键词 / 商品投放报告` | 判断投放词、投放 ASIN、匹配方式、Bid、花费、订单、销售额；决定保留、降 Bid、提 Bid、迁移、暂停 | 无法给出投放对象级别的后台动作 |
| 必须 | `SP广告位报告` | 分析 TOS / ROS / PP 的花费、订单、ACOS、CVR；判断广告位溢价加、降、取消 | 无法判断广告位溢价是否合理 |
| 必须 | `SP广告商品报告` | 按 ASIN / SKU / 变体判断哪个子体吃预算、哪个子体转化差；决定拆分、合并、暂停、防守 | 无法判断变体和广告商品层面的优化动作 |
| 必须 | `Campaign / Ad Group 设置表` | 提供预算、状态、竞价策略、默认 Bid、TOS/ROS/PP 溢价、Campaign 名、Ad Group 名 | 只能判断方向，不能输出后台可执行动作 |

### 建议导入

| 优先级 | 报表名称 | 主要用途 | 缺失影响 |
|---|---|---|---|
| 建议 | `SP广告位-每日明细` | 看最近 1 / 3 / 7 / 14 / 30 天广告位趋势，判断短期恶化或恢复 | 只能看汇总，无法判断广告位短期趋势 |
| 建议 | `SP关键词-每日明细` | 判断老投放词本身的趋势，不只看搜索词 | 难以判断投放词是否该保留、调 Bid 或迁移 |
| 建议 | `小时预算 / 小时花费报告` | 判断预算是否过快烧完、是否需要加预算、是否存在时段浪费 | 无法判断预算消耗速度和分时问题 |
| 建议 | `商品业务数据 / 订单目标 / 利润信息` | 至少包含当前订单目标、目标 ACOS 或目标 CPA、售价、毛利、库存、Coupon、Review 星级和数量 | 只能做广告内部优化，无法判断是否值得放量 |

如果用户提供的报表名称不同，先映射到上表标准名称，再继续判断。若无法映射，标记“报表名称不标准 / 需人工确认”，不要自行假设。

## 目标

先沿固定诊断路径判断现有广告为什么好或不好，再通过多层数据聚合确定目标，同时给出老广告优化方案和新广告架构。禁止只看 ACOS 直接调预算或 Bid。

## 阈值调用

CPA、CVR、ACOS 的具体标准不在本文件内硬编码。判断整体效果、广告位效果、广告商品效果和趋势状态时，必须先确认产品类目 / 型号 / 尺寸，再调用：

`agents/category data thresholds.md`

如果对应品类阈值缺失，不能自行编造标准，只能输出“品类阈值缺失，无法强判断”。

## 诊断路径

按顺序检查：

1. 数据有效性：日期、归因、币种、样本量、对象映射、异常值。输出“可判断 / 仅观察”。
2. 整体效果：ACOS、CPA、CVR、订单量、订单完成率、目标完成率。判断“高效达量 / 高效量少 / 有量超标 / 低效无量”。
3. 花费时段：预算消耗率、耗尽时间、小时花费/订单。整体效果好则不判断；整体表现不好才判断“过快 / 正常 / 过慢”。
4. Bid 与策略：曝光、点击、CPC、转化、实际竞价。判断“Bid偏高 / 合理 / 偏低”。
5. 广告位：先看整体活动效果。整体效果达标则不分析广告位；整体效果未达标才分析 TOS / ROS / PP 花费占比、ACOS、CVR、订单。
6. 广告商品：ASIN/SKU、父子体、尺寸、花费、订单、ACOS、CVR、CPA、CTR、变体表现。判断“暂停 / 换品 / 拆分 / 合并 / 防守 / 观察”。
7. 搜索词：单词与词根聚合、迁移、否定、相关性。调用 `search-term-reinvestment.md`。
8. 趋势：3/7/14/30 天方向和波动。不使用 1 天数据做趋势判断。判断“持续好 / 近期转差 / 连续恶化 / 恢复 / 震荡”。
9. 结构：重复词、预算分散、类型混装、内部竞争。判断“保持 / 合并 / 拆分 / 重建”。

## 整体效果判断

- 高效且达量：ACOS `<=` 目标 ACOS，订单完成率 `>=` 目标线，且出单词花费金额占比 `>25%`。动作：保持；预算受限时可增加。
- 高效但量少：ACOS `<=` 目标 ACOS，订单完成率 `<` 目标线。动作：查预算、Bid、曝光和广告位。
- 有量但超标：订单达标，且目标 ACOS `< ACOS <=` 正常线 ACOS。动作：优化词、Bid 和广告位。
- 低效无量：ACOS `>` 高风险线 ACOS，或无订单且花费达到停止线。动作：降价、否定、降预算或暂停。
- 数据不足：未达到最低点击/花费/订单样本。动作：保持，继续观察。

订单样本未达到 `category data thresholds.md` 要求时，只能标记观察，不能强行判断好坏。

## 花费时段诊断

花费时段只在整体广告表现不好时分析。

### 是否进入小时花费分析

1. 若整体广告效果好：
   - 不判断小时花费节奏。
   - 不因为上午花得快或下午花得慢就调整预算。
   - 动作：保持。

2. 若整体广告表现不好：
   - 开始分析小时数据。
   - 判断预算是否过快、正常或过慢。
   - 再结合订单表现决定动作。

### 理想累计花费曲线

最佳出单集中在 `06:00-18:00`，使用以下理想累计花费比例作为自动监控基准：

| 时间 | 理想累计花费 |
|---|---:|
| 06:00 | 10% |
| 08:00 | 20% |
| 10:00 | 35% |
| 12:00 | 50% |
| 14:00 | 65% |
| 16:00 | 80% |
| 18:00 | 95% |
| 24:00 | 100% |

计算：

```text
实际累计花费率 = 当前已花费 / 日预算
偏差 = 实际累计花费率 - 当前时间对应的理想累计花费率
```

判断：

| 判断 | 条件 |
|---|---|
| 过快 | 实际累计花费率 > 理想值 + 15% |
| 过慢 | 实际累计花费率 < 理想值 - 15% |
| 正常 | 其他情况 |

### 小时节奏动作

| 花费节奏 | 订单表现 | 判断 | 动作 |
|---|---|---|---|
| 过快 | 达标 | 有效流量但预算提前消耗 | 预算充足时可加预算；否则保持并观察耗尽时间 |
| 过快 | 不达标 | 高价低效流量提前消耗预算 | 不加预算；查搜索词、Bid、广告位；优先降低效位置和高花费无单词 |
| 正常 | 达标 | 投放健康 | 保持 |
| 正常 | 不达标 | 节奏不是主因，可能是转化或流量质量问题 | 查搜索词、Listing、广告位和商品承接 |
| 过慢 | 达标 | 小流量高效率 | 小幅提高 Bid 或增加优质广告位溢价 |
| 过慢 | 不达标 | 需求、竞价或相关性不足 | 查曝光、点击率、入口规模和关键词相关性 |

## Bid 与策略诊断

| 数据表现 | 判断 | 动作 |
|---|---|---|
| 曝光少，历史转化好 | 竞价不足 | 提高 Bid，受单次调整上限约束 |
| 曝光多，点击少 | 相关性或 Listing 吸引力不足 | 不盲目提高 Bid |
| 点击达到门槛，无订单 | 流量低效 | 降 Bid 或否定 |
| 订单稳定，CPA 达标 | Bid 合理 | 保持或小幅拓量 |
| 订单稳定，CPA 超标 | 成本偏高 | 小幅降低 Bid |
| 花费过快且订单不足 | 抢量过度 | 降 Bid 或改为动态仅降低 |
| 花费过慢且效果良好 | 流量获取不足 | 提高 Bid 或优质广告位溢价 |

## 广告位诊断规则

广告位诊断不是每次都执行。必须先判断整体活动效果。

### 是否进入广告位诊断

1. 若整体广告效果达到标准值：
   - 不分析广告位。
   - 不因为某个广告位 ACOS、CPA、CVR 短期波动就调整溢价。
   - 动作：保持当前广告位结构，继续观察。

2. 若整体广告效果未达到标准值：
   - 再进入广告位分析。
   - 目标是减少表现差的广告位花费比例，增加表现好的广告位花费比例。
   - 不允许只看 TOS / ROS / PP 单点数据就调整，必须结合整体活动效果。

### 广告位好坏判断

每个广告位分别看：

- 花费占比
- 订单
- ACOS
- CPA
- CVR
- 点击样本
- 是否达到样本门槛

判断：

| 广告位状态 | 判定 | 动作 |
|---|---|---|
| 表现好且花费占比低 | 有效流量拿得不够 | 增加该位置溢价，或小幅提高基础 Bid |
| 表现好且花费占比正常 | 当前结构健康 | 保持 |
| 表现差且花费占比高 | 低效位置消耗预算 | 降低该位置溢价，必要时降到 0 |
| 样本不足 | 不能判断 | 保持观察，不强调 |
| 整体活动效果已达标 | 不进入广告位优化 | 保持，不拆广告位 |

### 如何控制不同广告位花费

| 目标 | 控制方式 |
|---|---|
| 想要更多 TOS 花费 | 增加 TOS 位置溢价，或提高基础 Bid |
| 想要更多 ROS 花费 | 增加 ROS 位置溢价，或提高基础 Bid |
| 想要更多 PP 花费 | 降低基础 Bid，并把 TOS / ROS 溢价降到 0 |
| PP 表现好，其他位置也好 | 不需要调整 |
| TOS / ROS 表现差，PP 表现好 | 降低基础 Bid；TOS / ROS 溢价降到 0；保留 PP 获取能力 |
| TOS 表现好，ROS / PP 差 | 提高 TOS 溢价；降低 ROS / PP 溢价 |
| ROS 表现好，TOS / PP 差 | 提高 ROS 溢价；降低 TOS 溢价，基础 Bid 不盲目提高 |

提高基础 Bid 会同时影响多个广告位，不是精准控制单一位置。只有位置溢价才能更直接控制 TOS / ROS。

## 广告商品诊断

广告商品层必须看 ASIN/SKU、父子体、尺寸、花费、订单、ACOS、CVR、CPA、CTR、变体表现。

判断方向：

- 效果差的商品优先暂停或换品。
- 效果好的商品不提出拆分重建建议。
- 同一广告组内商品表现差异大时，才考虑拆分或合并。
- 样本不足时只能观察。

## 搜索词与词根诊断

搜索词再投放、词根聚合、ABA 匹配的细则见：

`agents/search-term-reinvestment.md`

核心老品规则：

- 单搜索词：定位匹配、跨周期重复成交、CPA/CVR 稳定；单搜索词根点击 `>=20`、订单 `>=2`，且 CPA <= 链接近 7/14 天平均 CPA 阈值，可拉词组/广泛。
- 词根聚合：按照 Amazon Broad / Phrase 匹配逻辑聚合，保留原始搜索词回溯。
- 单词差、词根好：投词根，精准否定该差词；按 ABA 排名决定单独投放、合并投放或并入老广告组并增加预算。
- 高花费无订单：花费达到停止线后降 Bid 或否定。
- 不相关词：属性或意图与产品冲突时直接否定。
- 样本不足词：保留观察，不做强动作。

## 趋势判断：3/7/14/30 天

趋势判断用于判断消耗速度、效果趋势和异常。当前版本不使用 1 天数据做趋势判断，避免单日波动误导动作。

### 指标方向标准

为了避免 ACOS、CPA、CVR 方向相反，趋势判断统一使用“表现变好 / 表现变差”：

| 指标 | 变好 | 变差 |
|---|---|---|
| ACOS | 下降 | 上升 |
| CPA | 下降 | 上升 |
| CVR | 上升 | 下降 |

只要 ACOS、CPA、CVR 任一指标满足趋势条件，即可标记对应趋势，但输出时必须写明是哪一个指标触发，并调用 `category data thresholds.md` 判断该指标是否达标。

### 趋势状态

| 状态 | 判定条件 |
|---|---|
| 持续好 | 3 天、7 天、14 天均达到标准值，且各周期变化幅度 `<= +/-10%` |
| 近期转差 | 3 天表现较 7 天变差 `>10%`，但 14 天、30 天仍稳定 |
| 连续恶化 | 3 天、7 天、14 天连续变差，累计变差幅度 `>15%` |
| 恢复 | 3 天优于 7 天，7 天优于 14 天，连续改善幅度 `>10%` |
| 震荡 | 各周期涨跌无明显方向，波动率 `>20%` |

### 趋势动作

| 趋势 | 动作 |
|---|---|
| 持续好 | 保持；如果订单不足，再看预算、Bid、广告位是否限制放量 |
| 近期转差 | 查最近 3 天变化原因：价格、库存、竞品、排名、搜索词、广告位 |
| 连续恶化 | 达到样本门槛后，允许降 Bid、降溢价、否定低效词、收缩预算或暂停 |
| 恢复 | 不急于大幅加预算；先观察是否稳定，再小幅恢复 Bid 或预算 |
| 震荡 | 不做强动作；延长观察周期，优先检查样本量和流量结构是否混乱 |

## 结构诊断

- 自动、广泛、词组混在同一结构且无法归因时，效果差的类型优先关闭，最后才考虑拆分重建。
- 效果好的类型不提出拆分重建建议。
- 同一关键词在多个相同目的广告组重复投放时，标记内部竞争并提出合并或隔离。
- 预算过度分散、类型混装、无法归因时，才考虑重建。

## 数据聚合层级

必须至少能说明使用了哪些层级：

- 产品层：ASIN / SKU，用于判断产品目标、总广告效率和预算空间。
- Campaign 层：用于判断预算、目标和竞价策略。
- 广告组层：用于判断结构、类型和内部竞争。
- 投放对象层：Keyword / Target ASIN，用于判断 Bid、迁移、保留或暂停。
- 买家搜索词层：用于发现真实流量、词根和否定词。
- 广告位层：TOS / ROS / PP，用于判断溢价和流量位置。

如果缺少当前链接自己的搜索词、Campaign、广告组、广告位、预算、Bid 或趋势报表，不得用类目历史出单词库补位生成老品优化方案；只能输出“缺少老品诊断源数据”，并可另行输出“基于类目历史的选词参考”。
- 时间层：小时 + 3/7/14/30 天，用于判断消耗速度、趋势和异常。

## 最终执行顺序

1. 先决定保留什么：保留目标清晰、数据可解释、效果稳定的广告。
2. 再决定优化什么：对预算、Bid、竞价策略、广告位和投放对象进行局部调整。
3. 最后决定新增或重建什么：解决流量入口缺失、结构混装、预算分散和关键词内部竞争。
4. 输出风险与审批级别：暂停、大幅降预算或超配置上限的操作必须人工审核。
