# AGENT: AGENTS 目录与输入清单

当用户输入：

```text
AGENTS 目录
```

必须读取并展示本文件，清晰说明每个 AGENT 能带来什么结果、用户需要输入什么、需要维护什么基础数据、缺失数据会造成什么影响。

新增、删除、改名或调整任何 AGENT 时，必须同步更新本文件。

## 总览

| 层级 | AGENT | 核心结果 | 标准输入表 / 信息 | 基础数据 | 缺失后影响 |
|---|---|---|---|---|---|
| 总入口 | `AGENTS.md` | 判断该调用哪个子 AGENT | `任务说明`、产品阶段、新品/老品/ABA/历史词/阈值/输出类型 | 子 AGENT 路由、默认 ABA 路径、历史词路径 | 只能先问清任务类型，不能直接判断 |
| 目录 | `agents/agents-directory.md` | 展示所有 AGENT 的能力、输入、基础数据和缺失影响 | 用户输入 `AGENTS 目录` | 本文件随 AGENT 增删改同步维护 | 目录会过期，用户不知道该导入什么 |
| 新品推广 | `agents/new-product-promotion.md` | 新品选词 + 新广告架构 | 见“新品标准输入” | ABA 表、历史出单词、产品属性 | 缺属性会降级为人工确认 |
| 老品推广 | `agents/old-product-promotion.md` | 老广告优化 + 新广告建议 | 见“老品标准导入表” | 当前真实广告报表、阈值、业务目标 | 缺必需表不能给完整后台动作 |
| 搜索词再投放 | `agents/search-term-reinvestment.md` | 出单词、词根、否词、迁移、放大 | 见“搜索词再投放输入表” | 当前搜索词、ABA、阈值 | 没当前链接数据只能做候选词参考 |
| ABA 类目流量 | `agents/category-traffic-strategy.md` | 判断多入口/少入口、头部集中/分散、打法 | 见“ABA 流量结构输入表” | ABA、竞对词表、Top ASIN/点击份额 | 只能判断类目打法，不等于产品选词 |
| 类目历史词 | `agents/category-history-data.md` | 固定历史出单词库，给新品/新广告参考 | 见“历史词入库输入表” | `raw/`、`normalized/`、`metadata.md` | 不能作为老品当前诊断数据 |
| 品类阈值 | `agents/category data thresholds.md` | 给 ACOS/CPA/CVR/点击/花费风险标准 | 见“阈值输入表” | 类目/型号/尺寸阈值 | 没对应类目不能强判 |
| 输出模板 | `agents/promo-output-templates.md` | 固定导出字段和表格格式 | 输出类型 + 上游判断结果 | 模板字段规则 | 只控格式，不做业务判断 |

## 新品标准输入

| 优先级 | 标准名称 | 必填字段 | 用途 | 缺失影响 |
|---|---|---|---|---|
| 必须 | `新品产品信息表` | ASIN/SKU、类目、产品类型、尺寸/容量、颜色、材质、功能、场景、风格、人群/宠物 | 判断产品能承接哪些 ABA 入口 | 缺属性会导致选词不准，只能标“待确认” |
| 必须 | `新品预算与目标表` | 日预算、目标订单阶段、是否冷启动、目标 ACOS/CPA 如有 | 判断选词层级、广告组数量和预算分配 | 无预算时 Bid/预算写“待人工配置” |
| 必须/默认 | `ABA类目词库表` | 搜索词、ABA 排名、类目、标签、合规状态、推荐层级 | 新品选词主数据 | 没 ABA 只能按历史词或人工词低置信判断 |
| 建议 | `类目历史出单词表` | 搜索词、点击、花费、订单、销售额、来源产品 | 优先引用同类有效词 | 没有则按 ABA + 产品属性低预算验证 |
| 标品建议/必要 | `竞对词表` | 竞品 ASIN、关键词、来源位置、覆盖 ASIN 数、出现频次 | 标品判断流量层和共用词 | 标品缺竞对词表，流量层判断不完整 |
| 可选 | `人工排除/合规词表` | 品牌词、侵权词、促销价格词、不相关词 | 排除风险词 | 风险词可能混入候选池 |

新品默认输出：

| 表名 | 内容 |
|---|---|
| `ABA选词表` | ABA 等级、搜索词、词根、排名、标签、推荐动作、匹配方式、原因 |
| `新广告设置表` | 广告组名称、ASIN、预算、Bid、投放策略、投放词、精准否定词、判断依据 |

## 老品标准导入表

| 优先级 | 标准报表名称 | 用途 | 缺失影响 |
|---|---|---|---|
| 必须 | `SP搜索词-按词-每日明细` | 近 3 天 CVR、出单词、浪费词、词根聚合、放大判断、精准否定 | 无法判断近 3 天趋势和是否可放大 |
| 必须 | `SP搜索词-按词-汇总` | 完整周期累计表现，与每日明细互相校验 | 可汇总替代，但稳定性下降 |
| 必须 | `SP投放对象 / 关键词 / 商品投放报告` | 投放词、投放 ASIN、匹配方式、Bid、花费、订单、销售额 | 无法给投放对象级动作 |
| 必须 | `SP广告位报告` | TOS / ROS / PP 花费、订单、ACOS、CVR、溢价判断 | 无法判断广告位溢价是否合理 |
| 必须 | `SP广告商品报告` | ASIN/SKU/变体花费、订单、ACOS、CVR、CPA | 无法判断变体拆分、暂停、合并、防守 |
| 必须 | `Campaign / Ad Group 设置表` | 预算、状态、竞价策略、默认 Bid、TOS/ROS/PP 溢价 | 只能判断方向，不能输出后台可执行动作 |
| 建议 | `SP广告位-每日明细` | 1/3/7/14/30 天广告位趋势 | 只能看汇总，短期变化不清 |
| 建议 | `SP关键词-每日明细` | 老投放词本身趋势 | 难判断投放词是否保留/调 Bid |
| 建议 | `小时预算 / 小时花费报告` | 预算消耗速度、时段浪费 | 无法判断过快/过慢 |
| 建议 | `商品业务数据 / 订单目标 / 利润信息` | 目标 ACOS/CPA、售价、毛利、库存、Coupon、Review | 只能做广告内部优化，不能判断是否值得放量 |

## 搜索词再投放输入表

| 优先级 | 标准名称 | 必填字段 | 用途 |
|---|---|---|---|
| 必须 | `SP搜索词-按词-每日明细` | 日期、Campaign、Ad Group、搜索词、点击、花费、订单、销售额 | 判断近 3 天趋势和可放大 |
| 必须 | `SP搜索词-按词-汇总` | 搜索词、点击、花费、订单、销售额、ACOS/CVR/CPA | 判断累计表现 |
| 必须 | `SP投放对象 / 关键词 / 商品投放报告` | 投放词、匹配方式、Bid、花费、订单 | 判断迁移、保留、降 Bid、暂停 |
| 建议 | `ABA类目词库表` | 搜索词、ABA 排名、类目、标签 | 判断词根流量等级 |
| 建议 | `品类阈值标准` | ACOS/CPA/CVR、点击无单线、花费无单线 | 判断词是否达标 |

输出：

| 表名 | 内容 |
|---|---|
| `搜索词词根聚合表` | 词根、ABA 等级、点击、订单、花费、ACOS、CVR、CPA |
| `再投放动作表` | Exact/Phrase/Broad、迁移、保留、降 Bid、否定 |
| `否词清单` | Negative Exact 为主，标明原 Campaign / Ad Group |

## ABA 流量结构输入表

| 优先级 | 标准名称 | 必填字段 | 用途 |
|---|---|---|---|
| 必须 | `ABA类目词库表` | 搜索词、搜索频率排名/ABA 排名 | 计算入口数量 N、Top 排名、滑动梯度 G |
| 必须 | `类目定义信息` | 类目核心词、标品/半标品/非标品 | 定义相关性和判断方法 |
| 建议 | `ABA点击份额表` | Top ASIN、Top 品牌、Top 品类、点击份额 | 判断头部垄断和流量归属 |
| 标品必须/非标可选 | `竞对词表` | 竞品 ASIN、关键词、来源、覆盖 ASIN 数、出现频次 | 标品判断 L1-L5 流量层 |
| 可选 | `产品属性信息` | 尺寸、颜色、材质、功能、场景 | 从类目打法进入产品打法时使用 |

输出：

| 表名 | 内容 |
|---|---|
| `类目流量结构表` | N_core、N_accessory、N_competitor、N_adjacent、Top 排名、G |
| `流量层判断表` | 多入口/少入口、头部集中/排名平滑、标品 L1-L5 |
| `类目打法建议表` | 推荐打法、不建议打法、数据置信度 |

## 历史词入库输入表

| 优先级 | 标准名称 | 必填字段 | 用途 |
|---|---|---|---|
| 必须 | `原始历史搜索词报表` | 搜索词、点击、花费、广告订单、来源文件 | 入库 raw，提取历史出单词 |
| 必须 | `类目登记信息` | 类目、子类目、产品形态、来源产品、日期范围 | 判断能否归入对应类目 |
| 建议 | `来源产品信息表` | 来源 ASIN/SKU、容量/尺寸/材质/场景 | 判断是否适合同类复用 |
| 建议 | `历史表现字段` | 销售额、ACOS、CVR、CPA、Campaign、Ad Group | 提高数据置信度 |

固定存放：

| 目录 | 内容 |
|---|---|
| `reference/category-history/<category>/raw/` | 原始报表 |
| `reference/category-history/<category>/normalized/` | 标准化历史词表 |
| `reference/category-history/<category>/metadata.md` | 数据说明、时间范围、适用边界 |

## 品类阈值输入表

| 优先级 | 标准名称 | 必填字段 | 用途 |
|---|---|---|---|
| 必须 | `品类阈值标准表` | 类目、型号/尺寸、CVR、ACOS、CPA、点击<2单、花费<2单 | 判断优质/正常/警戒/高风险 |
| 必须 | `产品类目信息` | 类目、型号、尺寸，如 10L、5L、2x5、5x7、8x10 | 选择正确阈值 |
| 建议 | `阈值来源文件` | 来源文档、截图、更新时间 | 避免阈值来源不明 |

输出：

| 表名 | 内容 |
|---|---|
| `阈值调用结果` | 当前类目适用哪套 ACOS/CPA/CVR 标准 |
| `风险判断说明` | 为什么是优质/正常/警戒/高风险 |

## 输出模板输入表

| 优先级 | 标准名称 | 内容 | 用途 |
|---|---|---|---|
| 必须 | `输出任务说明` | 新品方案 / 老品优化 / 搜索词报告 / ABA 打法 / 缺失数据说明 | 决定输出模板 |
| 必须 | `上游判断结果` | 来自新品、老品、搜索词、ABA、历史词、阈值模块 | 填充表格 |
| 可选 | `导出格式要求` | xlsx、表名、字段顺序、是否需要预览 | 控制最终交付格式 |

固定输出规则：

| 场景 | 默认输出 |
|---|---|
| 新品推广 | `.xlsx`，只含 `ABA选词表`、`新广告设置表` |
| 老品推广 | 老广告优化表 + 新广告设置表 + 必要摘要 |
| 搜索词再投放 | 词根聚合表 + 动作表 + 否词清单 |
| ABA 类目打法 | 类目流量结构表 + 流量层判断表 |
| 缺失数据说明 | 缺失表名、影响、是否可降级判断 |
