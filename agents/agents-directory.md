# AGENT: AGENTS 目录与输入清单

当用户输入：

```text
AGENTS 目录
```

必须读取并展示本文件。默认只展示下面这一张总表，用一张表说明每个 AGENT 能带来什么结果、用户需要输入什么、需要维护什么基础数据、缺失数据会造成什么影响。

新增、删除、改名或调整任何 AGENT 时，必须同步更新本文件，并继续保持“一张表说清楚”的结构。
