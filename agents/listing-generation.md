# Listing 生成流程

每次生成或审核 Amazon Listing，都按这个流程走。

## 输入处理

只能从用户提示、上传图片、上传词库 / 风险库、现有项目数据中收集或推断：

- 品牌
- 产品类型
- 尺寸 / 规格 / 容量
- 厚度或绒高，适用于地毯
- 颜色
- 图案或视觉元素，适用于地毯等有图案产品
- 风格
- 已确认卖点
- 目标用户或目标宠物
- 使用场景
- 站点，默认 Amazon US
- 图片中可确认的产品事实

缺关键输入时，保守假设，并写入 `Needs manual confirmation`。不能编造。

## 图片使用规则

图片只能用来确认可见事实：

- 产品类型
- 颜色大类
- 可见纹理
- 形状
- 场景
- 可见配件

不能只凭图片推断：

- 材质
- 认证
- 安全性
- 清洁方式
- 精确尺寸
- 电池容量
- 续航
- 抗菌 / 杀菌
- 性能
- 保修

用户提供但图片不可见的卖点，可以用，但必须先过风险筛查；需要证明的内容要写进确认项。

## 生成步骤

1. 标准化并筛查所有用户输入。
2. 判断或接受 `productCategory`。
3. 只加载对应类目的关键词库和风险库。
4. 按 ABA 和相关性给关键词打分。
5. 移除禁用词、高危词、竞品词、纯配件词、不可证明词。
6. 自然分配关键词：
   - Title：品牌、尺寸 / 规格、核心产品名、短且已确认的属性。
   - Item Highlights：Title 放不下但可搜索的确认事实。
   - Bullets：每条一个主题，每条自然埋 1-3 个安全关键词 root。
   - Description：给买家读的自然文案，不重复堆五点。
   - Search Terms：低风险、高相关、Title 未完整覆盖的 root。
7. 运行确定性审核。
8. 失败模块必须重写后再输出。

## 关键词评分

关键词库是候选池，不是自动文案。

默认评分：

- ABA 排名权重：40%。
- 产品相关性权重：60%。
- ABA rank 越低，流量越强。
- 相关性看产品类型、尺寸 / 规格、类目、目标用户、确认卖点、场景、颜色、图案、材质、适配对象。

以下内容在评分前或输出前排除：

- 禁用词和高危词。
- 竞品品牌和 IP 词。
- ASIN、UPC、EAN。
- 产品不是配件时，排除纯配件搜索词。
- 未确认的材质、护理、功能、认证、健康、安全、保修或性能词。
- 高流量但不相关的词。

## Title 规则

每个产品或变体生成 1 个 Title。

规则：

- 英文最多 75 字符。
- 有意义时尽量 70-75 字符。
- 最多 1 个英文逗号。
- 必须以准确品牌名开头。
- 不使用 `!`、`$`、`?`、`_`、`{}`、`^`、`¬`、`¦`、`|`，除非这些字符属于品牌名。
- 除冠词、介词、连词外，同一词不要重复超过 2 次。
- 禁止关键词堆砌。

类目产品名：

- Rug：`Area Rug`、`Runner Rug`、`Entryway Rug`、`Door Mat`。
- Chair：`Office Chair`、`Desk Chair`、`Gaming Chair`、`Computer Chair`、`Criss Cross Chair`。
- Pet water fountain：`Pet Water Fountain`、`Dog Water Fountain`、`Cat Water Fountain`、`Pet Water Dispenser`。

Title 只放简短且已确认的事实。多数功能细节放到 Item Highlights、五点或描述。

## 五点规则

必须正好 5 条。

每条都要：

- 一个清晰主题。
- 自然埋词。
- 只用产品事实或用户确认且可支撑的卖点。
- 避免排名、保证、保修、医疗、疾病、安全、价格、竞品、不可验证声明。
- 避免机械重复。

## Description 规则

默认 1800-2000 英文字符，除非用户要求更短。

描述必须：

- 给买家正常阅读。
- 包含产品身份、类目、尺寸 / 规格、场景、确认功能、维护 / 使用说明。
- 不写无支撑声明，不堆关键词。
- 不要为了说明“不能写什么”而在 Listing 正文里重复风险词。

## Search Terms 规则

后端 Search Terms：

- 小于 250 UTF-8 bytes。
- 全小写。
- 空格分隔。
- 无逗号、竖线、分号、括号、促销标点。
- 无品牌名。
- 无竞品名。
- 无 ASIN 或 ID。
- 无禁用 / 风险词。
- 无重复 root。
- 优先放安全、高相关、Title 没完整覆盖的词。
