# AGENT: 新品推广选词与广告架构搭建

本 AGENT 用于 Amazon 地毯新品推广阶段的选词、词根归并、ABA 阶段匹配、广告架构搭建和人工审批输出。

新品阶段只输出建议和广告架构表，不直接执行 Amazon Ads API 操作，不自动调预算、Bid、广告位或否词。

## 适用范围

适用：

- 新 ASIN / 新 SKU / 新父体推广。
- 当前链接没有稳定广告数据、搜索词数据、广告位数据和趋势数据。
- 任务目标是新品选词、首轮广告架构搭建、低预算验证、ABA 阶段匹配。

不适用：

- 当前链接已有稳定广告表现，需要判断预算、Bid、广告位、搜索词否定或趋势变化。此时读 `agents/old-product-promotion.md`。
- 任务只做历史出单词再投放和词根聚合。此时同时读 `agents/search-term-reinvestment.md`。

## 新品阈值边界

新品一般没有稳定 CPA / CVR / ACOS 阈值参考，因为它是重新开始推。

只有以下情况可以引用阈值：

1. 用户提供同类历史产品数据，并明确可作为参考。
2. 用户手动给出新品测试目标，如目标 CPA、目标 ACOS、最低 CVR。
3. 当前链接已经有稳定广告数据、搜索词数据、广告位数据和趋势数据，此时应转入 `agents/old-product-promotion.md`，不再按新品模块判断。

没有上述参考时，不能直接用 CPA / CVR / ACOS 判定“高风险 / 不达标 / 暂停”。新品阶段只能输出低预算验证、继续观察、人工确认或不建议投放。

`agents/category data thresholds.md` 不作为新品默认强判标准，只能在用户明确要求、或有同类历史数据对照时辅助参考。

## 输入要求

必须读取或人工确认：

- 主推 SKU / ASIN。
- 父体或链接目标广告订单量。
- 产品类型：室内进门垫 / 长条 / 区域 / 圆形 / 厨房垫 / 浴室垫 / 未识别。
- 场景：living room / bedroom / entryway / hallway / kitchen / bathroom / outdoor 等。
- 尺寸：如 2x3、3x5、5x7、8x10、9x12、runner、round 等。
- 材质、功能、风格、颜色。
- 是否有同类历史成交搜索词。
- 是否有用户指定目标 CPA / ACOS / CVR。

信息缺失时，不要补造属性。输出“待人工确认”，并说明缺失字段会影响哪个判断。

如果用户提供或项目中存在类目历史出单词数据，先读 `agents/category-history-data.md`，再判断这些历史词能否作为当前新品的同类参考。ABA 表和类目历史出单词表必须分开读取，不得把 ABA 词库当作历史出单数据。

## 地毯类型识别

按产品形态优先，其次看场景词、尺寸词和标题词。

- 室内进门垫：`door mat`、`doormat`、`entryway`、`front door`、`welcome mat`、`2x3`、`3x5` 等。
- 长条：`runner`、`hallway`、`corridor`、`stair runner`、`2x5`、`2x6`、`2x8`、`2.5x8` 等。
- 区域：`area rug`、`rug`、`carpet`、`living room`、`bedroom`、`5x7`、`8x10`、`9x12` 等。
- 圆形：`round`、`circle`、`circular`、`oval`、直径尺寸等。
- 厨房垫：`kitchen`、`under sink`、`anti fatigue`、`kitchen mat` 等。
- 浴室垫：`bathroom`、`bath mat`、`shower mat`、`absorbent` 等。

如果产品形态和场景冲突，先按产品形态选主 sheet，再用场景 sheet 辅助。无法判断时标记“未识别”，不得强行归类。

必须读取以下字段：

- `建库类目`

- `详细分类`
- `推荐层级`
- `相关度等级`
- `合规状态`
- `综合优先级`
- `广告用途`
- `否定/隔离类型`
- `尺寸标签`
- `场景标签`
- `功能标签`
- `风格图案标签`
- `颜色标签`
- `材质结构标签`
- `形状标签`
- `搜索量排名`
- `前三点击份额`
- `前三转化份额`

其中 `搜索量排名` 是 ABA 排名。排名越小代表流量越大，但不能因为 ABA 排名高就直接主投。

`综合优先级` 只用于同类型、同阶段、同合规状态下排序，不能替代 ABA 排名，也不能覆盖合规判断。

输出表必须把词的标签合并成一列 `对应标签`。标签来源为 `尺寸标签`、`场景标签`、`功能标签`、`风格图案标签`、`颜色标签`、`材质结构标签`、`形状标签`、`人群宠物标签`。格式为：

`尺寸:8x10；场景:living room；功能:washable, soft；风格:vintage；颜色:neutral`

没有值的标签不写，不要用空标签占位。

## 推荐层级处理

- `P0 核心词`：类目核心词。新品早期不直接高预算主投，必须通过阶段匹配和产品承接能力判断。
- `P1 优先词`：新品优先验证词，适合 Phrase 或拆组测试。
- `P2 扩展词`：适合关键词 Broad / Phrase 小预算扩词；Broad 只能作为关键词匹配方式，不等同于自动广告的 Loose match。
- `P3 观察/否定候选`：不进核心广告，只能隔离观察。
- `风险/隔离`：品牌、竞品、风险词，必须单独复核。
- `P4 完全不相关`：否定候选，不投放。

`合规状态=安全` 才能进入常规广告候选池。促销/价格词、品牌/竞品词、完全不相关词不得混入新品核心广告组。

## 地毯新品阶段 ABA 区间硬过滤

地毯新品广告方案只展示“当前阶段需要投放的词”。不展示阶段外大词、阶段外低相关词、受限测试词、观察词或精准否定候选词。

没有用户提供链接目标广告订单量时，默认按 `0-15 单/日` 新品冷启动阶段处理。

`0-15 单/日` 阶段固定规则：

| 地毯类型 | 可进入输出表的 ABA 排名 | 适合关键词类型 | 最低匹配度 | 最大选词数 |
|---|---:|---|---:|---:|
| Area Rug / 区域地毯 | `>= 60,000` | 长尾词、尺寸词、场景词、属性组合词 | `>=90%` | `5` |
| Runner Rug / 长条地毯 | `>= 50,000` | 长尾词、尺寸词、场景词、属性组合词 | `>=90%` | `5` |

执行优先级：

1. 先判断产品类型和当前订单阶段。
2. 再按该类型的阶段 ABA 区间过滤候选词。
3. 阶段外的词直接剔除，不出现在 `ABA选词表`，也不出现在 `新广告设置表` 的 `投放词 / 词根 / 类目`。
4. 新品广告方案只展示最终需要投放的词；不要为了说明风险而把阶段外词、受限测试词、2 万名以内大词或否定候选词放进输出表。
5. 如果一个商品同时覆盖 Area Rug 和 Runner Rug，例如 `8x10/5x7 + 2x6`，分别按 Area Rug 和 Runner Rug 区间筛选，再按产品匹配度和最大选词数合并输出。
6. `最大选词数` 是首轮投放词上限；如果多尺寸、多类型导致候选词超过上限，优先保留“尺寸 + 类型 + 风格/颜色”同时命中的词，其次保留“尺寸 + 类型”或“类型 + 风格/颜色”词。

`搜索量排名 <= 20000`、低于当前阶段下限、或明显超出阶段承接能力的词，不再因为“风险高”而作为精准否定输出；默认直接不展示。只有用户明确要求输出否词清单时，才单独生成否词表。

## 选词流程

按顺序执行：

1. 确认产品类型、尺寸、场景、功能、风格、颜色。
2. 按类型读取对应 ABA sheet，并用类目 sheet 做补充。
3. 从 `广告词库` 过滤 `P0/P1/P2 + 安全` 词。
4. 从 `否定观察` 排除 `P4`、促销价格词、品牌风险词和不相关词。
5. 用 `词根归并` 把搜索词聚合成规范词根，保留代表词和全部变体。
6. 如果有同类历史成交词，优先从历史出单词根开始，再匹配 ABA。
7. 如果没有历史成交词，则按 ABA 阶段、产品匹配度和低预算测试逻辑选词。
8. 按地毯类型和当前订单阶段做 ABA 区间硬过滤；阶段外词直接剔除，不展示。
9. 对通过阶段 ABA 区间、匹配度和合规过滤的词，按最大选词数输出广告架构，不做自动执行。

不要把“ABA 词根”直接等同于“应该投放的词”。ABA 主要用于判断市场容量、稳定流量和长期排名机会；实际投放优先级必须结合新品阶段、产品匹配、历史成交证据和合规状态。

## 同类历史成交词规则

如果用户提供同类历史成交搜索词，优先级高于通用 ABA。

类目历史出单词固定从 `/Users/leo/Documents/广告智能体 2/reference/category-history/` 读取。读取、入库、字段映射和置信度规则见 `agents/category-history-data.md`。

历史词进入候选池需满足：

- 搜索词与当前新品类型、尺寸、场景或属性相关。
- 不是明显偶然单；优先选择历史订单 `>=2` 或多日期成交词。
- 如果有历史 CVR / CPA / ACOS，只能作为同类历史参考，不能直接当当前新品强判线。
- 若历史词与 ABA 表匹配到 `P4`、品牌风险、促销价格词，必须人工复核，不得直接投放。

没有同类历史数据时，输出“无历史阈值参考”，按 ABA 与产品属性做低预算验证。

## ABA 阶段匹配

用父体或链接目标广告订单量判断阶段，再用 `搜索量排名` 过滤。

| 目标阶段 | 区域 / 门垫 / 圆形参考 | 长条参考 | 选词方向 |
|---|---:|---:|---|
| 0-15 单/日 | 60,000-500,000+ | 50,000-800,000+ | 尺寸词、场景词、属性长尾 |
| 15-30 单/日 | 30,000-180,000 | 20,000-200,000 | 中流量成熟入口 |
| 30-50 单/日 | 8,000-100,000 | 10,000-120,000 | 中高流量排名投资词 |
| 50+ 单/日 | 2,000-60,000 | 2,000-80,000 | 核心词、防守词、放量词 |
| 100+ 单/日 | 500-30,000 | 500-50,000 | 头部词、类目词、竞品词隔离测试 |

新品早期不要因为 `outdoor rug`、`bathroom rugs`、`rug` 这类 ABA 排名高的词流量大就直接主投。高流量词如果不在当前阶段 ABA 区间内，直接从新品广告方案输出中剔除。

如果某词超出当前阶段流量范围，即使产品匹配强，也不进入首轮广告方案输出；只有用户明确要求“后续升级词 / 否词清单 / 观察词清单”时，才另行输出。

新品执行优先级：阶段 ABA 区间硬过滤高于 `综合优先级`、`推荐层级` 和单项属性匹配。阶段外词不展示、不投放、不混入广告组。

`受限测试` 不属于默认广告方案输出动作。只要一个词的结论是 `受限测试`，默认直接从 `ABA选词表` 和 `新广告设置表` 剔除；只有用户明确要求“列出受限测试词 / 观察词 / 后续升级词”时，才单独输出。

## 匹配评分

评分只用于排序，不用于替代人工审批。

建议结构：

- 历史证据：0-60 分。有同类历史成交词才计算；无历史数据则标记“无历史参考”，不强行给满分。
- ABA 阶段匹配：0-20 分。依据 `搜索量排名` 是否符合当前目标阶段。
- 产品属性匹配：0-20 分。尺寸、场景、功能、风格、颜色、材质、形状匹配越明确，分数越高。

结论分层：

- 建议投放：历史或 ABA 阶段证据明确，产品属性匹配强，合规安全。默认进入输出表。
- 低预算拓词：通过阶段 ABA 区间、匹配度和合规过滤，但角色是拓词。默认可以进入输出表。
- 受限测试：有一定相关性，但无历史阈值参考、样本弱、ABA 阶段偏大或偏小。默认不进入输出表。
- 继续观察：相关但证据不足。默认不进入输出表。
- 不建议投放：P4、不相关、明显品牌风险、促销价格词、产品属性冲突，或完全超出新品阶段。默认不进入输出表。

## 新品广告架构规则

地毯类目新品阶段允许：

- Phrase
- Broad
- Auto Close

地毯类目新品阶段禁止：

- Auto Loose / 自动宽泛匹配。
- Auto Substitutes。
- Auto Complements。
- ASIN 匹配广告 / ASIN 商品投放，包括竞品 ASIN、自有 ASIN、单 ASIN 定向。
- Product Targeting ASIN 广告组。
- Exact。Exact 只在搜索词已经稳定出单、或产品进入老品优化阶段后再单独承接。

地毯新品首轮方案默认只生成 Phrase、关键词 Broad 和 Auto Close。自动广告只保留紧密匹配 `Close match`，不跑自动宽泛匹配 `Loose match`，也不跑 `Substitutes`、`Complements`。除非用户明确要求测试类目投放，否则不生成 Product Targeting；即使测试类目投放，也只能是类目维度，不能放 ASIN。

结构建议：

- `SP_New_[ASIN]_[类型]_[场景]_Phrase_Verify`
- `SP_New_[ASIN]_[类型]_[场景]_Broad_Expand`
- `SP_New_[ASIN]_Auto_Close`

每个广告组放 3-5 个同入口、同词根或同场景关键词。

Phrase 承接稳定短语和属性长尾。关键词 Broad 用于低 Bid 拓词。Auto 只用 Close match 补充紧密搜索词流量。地毯新品不使用自动 Loose match，也不使用 ASIN 商品投放拓量。

## 关键词 ABA 排名分组规则

新品广告方案给关键词分组时，必须先看单个关键词的 ABA 排名，再决定是否单独建组。

- 单个关键词 `ABA排名 <= 30,000`：该词必须单独建广告组，不得和其他关键词混在同一个广告组里。
- 单个关键词 `30,000 < ABA排名 <= 100,000`：建议按同对象、同词根、同属性放在同一个广告组，每组 `2-5` 个词。
- 单个关键词 `ABA排名 > 100,000`：按同对象、同词根、同属性低预算拓词；如果和更高流量词混组会干扰判断，应单独拆组或只与同层级长尾词合并。

执行细节：

1. `ABA排名 <= 30,000` 的词即使属于同一词根，也要单词单组。
2. `30,000 < ABA排名 <= 100,000` 的词可以合并，但必须语义一致，不能把猫用、狗用、通用宠物、尺寸、材质、颜色等不同入口硬塞在一起。
3. 同一个广告组不能混入不同层级目的明显不同的词，例如核心大词、属性词、容量词和拓词词根混在一起。
4. 如果预算不足以承载所有单独广告组，优先保留匹配度最高、产品承接最强的 `ABA排名 <= 30,000` 词；不要为了省广告组数量而违反单词单组规则。

## 匹配方式规则

推荐 Phrase：

- 词序稳定。
- 搜索词围绕同一个短语扩展。
- 适合尺寸词、场景词、功能词组合。
- ABA 表 `广告用途` 为“优先词组投放；新品阶段不优先精准”。

推荐关键词 Broad：

- 用户表达分散，修饰词位置不固定。
- ABA 表 `广告用途` 为“广泛或同词根合并低预算测试”。
- 关键词 Broad 只能低 Bid、小预算拓词，不承担主预算收割。
- 输出表中可以写 `Broad` 或 `Phrase + Broad`，但必须明确这是关键词匹配，不是 Auto Loose。

禁止自动宽泛：

- 地毯新品自动广告只保留 `Close match`。
- 不生成 `Auto Loose`、`Loose match`、自动宽泛匹配。
- 不生成 `Auto Substitutes` 或 `Auto Complements`。

禁止 ASIN 匹配广告：

- 地毯新品方案中，不生成竞品 ASIN、自有 ASIN、单 ASIN 定向广告组。
- 输出表中 `投放策略` 不得写 `Product Targeting ASIN`、`ASIN Targeting`、`竞品 ASIN`、`自有 ASIN`。
- 输出表中 `投放词 / 词根 / 类目` 不得放具体 ASIN。

不推荐 Exact：

- 新品无稳定搜索词表现。
- 没有足够广告订单和转化稳定性。
- 只是因为词精准，不足以建立 Exact。

## 否定与隔离边界

新品首轮不要因为短期点击无单就激进否词。否词必须结合样本量、相关性和是否属于 P4 / 风险词。

可直接排除且默认不展示：

- 阶段 ABA 区间外的新品候选词。
- 结论为 `受限测试` 的候选词。
- `推荐层级=P4 完全不相关`。
- `否定/隔离类型=完全不相关否定`。
- 明显非地毯品类、配件、清洁工具、耗材等无关词。

必须隔离复核：

- 品牌/竞品词。
- 促销/价格词。
- `P3 观察/否定候选`。
- ABA 表里标记风险或隔离的词。

### 新品精准否定规则

新品方案里的 `精准否定词` 不是“不相关词清单”，只能用于已投放词的 `Negative Exact` 隔离。

执行规则：

1. 如果某个词 `A` 已经出现在本方案 `新广告设置表` 的 `投放词 / 词根 / 类目` 中，且 `A` 的 ABA 排名落在当前产品阶段、品类或流量层允许投放的规定范围内，则在该广告组 `精准否定词` 列输出 `A`，表示对该词做 `Negative Exact`。
2. 如果 `A` 没有被本方案投放，即没有出现在 `投放词 / 词根 / 类目` 中，则默认不做精准否定设置。
3. 如果 `A` 被剔除为阶段外词、受限测试词、观察词、配件词、不相关词、品牌/竞品风险词，默认也不写入 `精准否定词`；这些词只做“不展示 / 不投放 / 隔离复核”处理。
4. 如果某个词被投放但 ABA 排名缺失，或无法确认是否在规定范围内，默认不写精准否定，除非用户明确要求人工加入。
5. 只有用户明确要求“输出否词清单”时，才单独生成未投放词的否词表；不得把未投放词混入默认 `新广告设置表` 的 `精准否定词` 列。

例子：

- 投放 `big and tall office chair`，且该词 ABA 排名在当前规定范围内，则 `精准否定词` 可以写 `big and tall office chair`。
- 没有投放 `gaming chair`、`office chair mat`、`office chair wheels`，即使这些词不适合当前产品，也不能在默认 `精准否定词` 列写它们。

新品阶段不要把同词根下个别低表现搜索词直接做 Negative Phrase，避免误杀后续长尾。

## 冲突检查

输出前必须检查：

- 产品类型是否和 ABA sheet 一致。
- 场景、尺寸、功能、颜色是否明显冲突。
- 是否把 P3 / P4 / 风险词混进核心广告组。
- 是否把高流量大词放进新品首轮主预算。
- 是否把当前订单阶段 ABA 区间外的词放进输出表。
- 是否把受限测试词、阶段外词、2 万名以内大词或否词候选词展示在新品广告方案表格里。
- 是否把没有投放的词写进 `新广告设置表` 的 `精准否定词` 列。
- 是否把配件词、不相关词、品牌/竞品风险词当成默认精准否定词，而不是剔除或隔离复核。
- 是否把 `ABA排名 <= 30,000` 的关键词和其他词混在同一个广告组里。
- 是否把 `30,000 < ABA排名 <= 100,000` 的关键词超出 `2-5` 个词强行合并，或与语义不一致的词混组。
- 是否在地毯新品方案的自动广告中生成了 Auto Loose / 自动宽泛匹配。
- 是否在地毯新品方案中生成了 Auto Substitutes / Auto Complements。
- 是否在地毯新品方案中生成了 ASIN 匹配广告、竞品 ASIN、自有 ASIN 或单 ASIN 定向。
- 是否在新品阶段创建了 Exact。
- 是否错误调用 `category data thresholds.md` 做新品强判。
- 是否把无历史阈值的 CPA / CVR / ACOS 写成确定性结论。

命中冲突时，输出人工确认，不直接给执行动作。

## 输出要求

新品推广方案默认必须导出表格文件，不能只在对话里给口头方案。用户说“给我广告方案 / 输出广告方案 / 导出方案”时，默认生成 `.xlsx`。

新品推广方案只输出 2 张核心表：

1. `ABA选词表`
2. `新广告设置表`

不要额外输出 `策略摘要表`、`人工确认表`、`来源说明表`。必要的策略、缺失数据、人工确认事项，合并写入两张核心表的 `判断依据 / 备注` 字段。

必须在 `ABA选词表` 下方追加一段 `判断依据与设计逻辑`。该说明只用自然段，不新增表格、不新增 sheet，内容必须说明：

- 本次使用的 ABA 表、产品属性、历史出单词、竞对词或类目流量层证据。
- 当前新品阶段和 ABA 区间如何影响选词。
- 为什么这样拆广告组、选择 Phrase / Broad / Auto Close、设置预算和 Bid。
- 为什么没有选择阶段外词、受限测试词、ASIN 投放、自动宽泛匹配或 Exact。

说明段必须把关键判断按来源标注清楚：

- `【流量结构打法】`：说明是否调用类目流量结构、竞对词表或 ABA 入口层判断，以及它影响了哪些广告组或预算分配。
- `【历史数据】`：说明是否调用同类历史出单词；如果调用，只能作为选词参考和可复用词证据，不能当作当前新品已验证表现。
- `【用户固定规则】`：说明哪些结论来自已固定规则，例如地毯自动广告只保留 Close、不输出 ASIN 投放、ABA<=3W 单词单组、3W-10W 词 2-5 个合组、新品精准否定边界。
- `【ABA/产品属性】`：说明 ABA 排名区间、sheet 映射和产品尺寸 / 颜色 / 风格 / 容量 / 材质 / 人群宠物匹配如何决定最终投放词。
- `【人工输入/预算目标】`：说明用户给定预算、产品定位、目标阶段如何影响预算、Bid 和验证强度。
- `【缺失数据】`：说明没有提供的证据，例如无历史数据、无竞对词表、无目标 ACOS / CPA 时，哪些结论只能做低预算验证或待人工确认。

如果用户明确要求“先预览、不导出”，才可以在对话里输出 Markdown 表格；否则默认给 Excel 表格文件。

### 1. ABA 选词表

字段：

- ABA等级
- 机会类型
- 综合分
- 搜索词
- 规范词根
- ABA排名
- 匹配 ABA 词
- 来源 sheet
- 建库类目
- 地毯类型
- 对应标签
- 推荐层级
- 相关度等级
- 合规状态
- 广告用途
- 产品匹配点
- 建议动作
- 建议匹配方式
- 精准否定
- 原因

`对应标签` 必须合并输出该词在 ABA 表中的全部可用标签，包括尺寸、场景、功能、风格图案、颜色、材质结构、形状、人群宠物。

`精准否定` 列必须明确：

- 新品广告方案默认只展示投放词，因此写 `否`。
- 受限测试词、阶段外词、2 万名以内大词和否定候选词不进入本表。
- `ABA选词表` 不承载未投放词的否词清单；只有用户明确要求输出否词清单时，才另行输出 `Negative Exact`。

### 2. 新广告设置表

字段：

- 广告组名称
- ASIN
- 类型：新增广告组 / 加入原组 / 重建 / 不新建
- 预算
- Bid
- 投放策略
- TOS / ROS / PP
- 投放词 / 词根 / 类目
- 精准否定词
- 判断依据

没有明确预算和 Bid 边界时，写“待人工配置”，不要编数。

`精准否定词` 列执行新品精准否定规则：

- 只允许填写本方案已经投放、且 ABA 排名在当前规定范围内的词。
- 没有被投放的词，不得写入 `精准否定词`。
- 配件词、不相关词、阶段外词、品牌/竞品风险词默认剔除或隔离复核，不作为默认精准否定词。
- 如果本广告组没有符合条件的已投放词，写 `无` 或留空。

## 判断禁区

- 不要把 ABA 排名高等同于新品应该主投。
- 不要把当前订单阶段 ABA 区间外的词放进新品广告方案输出表。
- 不要在新品广告方案默认输出里展示受限测试词、阶段外词、2 万名以内大词或否定候选词；只展示需要投放的词。
- 不要把未投放词写进 `精准否定词` 列；精准否定只针对已投放且排名在规定范围内的词。
- 不要把 `综合优先级` 当成唯一排序依据。
- 不要把所有地毯类型混用同一个 ABA sheet。
- 地毯新品关键词广告可以输出 Broad，但自动广告只能输出 Auto Close。
- 地毯新品不要输出 Auto Loose / 自动宽泛匹配。
- 地毯新品不要输出 Auto Substitutes / Auto Complements。
- 地毯新品不要输出 ASIN 匹配广告、竞品 ASIN、自有 ASIN 或单 ASIN 定向。
- 不要在新品阶段默认建 Exact。
- 不要用新品短期 CPA / CVR / ACOS 直接判死。
- 不要把 `category data thresholds.md` 当成新品默认阈值。
- 不要把促销/价格词、品牌/竞品词、P4 词混进核心广告组。
- 不要把历史同类数据当成当前 ASIN 的确定表现，只能作为参考证据。
