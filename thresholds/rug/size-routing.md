# Rug 尺寸与类型路由

- 状态：`HUMAN_RULE_FIXED`
- 来源参考：`reference/rug-aba/area_rug_ABA关键词库_202605_v8.xlsx` 的 `广告词库`。

## 标准化

1. `×`、方向颠倒和空格统一成短边在前的 `AxB`。
2. 明确 round / circle / circular / oval 时先判圆形。
3. `2x4`、`3x6`、`3x7`、`4x10`、`4x12` 固定归长条。
4. 短边为 `2.5` 且长边更大的矩形固定归长条。
5. 父体多尺寸必须逐尺寸路由。

## 固定映射

- 门垫：`2x3`。
- 长条：`2x4`、`2x5`、`2x6`、`2x7`、`2x8`、`2x9`、`2x10`、`2x12`、`2x14`、所有 `2.5xN` 矩形、`3x6`、`3x7`、`3x8`、`3x9`、`3x10`、`3x12`、`3x20`、`4x10`、`4x12`。
- 圆形：明确标注圆形的直径尺寸，包括 `3ft` 至 `10ft round`。
- 区域：当前 ABA 映射中除门垫、长条和圆形外的矩形尺寸。

## 区域阈值档案

- 面积 `<=57.5 ft²`：`area_small`。
- 面积 `>57.5 ft²`：`area_large`。
- 未命中或单位无法换算：`BLOCKED`。

圆形没有性能阈值，不能借用区域档案。
