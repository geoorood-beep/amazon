# Rug 流量结构与搜索词评分阈值

- 状态：`HUMAN_RULE_FIXED / MACHINE_NOT_ACTIVE`
- 机器 Threshold ID：`PENDING`

## 类目入口数量

| N_core | 分类 |
|---:|---|
| `<150` | 入口少 |
| `150-500` | 入口中等 |
| `>500` | 入口多 |

## 滑动排名梯度

```text
G = 第4-6个 N_core 词 ABA 排名合计 / 第1-3个 N_core 词 ABA 排名合计
```

- `G>3.5`：头部集中；
- `G<=3.5`：排名平滑；
- `N_core<6`：样本不足，不能计算 G。

## 常规机会综合分

总分 `100`：稳定流量 `32` + 转化验证 `36` + 效率机会 `32`。

- 稳定流量：ABA 排名 `22` + 点击样本 `10`；
- 转化验证：订单 `18` + CVR `12` + 样本密度 `6`；
- 效率机会：ACOS `24` + CVR 加分 `8`。

| 分数 | 等级 |
|---:|---|
| `80-100` | 强优先级 |
| `65-79` | 高优先级 |
| `50-64` | 控 Bid 验证 |
| `35-49` | 低预算观察 |
| `<35` | 不做主投，战略防守除外 |

## 当前链接历史词根优化分

资格要求包括可追溯当前链接、完整转化指标、对应 Rug 阈值存在且聚合订单 `>=2`。

```text
历史词根优化分 = 订单验证40 + CVR达标30 + ACOS达标30
```

订单：`>=4` 单得 `40`；`3` 单得 `32`；`2` 单得 `24`。

CVR / ACOS：优质 `30`；正常 `22`；警戒 `8`；高风险 `0`。

| 分数 | 词根层权限 |
|---:|---|
| `85-100` | 优质保留 / Phrase 候选；完整搜索词达标时可列 Exact 候选 |
| `65-84` | 达标保留 / Phrase 候选，待对象映射 |
| `50-64` | 控制观察或 Broad 低预算候选 |
| `0-49` | 只在同时命中有效停止线时列限流/否定候选，待映射 |

## 放大预筛

必须同时满足：历史订单 `>=3`、历史点击 `>=30`、近 `3` 天 CVR 不低于正常线、出单花费占比 `>=25%`。缺日期字段时不得判定“可放大”。

## 跨广告产品拓量最低证据

当前链接真实报表观察期至少 `7-14` 天；少于 `7` 天只观察。订单 `>=3`、点击 `>=30`，并继续通过当前链接效率、素材和资质检查。类目历史效果词不具备此权限。
