# 亚马逊资料归类仓库

本仓库把原先分散的 4 个亚马逊相关仓库归类到一起。每个子目录对应一个原仓库，并保留完整提交历史。

原仓库均未删除、未归档、也未改动；日常开发仍可继续使用原仓库。本仓库用于集中查阅与归类。

本仓库为私有仓库。

## 子目录

| 子目录 | 原仓库 | 用途 |
|---|---|---|
| `amazon-ads-agents` | [geoorood-beep/amazon-ads-agents](https://github.com/geoorood-beep/amazon-ads-agents) | 亚马逊广告智能体 AGENTS 规则与参考数据（广告智能体 V1.1：规则、固定参考数据、类目历史选词、新品推广辅助） |
| `Listing` | [geoorood-beep/Listing](https://github.com/geoorood-beep/Listing) | Amazon、Walmart 与 Wayfair 的 Listing AGENTS 规则，用于按平台、类目、关键词库和风险库生成合规 Listing |
| `amz-sales-forecast` | [geoorood-beep/amz-sales-forecast](https://github.com/geoorood-beep/amz-sales-forecast) | 亚马逊销量预测智能体说明（由本地「amz预测2.0」转换而来） |
| `luyao-ads-agent-v2` | [geoorood-beep/luyao-ads-agent-v2](https://github.com/geoorood-beep/luyao-ads-agent-v2) | 陆遥广告智能体：地毯类目专用的 Amazon 广告 AGENTS 项目（运行时 V2.1） |
