## 人工修改方法

1. 改数字：只去 `thresholds/README.md` 找对应文件，同时补来源和状态。
2. 改判断：只去 `rules/README.md` 找对应领域或核心规则，数字只引用 Threshold ID。
3. 改表格字段：去 `contracts/README.md`。
4. 改 ABA/历史/报表优先级：去 `knowledge/README.md`。
5. 新增或改名文件：同步 `config/project_scope.json`、目录 README 和 `agents/agents-directory.md`。
6. 运行三个校验器和 pytest；任一失败都不宣称完成。
