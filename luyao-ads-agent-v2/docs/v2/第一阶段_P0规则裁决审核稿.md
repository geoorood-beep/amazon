## 整体状态计算优先级

```text
DATA_BLOCKED
→ DATA_INSUFFICIENT
→ TARGET_CATEGORY_RISK_CONFLICT
→ HIGH_RISK_WITH_VOLUME / HIGH_RISK_WITHOUT_VOLUME
→ EFFICIENT_AT_TARGET
→ EFFICIENT_STRUCTURE_RISK
→ EFFICIENT_UNDERSCALE
→ VOLUME_ACHIEVED_COST_ABOVE_TARGET
→ COST_ABOVE_TARGET_UNDERSCALE
→ INCONCLUSIVE
```

该顺序解决“同一对象同时高效和高风险”“状态为空”“有量高风险仍被叫作低效无量”等问题。

## 启用门槛

1. L-001和L-002必须通过边界、冲突和BLOCK回归测试。
2. 未确认品类不得套用 Rug 已确认区间。
3. 机器执行的唯一规则源决定前，不创建 ACTIVE 规则包。
4. 独立 Validator 通过后，规则才可从 `CONFIRMED_RULE` 进入 `TESTED_ACTIVE`。
5. ACTIVE 切换必须通过版本清单完成，禁止手工同时启用两套机器规则。
