# 合同：Rug 广告架构设计输出

默认导出 `.xlsx`。用户明确说“先预览”时才可只输出 Markdown。

网页必须同时提供可读预览和 `.xlsx` 下载。网页预览只显示 `新广告设置表` 中用户执行和确认所需的 Campaign/广告组、广告 ASIN、匹配方式、投放对象、预算/Bid/Placement、人工确认状态；不得显示内部规则路径、阈值 ID、证据状态或判断过程。完整判断依据保留在下载工作簿中。

## `ABA选词表`

必须包含：

- ABA等级、机会类型、综合分；
- ASIN；多产品任务中每一行必须能回溯到对应产品，不得混合无法归属的关键词；
- 搜索词、规范词根、ABA排名、匹配 ABA 词；
- ASIN 相关性证据状态、相关性等级和来源；
- 完整搜索词月搜索量、词根月搜索量、Top3占比、有效查询数、数据月和来源；
- Phrase/Broad 判定状态；缺表时必须写 `MATCH_TYPE_DATA_PENDING`；
- 来源 ABA 文件、来源 sheet；
- 类目判断、Rug 类型、目标推广尺寸、对应标签；
- 推荐层级、相关度、合规状态、广告用途；
- 产品匹配点、属性冲突检查；
- 建议动作、投放角色、主投状态、建议匹配方式；
- 精准否定、原因。

来源 sheet 必须显示实际读取的 `广告词库`。硬冲突词不得出现在本表。默认只展示实际投放候选；观察、阶段外和否定候选不用本表伪装为投放词。

表格下方必须有自然段 `判断依据与设计逻辑`，不新建 sheet。
一次输入多个 ASIN 时，每个 ASIN 分别追加一段判断依据，工作簿仍固定为两张核心 sheet。

## `新广告设置表`

必须包含：

- Campaign 名称、广告组名称、ASIN；
- 结构模式：新品默认 `SINGLE_ASIN_CONTROL`，明确设计为相关变体发现池时才允许 `MULTI_ASIN_DISCOVERY_POOL`；
- 操作：新增广告组 / 加入原组 / 拆分 / 重建 / 不新建；
- 匹配方式：词组 / 广泛 / Auto Close / 待补数据；
- 预算、Bid、投放策略、TOS / ROS / PP；
- 投放角色/主投；
- 投放词/词根/类目；
- 精准否定词；
- 判断依据。

预算和隔离只引用 `thresholds/`；Bid 或 Placement 参数未确认时写待人工配置。本组主投词不得同时出现在本组精准否定词。

相关性或词根搜索量证据未就绪时，本表固定输出一行“不新建”并说明待补数据，不得以 ABA 排名生成 Phrase/Broad。
