# 合同：新品相关性与搜索量证据

这两张表只为新品 Phrase / Broad 判定提供数据，不保存规则或阈值。

## 相关性表

实际文件放入 `reference/rug-relevance/`。支持 `.csv / .xlsx / .xlsm`。

| 字段 | 必填 | 规则 |
|---|---|---|
| `ASIN` | 是 | 10位 Amazon ASIN；`*` 只能代表经人工审核的全局相关性 |
| `搜索词` | 是 | 保留原词；系统只做小写、空格和基础标点归一 |
| `相关性结论` | 是 | `HIGH / MEDIUM / LOW / IRRELEVANT` 或高度相关/中度相关/低度相关/不相关 |
| `相关性得分` | 否 | `0-100`；只作同结论内排序，不覆盖结论 |
| `判断依据` | 建议 | 产品尺寸、类型、场景、材质、风格等可追溯理由 |

唯一键是 `ASIN + 标准化搜索词`。重复行结论不同时标记 `CONFLICT`，不随机取一行。

## 搜索量表

实际文件放入 `reference/rug-search-volume/`。支持 `.csv / .xlsx / .xlsm`。

| 字段 | 必填 | 规则 |
|---|---|---|
| `搜索词` | 是 | 完整市场查询，不是仅词根 |
| `规范词根` | 是 | 人工或可追溯词根器确认的单一词根 |
| `月份` | 是 | `YYYY-MM`，必须是完整自然月 |
| `月搜索量` | 是 | 非负整数；口径必须是该月市场搜索量 |
| `站点` | 建议 | 默认 `US`；不同 Marketplace 不得合并 |

唯一键是 `站点 + 月份 + 标准化搜索词`。重复键的搜索量或词根不同时整批阻断。

## 与广告搜索词报表的区别

- 本合同的“搜索量表”提供市场需求量和词根分布。
- Amazon `SP搜索词报表` 提供当前链接的曝光、点击、花费、订单和销售额，不等于市场月搜索量。
- 两者后续可联合回放，但不允许互相冒充。
