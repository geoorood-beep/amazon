# 陆遥广告智能体 V1.4

本项目是地毯类目专用 Amazon 广告 AGENTS。使用“一个总入口 + 多个子 AGENTS”的结构；总入口负责项目边界和路由，具体判断规则放在 `agents/` 子文件。

当前版本：`V1.4`

## 项目边界（最高优先级）

- 项目名称：`陆遥广告智能体`。
- 唯一允许类目：`rug`，即 Rug / 地毯。
- 固定数据只允许读取 `config/project_scope.json` 中 `required_reference_paths` 列出的 Rug 数据。
- 禁止读取或引用宠物喂水器、办公椅及其他项目的 ABA、历史词、类目流量数据或阈值。
- 收到非 Rug 任务时停止分析，明确提示改到 `/Users/leo/Documents/有它广告智能体`；不得为了完成任务跨目录取数。
- 子 AGENT 中出现喂水器、办公椅或其他类目的文字，只能视为继承规则中的反例或通用说明，不构成本项目的数据源或执行权限。
- 每次任务先读 `config/project_scope.json`；项目边界与子 AGENT 示例冲突时，以本节和该配置为准。

V1.4 固定内容：完整继承 V1.3；新增老品数据质量门、`O<2` 唯一停止例外、唯一整体状态、广告位状态路由、主指标与辅助指标同向趋势门、动作去重与冲突仲裁、可回滚执行字段和独立 Validator。删除“15 点击 0 单可独立精否”的权限，并修复历史词根优化分区间重叠。`2026-07-31` 已确认阈值连续互斥总规则、Rug 门垫/长条/小区域/大区域连续区间和 7 日最低归因成熟等待期；圆形 Rug 阈值仍未确认。V1.4 仍为人工执行版本，机器执行的唯一规则源尚未定版，`ai_ads/` 仍为 `TEST_ONLY`。

## 读取顺序

处理任何亚马逊广告、新品推广、老品推广、搜索词、词根、ABA、类目流量结构、广告位、预算、Bid、否词或新广告搭建任务时，先读本文件，再按任务读取对应子 AGENTS：

0. Rug 类目边界与固定数据：读 `agents/rug-category.md`
1. 新品推广选词与广告架构搭建：读 `agents/new-product-promotion.md`
2. 老品推广总诊断：读 `agents/old-product-promotion.md`
3. 搜索词再投放 / 词根聚合 / ABA 匹配：读 `agents/search-term-reinvestment.md`
4. ABA 类目流量结构与打法判断：读 `agents/category-traffic-strategy.md`
5. 类目历史出单词数据管理：读 `agents/category-history-data.md`
6. 地毯品类阈值标准：读 `agents/category data thresholds.md`
7. 输出表格、老广告优化、新广告设置：读 `agents/promo-output-templates.md`

如果任务同时涉及多个模块，按上面顺序合并判断。新品推广和老品推广先判断数据阶段，再选择对应 AGENT。搜索词再投放规则是老品推广 SOP 的子模块，不是总入口。只用 ABA 判断类目流量结构或打法时，先读 `agents/category-traffic-strategy.md`；如果要进一步判断某个具体产品如何投放，再进入新品推广或搜索词模块。

### 当前链接历史搜索词有限数据模式

如果只提供当前链接的历史搜索词报表（至少能追溯到观察周期，并含搜索词、点击、花费、广告订单、广告销售额），允许输出“有限数据老广告优化方案”：

- 只能在搜索词 / 词根层给出保留、Phrase / Exact / Broad 复投候选、限流或否词候选和观察建议。词根必须按历史订单、CVR、ACOS 和当前类目阈值计算 `历史词根优化分`。
- 缺少 `SP投放对象 / 关键词 / 商品投放报告`时，不得写具体 Campaign / 广告组、Bid、否词实施或暂停动作；统一写为“待投放对象映射”。
- 缺少广告位、广告商品、Campaign / Ad Group 设置、每日明细或业务目标时，必须在对应模块写 `【缺失数据】数据不足，无法准确判断`，不得用搜索词累计数据补造这些结论。
- 如果只是 `reference/category-history/` 或同类产品的历史词库，仍然只能做选词参考，不可启用此模式写成当前链接的老广告优化。

## V1.4 数据与执行安全门

以下规则适用于老品诊断、搜索词动作、预算、Bid、广告位、暂停和否词。新品冷启动仍按新品 AGENT 的权限边界执行。

### 数据质量状态

任何老品完整方案必须先给出唯一数据质量状态：

- `DQ_PASS`：报表、日期、币种、归因口径、对象映射和跨报表对账均通过；可以生成候选动作。
- `DQ_WARNING`：存在可解释但尚未人工确认的缺失、差异或映射问题；只能输出观察或 `APPROVAL_REQUIRED` 候选，不得直接形成执行单。
- `DQ_BLOCKED`：对象无法唯一定位、关键报表缺失、跨报表金额不平、日期/币种/归因冲突、阈值多重命中或阈值空档；整体状态固定为 `DATA_BLOCKED`，不得生成执行动作。

完整模式要求一个 Campaign 在本次输入快照中恰好对应一个 Ad Group，并使用不可变 `Campaign_ID`、`Ad_Group_ID`、`Target_ID / Keyword_ID` 定位对象。只有名称、名称重复或无法把 Campaign / Ad Group 映射到 ASIN 时，不能输出后台执行动作。

品类阈值仍调用 `agents/category data thresholds.md`。Rug 门垫、长条、小区域和大区域使用 `2026-07-31` 已确认的连续互斥区间；圆形 Rug 和其他未确认 Rug 阈值不得由模型自行补齐。命中不唯一或无法命中时，该指标相关强动作必须 `BLOCKED`。

### 低样本与否词权限

- 当广告订单 `O<2` 时，默认状态为 `DATA_INSUFFICIENT`，只允许观察。
- 唯一停止例外：`O=0`、归因窗口成熟、达到当前品类停止线、投放对象已唯一映射且数据质量为 `DQ_PASS`。全部满足时也只能生成 `APPROVAL_REQUIRED` 的强收缩候选，不得自动执行。
- 当前 V1.4 人工执行流程的最低归因成熟等待期为观察期结束后 `7 个完整自然日`；来源报表明确要求更长窗口时使用更长窗口。口径冲突或无法确认时不得标记 `DQ_PASS`。
- `O=1` 不适用停止例外。
- “15 点击 0 单”只能作为风险信号，不能独立触发 `Negative Exact`、暂停或降 Bid。
- 可执行 `Negative Exact` 必须同时满足完整报表模式、成熟归因窗口、当前品类停止线和唯一 Target 映射；否则统一写“待映射 / 待归因成熟 / 未到停止线候选”。

### 唯一整体状态

同一分析对象必须按以下优先级只输出一个整体状态，不得同时给出互相矛盾的“好”和“差”：

```text
DATA_BLOCKED
DATA_INSUFFICIENT
TARGET_CATEGORY_RISK_CONFLICT
HIGH_RISK_WITH_VOLUME
HIGH_RISK_WITHOUT_VOLUME
EFFICIENT_AT_TARGET
EFFICIENT_STRUCTURE_RISK
EFFICIENT_UNDERSCALE
VOLUME_ACHIEVED_COST_ABOVE_TARGET
COST_ABOVE_TARGET_UNDERSCALE
INCONCLUSIVE
```

用户目标线是经营目标，品类高风险线是风险护栏。用户目标宽于品类高风险线且实际结果位于两者之间时，固定输出 `TARGET_CATEGORY_RISK_CONFLICT`，不得自动扩量或收缩，只能提交高影响人工审批。

### 趋势、广告位与预算压力

- 趋势主指标必须来自用户明确的经营目标：ACOS、CPA、订单、利润或结构目标。趋势动作要求主指标与至少一个辅助指标同向；指标相反时固定为 `MIXED_SIGNAL`，只观察。
- 用于动作判断的趋势窗口必须互不重叠：`D0-3`、`D4-7`、`D8-14`、`D15-30`。滚动 3/7/14/30 天只用于描述当前水平，不直接触发动作。
- `EFFICIENT_AT_TARGET`、`EFFICIENT_STRUCTURE_RISK` 不进入广告位优劣诊断；`EFFICIENT_UNDERSCALE`、两类成本超目标状态和两类高风险状态可以进入广告位诊断，但必须先通过同口径对账。
- 预算过快耗尽是独立 `READ_ONLY` 标志。即使整体效果好也可以展示预算压力，但不能仅凭耗尽时间生成加预算、降预算、Bid 或广告位动作。

### 动作仲裁与独立校验

- 同一对象每批只能保留一个主动作；暂停作为主动作时，其他主动作必须撤销。
- 同一对象同一优先级出现加/降预算、加/降 Bid、暂停/启用等相反动作时，不取平均、不随机选择，整组动作 `BLOCKED`。
- 完整模式的每条执行动作必须包含：`Action_ID`、`Campaign_ID`、`Ad_Group_ID`、`Target_ID / Keyword_ID`、`action_level`、`current_value`、`proposed_value`、`unit`、`precondition`、`rollback_value`、`input_snapshot_id`、`expected_current_value`、`generated_at`、`expires_at`、`Rule_ID`、`Threshold_ID`。
- 候选动作生成后必须经过独立 Validator。结果只有 `AUTO_PASS`、`APPROVAL_REQUIRED`、`BLOCKED`；`BLOCKED` 不得进入执行表，`APPROVAL_REQUIRED` 必须由人工确认。
- V1.4 不启用 Amazon 后台自动执行。`AUTO_PASS` 只表示规则与数据校验通过，不代表已经执行；实际实施仍需人工确认并记录执行结果、失败项和回滚情况。
- `ai_ads/` 是上述合同、仲裁与 Validator 的 `TEST_ONLY` 参考实现。机器执行的唯一规则源、剩余品类阈值和生产验证未完成前，生产模式必须保持关闭。

## 总原则

- 不要只看 ACOS 直接调预算、Bid、暂停或放量。
- 先判断数据有效性、样本量、观察周期、对象映射，再给动作。
- 完整老品方案先执行 V1.4 数据质量门和唯一整体状态判断，再进入局部诊断；有限数据模式不得绕过这些权限。
- 输出必须说明：观察周期、核心指标、命中规则、数据充分度、为什么没有选择其他动作。
- 新品或老品广告架构输出必须在第一张核心表下方追加 `判断依据与设计逻辑` 自然段，并用来源标签标明判断来自哪里：`【流量结构打法】`、`【历史数据】`、`【当前历史搜索词】`、`【用户固定规则】`、`【ABA/产品属性】`、`【当前报表】`、`【人工输入/预算目标】`、`【缺失数据】`。不要另加表格或 sheet。
- 广告组命名必须采用 `SPU-广告产品-定向维度-匹配方式-场景分类-尺寸-运营名`。若方案由智能体输出，运营名统一写 `lulu`；若人工运营名已明确，则使用人工运营名。
- 单关键词广告组且 ABA 排名可确认时，定向维度后用括号写大致排名，例如 `runner rug(4k)`、`area rug(1.8w)`。千用 `k`，万用 `w`。多个词、词根、类目、Auto 或 ASIN 定向不得在广告组名称中写 ABA 排名。
- 广告组标准最低日预算按对应类目 / 型号 / 尺寸的 CPA 正常线上限设置；不同类目根据各自阈值、产品名称、场景、尺寸和运营名切换参考数据。预算低于 CPA 正常线上限时，只能定义为观察预算或拓词预算，不能定义为可判断出单的标准预算。
- 新品 Auto / Broad / Phrase 只有命中当前类目已维护的高流量核心隔离阈值时，才可写 `Negative Exact`。Rug 当前阈值为 `推荐层级=P1/P2`、`ABA排名<=11000`、`合规状态=安全`且与产品属性不冲突；已投放不是精否理由，同一个广告组不得精否自己的主投词或组内投放词。其他类目未维护阈值时不得套用 Rug 阈值。
- 用户问 Rug 类目新品广告需要输入哪些信息时，必须按 Rug 输入模板字段回答，不要把系统侧 ABA 表字段、功能、场景、人群/宠物、是否冷启动等泛化字段列为用户默认必填。
- Rug 新品选词必须先做产品属性硬冲突过滤。输入 `尺寸` 代表本次任务的目标推广尺寸；关键词含明确尺寸时必须与目标尺寸一致，例如目标 `5x7` 不得推荐 `3x5` 或 `5x8`。明确冲突的地毯类型、形状、材质、颜色、风格和图案动物类型同样直接剔除，ABA 排名、历史成交和综合分不得覆盖硬冲突。
- Rug 新品或老品广告分析必须先按 `agents/category data thresholds.md` 的尺寸映射自动识别 `长条 / 门垫 / 区域 / 圆形`，再调用该类型的 CPA / CVR / ACOS 阈值。`2x4`、`3x6`、`3x7`、`4x10`、`4x12` 和所有短边为 `2.5` 的矩形统一归长条；父体多尺寸必须逐尺寸识别。圆形阈值未配置时不得借用其他类型阈值。
- Rug 产品如果有具体动物图案，必须使用 `图案动物类型` 做强匹配；该字段可由用户手动填写，也可由图片识别得到。动物类型不明确时不得推荐具体动物 ABA 关键词。
- 新品推广一般没有稳定 CPA / CVR / ACOS 阈值参考；可以用类目 CPA 正常线上限计算标准最低日预算，但不能用短期 CPA / CVR / ACOS 直接强判暂停、否词或放量。
- 新品阶段不能用短期 CPA / CVR / ACOS 直接强判暂停、否词或放量；如果当前链接已有稳定广告数据，应转入老品推广。
- 对已判定为“多入口、非标或半标、ABA 排名平滑”的品类，新品可采用“阶段主投门槛 + 强匹配低预算隔离测试”架构；必须先由类目流量结构模块确认，并维护该品类自己的阶段区间。不得套用 Rug 的 `60,000`、`20,000-60,000` 或 `P1/P2 + ABA<=11000` 数值。
- 老品推广必须同时考虑：老广告如何优化、新广告是否需要新增/并入/重建。
- 老品出单词达到当前类目优质线且表现稳定时，可以做跨广告产品拓量；必须先保留原 SP，再按素材和资质新增 SPV / SB / SBV 等复制验证。该动作只能来自当前链接真实报表，不能用类目历史出单词直接放量。
