# 新品：Phrase / Broad 匹配方式路由

本文件只保存判断顺序。所有数值只从 [`thresholds/rug/match-type-routing.md`](../../../thresholds/rug/match-type-routing.md) 读取。

## 五层判断顺序

1. **相关性资格门**：按 `ASIN + 完整搜索词` 读取相关性表。只有高度或中度相关可继续；低度相关、不相关或证据冲突不进入新建架构。
2. **词根需求门**：按 `Marketplace + 规范词根 + 完整自然月` 聚合去重搜索词的月搜索量。词根月搜索量只判断是否值得投和投放层级，不单独决定 Phrase / Broad。
3. **语义特异度优先**：完整搜索词命中已确认尺寸、场景、材质、风格、颜色或形状时，优先 Phrase 保留语序。这个例外不能越过相关性和最低需求门。
4. **词根分布决定匹配**：比较词根内 Top 3 完整查询搜索量占比与有效查询数。集中则 Phrase，分散则 Broad，中间区间则 Phrase 承接与 Broad 探索分组。
5. **历史表现后验证**：上线后只能用当前链接的真实 Customer Search Term 点击、花费、订单和销售额判断保留、迁移或关闭。同类历史词不得冒充当前 ASIN 转化证据。

## 双路由分组

同一词根同时获得 Phrase 和 Broad 候选时：

- Phrase 只承接已知语序和高相关查询；
- Broad 只做低预算探索；
- 必须分广告组和流量角色，不共用一个无边界预算；
- 否定词只按实际查询和误杀检查生成，不为了表面“去重”自动互否。

## 数据不足固定处理

以下任一情况固定输出 `MATCH_TYPE_DATA_PENDING`：

- 相关性表未覆盖当前 `ASIN + 搜索词`；
- 搜索量表没有规范词根、数据月或月搜索量；
- 同一搜索词映射到多个规范词根；
- 同一站点、月份和搜索词出现不同搜索量；
- 词根搜索量合计为零。

该状态下可保留 ABA / 产品属性候选，但新广告设置表必须写“不新建 / 待补相关性与搜索量数据”。ABA 搜索量排名不是月搜索量，不允许换算、拟合或代替。
