# 老品：诊断顺序

固定顺序：

```text
数据质量
→ 唯一整体状态
→ Campaign 预算
→ Bid / 策略
→ Placement
→ 广告商品
→ 搜索词 / 词根
→ 趋势
→ 结构
```

数据质量和唯一整体状态优先于全部局部诊断。阈值空档、多重命中、圆形档案缺失或尺寸无法对象化时，相关强动作阻断。

- Campaign、Bid 和 Placement：`budget-bid-placement.md`；
- 广告商品和趋势：`product-and-trend.md`；
- 搜索词和词根：`../search-term/README.md`；
- 新结构与跨广告产品：`growth-and-structure.md`。
