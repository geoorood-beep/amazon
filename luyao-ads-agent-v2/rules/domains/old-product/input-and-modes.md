# 老品：输入和数据模式

## 完整模式

输入报表名称和字段见 `contracts/data-input.md`。先执行数据质量门、对象映射和跨报表对账，再进入诊断。

“当前链接历史搜索词”必须能追溯到同一链接和观察周期。“类目/同类历史效果词”来自其他产品或 `reference/category-history/rug/`，只能做新词候选。两者不得混用。

## 有限模式

仅在用户提供当前链接自己的历史搜索词，且可追溯周期并含点击、花费、广告订单和广告销售额时启用。

允许：

- 搜索词 / 词根保留；
- Phrase / Exact / Broad 复投候选；
- 限流或否词候选；
- 观察建议。

禁止：

- 还原具体 Campaign / Ad Group；
- 编造 Bid、预算、广告位、状态或暂停动作；
- 用类目历史效果库启用有限老品模式。

缺失模块统一写 `【缺失数据】数据不足，无法准确判断`。

| 缺失 | 不得判断 |
|---|---|
| 投放对象/关键词/商品投放报表 | 实际匹配类型、具体 Bid、否词实施和对象迁移 |
| Placement 报表 | TOS / ROS / PP 好坏和溢价 |
| 广告商品报表 | ASIN/SKU/变体的暂停、拆分、合并或防守 |
| Campaign / Ad Group 设置表 | 预算、竞价策略、状态和执行对象 |
| 每日明细 | 近期趋势；累计数据不得伪装成最近表现 |
