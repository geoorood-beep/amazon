# Rug 历史数据：调用边界

## 允许

- 新品选词的同类历史效果证据；
- 新广告的可复用投放词和词根候选；
- 老品新结构的补入口候选，但只能作选词参考。

调用顺序：先匹配 Rug 产品形态，再过当前产品尺寸、颜色、材质、风格、场景和动物图案门，最后与 ABA 阶段和合规证据联合判断。历史成交不得覆盖属性硬冲突。

## 禁止

- 把 ABA 词库当成历史成交词；
- 把 `TARGETING_KEYWORD` 写成真实 Customer Search Term 或实际匹配方式；
- 用类目历史数据启用当前链接有限老品模式；
- 判断当前 Campaign 的预算、Bid、Placement、趋势、暂停、否词或放量；
- 用历史均值生成当前产品的 CPA / CVR / ACOS 阈值；
- 把不同 Rug 形态混成一个无条件复用池。

当前链接自己的报表永远高于类目历史证据。没有当前报表时，结论只能写“基于类目历史的选词参考”。

## 输出说明

必须写明文件、日期范围、证据粒度、数据置信度、缺失字段，并分开标注“历史效果来源”和“ABA 来源”。未找到可用数据时，明确回退到 ABA + 产品属性 + 人工验证，不伪造历史证据。
