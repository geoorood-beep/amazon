# Rug 类目流量结构规则

本模块只判断类目入口数量、头部集中度、流量梯度和打法方向；不替代新品选词、老品动作或历史词复用。

## 读取顺序

1. [任务边界、数据源和输入](scope-and-input.md)；
2. [标准化程度、入口相关性和竞对分层](relevance-and-segmentation.md)；
3. [结构组合和打法](structure-and-playbook.md)；
4. [必备输出与置信度](output-and-confidence.md)；
5. [N、G 和结构分档数值](../../../thresholds/rug/traffic-and-scoring.md)。
