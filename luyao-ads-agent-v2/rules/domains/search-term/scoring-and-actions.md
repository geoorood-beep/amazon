# 搜索词：评分与动作

## 评分路由

- 常规选词和流量机会：使用 `thresholds/rug/traffic-and-scoring.md` 的常规机会综合分。
- 仅当前链接历史搜索词的有限老品模式：使用历史词根优化分。
- 数据不满足评分资格时写 `待评分`，不能用零分代替。

## 动作

候选动作从历史出单搜索词和词根表现出发，ABA 用于容量、稳定流量和长期排名机会。

- Phrase：稳定短语和连续语序；
- Broad：语义相关拓词，低预算验证；
- Exact：完整搜索词自身经过验证后才列候选；
- 限流 / 否词：继续通过样本、归因、停止线和唯一 Target 映射；
- 放大：继续通过当前链接趋势和预筛门；
- 跨广告产品：只走老品增长规则。

Phrase 和 Broad 同时具备证据时分组记录，不抢同一预算。Exact 只能由完整搜索词自身证据获得，不得因词根高分就把其下全部词建 Exact。

有限老品模式中，所有动作必须写“待投放对象映射”。高分不得还原出不存在于源表的 Campaign、Ad Group、Bid 或实际匹配类型。

## 否词边界

单个点击无单经验信号没有独立否词权限。可执行 Negative Exact 必须通过完整数据模式、低样本门、归因成熟、停止线、唯一 Target 映射、数据质量和 Validator。任一项缺失时只列候选及缺失原因。

默认不做 Negative Phrase。只有整个词根经 Rug 产品意图和属性复核后明确不相关、当前组可触达且不误杀主投词时，才可列高影响人工审批候选。

## 花费占比

出单花费占比和未出单花费占比的分母都是所属词根总广告花费。明细行不能用自身花费除以自身花费。

## 去重

多词根归属只增加证据，不生成重复后台动作。去重键必须包含 ASIN、Search Term、Ad Product、Match Type 和 Traffic Role；完整执行时再由不可变 Campaign / Ad Group / Target ID 定位。

同一对象的复投、否词、Bid、预算或暂停候选最终必须进入统一动作仲裁。相反动作不能同时输出。
