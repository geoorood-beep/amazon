# 外部服务器接入位（预留）

当前状态：`PLACEHOLDER_NOT_ACTIVE`。

本目录用于不能归入 MCP 或标准 HTTP API 的只读数据连接，例如经批准的 SFTP、对象存储或专用报表服务器。不得用本目录绕过 MCP/API 的身份认证和数据合同。

未来连接器必须固定：

- 服务身份、协议、Endpoint 和账户范围；
- 只读目录或资源白名单；
- 文件类型、最大大小、周期和时区；
- 下载完成标记、断点续传和重复文件判定；
- 来源对象 ID、ETag/版本、SHA-256 和接收时间；
- 到 `ExternalDataEnvelope` 的转换结果。

未知协议、未知来源或无法确认 Rug 范围的数据必须进入隔离区，不得进入分析。
