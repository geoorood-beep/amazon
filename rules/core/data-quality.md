# 核心规则：数据质量与对象映射

## 唯一数据质量状态

| 状态 | 权限 |
|---|---|
| `DQ_PASS` | 可以继续生成候选动作 |
| `DQ_WARNING` | 只能观察或生成 `APPROVAL_REQUIRED` 候选 |
| `DQ_BLOCKED` | 整体状态固定为 `DATA_BLOCKED`，不得生成执行动作 |

## 判定顺序

1. 报表类型和关键字段完整；
2. 日期、站点、时区、币种和归因口径一致；
3. Campaign、Ad Group、Target、搜索词和产品对象可唯一定位；
4. 跨报表金额和样本对账通过；
5. 阈值单位、适用范围和命中结果唯一；
6. 数据快照、上下文和规则版本冻结。

完整模式不得只校验“文件存在”。必需报表必须有非零行数，解析后的 Campaign、Ad Group、Target、搜索词和指标也必须非空。报表周期必须与快照周期一致；搜索词到 Target 的父级链、命名指标窗口长度和曝光→点击→订单漏斗均需确定性校验。

当前完整 SP 模式要求 Campaign 与 Ad Group 一对一，并同时保存不可变 ID。只有名称、名称重复或无法映射到 ASIN / SKU 时，不得输出后台执行动作。

## 有限数据模式

只有当前链接自己的历史搜索词报表满足最低字段时，才允许输出搜索词/词根层有限方案。允许保留、复投、限流或否词候选；不得编造 Campaign、Ad Group、Bid、广告位、预算、暂停或执行状态。

Rug 类目历史 `TARGETING_KEYWORD` 效果库不是当前链接报表，不能启用有限 SP广告优化模式。
