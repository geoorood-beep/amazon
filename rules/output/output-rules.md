# 输出规则正文

## 新品

固定两张表：

1. `ABA选词表`；
2. `新广告设置表`。

第一张表下方必须追加自然段 `判断依据与设计逻辑`，不另建策略摘要 sheet。字段见[广告架构设计输出合同](../../contracts/new-product-output.md)。

网页只预览用户要执行或确认的广告设置字段；完整选词证据和判断依据只进入下载工作簿，不在默认页面展开。

## 老品

根据数据模式输出产品策略、当前 SP 广告优化、新广告设置和 Validator 结果。完整模式的执行字段不得因减少表格数量而隐藏；有限模式只能输出词根候选和缺失数据影响。字段见[SP广告优化输出合同](../../contracts/old-product-output.md)。

## 判断依据标签

使用：

- `【流量结构打法】`；
- `【历史数据】`；
- `【当前历史搜索词】`；
- `【用户固定规则】`；
- `【ABA/产品属性】`；
- `【当前报表】`；
- `【人工输入/预算目标】`；
- `【缺失数据】`。

## 广告组命名

```text
SPU-广告产品-定向维度-匹配方式-场景分类-尺寸-运营名
```

规则见[新品广告架构](../domains/new-product/architecture.md)。

## 执行字段

完整动作严格使用[动作与方案合同](../../contracts/action-and-plan.md)。只有方向或百分比、没有不可变 ID、当前值、目标值、回滚、快照、Rule ID、Threshold ID 和有效期时，必须降级为建议。

## 可读性

- 核心表优先；
- 阻断原因直接写在人可见的位置；
- 词根、完整搜索词和 ABA 排名保持可追溯；
- 不用备注区覆盖核心字段；
- 为什么没有选择其他架构或动作必须写清楚。
