# 新品：范围、输入和数据源

## 适用

- Rug 新品选词；
- 新品 SP 人工架构；
- 老品需要新建广告时的新品式选词子流程。

已有稳定当前链接广告表现时转入老品模块。

## 用户输入

Rug 默认输入必须与 `新品基础信息输入模版_Rug类目` 的 `产品信息表` 一致，不把 ABA 系统字段当成用户必填。

| 字段 | 要求 | 用途 |
|---|---|---|
| `ASIN/SKU` | 必填 | 确认推广对象；可识别的款号可作为 SPU |
| `运营` | 建议填 | 广告组命名；智能体默认 `lulu` |
| `地毯区域` | 可选复核 | 系统仍必须先按尺寸自动识别，人工值不得跳过尺寸路由 |
| `尺寸` | 必填 | 本次任务的目标推广尺寸；用于类型路由和硬冲突 |
| `材质` | 有特殊材质才填 | 材质词匹配；常规仿羊绒不强制 |
| `颜色` | 有明确颜色才填 | 颜色词匹配 |
| `风格` | 有明确风格才填 | 风格或图案词匹配 |
| `预算（USD/日）` | 建议填 | 与标准最低日预算比较 |
| `目标订单阶段` | 必填 | 选择 ABA 阶段区间 |
| `图案动物类型` | 条件必填 | 有具体动物图案时强匹配 |

SPU 无法从 `ASIN/SKU` 识别时，命名中写 `SPU待补`；不把 SPU 另列为默认必填字段。

缺失属性不得补造；必须说明影响。
