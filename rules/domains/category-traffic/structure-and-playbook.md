# 类目流量：结构和打法

入口数量和梯度公式只读 `thresholds/rug/traffic-and-scoring.md`。数据未达可计算条件时写样本不足，不按经验选一个结构。

| 结构 | 打法方向 |
|---|---|
| 多入口 + 头部集中 | 头部词单独控制；中尾词和类目入口分散验证；防止头部词吃完预算 |
| 多入口 + 排名平滑 | 大词、中词、长尾和属性词分层；Phrase 与 Broad 分组拓入口 |
| 中入口 + 头部集中 | 核心词单独控预算；属性词做隔离验证 |
| 中入口 + 排名平滑 | 尺寸、场景、属性和中尾入口分组 |
| 少入口 + 头部集中 | 覆盖核心词和头部竞对，小词只补充，不做大面积拓词 |
| 少入口 + 排名平滑 | 覆盖全部有效层级，以小预算查漏补缺 |

Top ASIN/品牌垄断度只修正打法，不改写 `N_core` 或 G。类目结构也不能覆盖产品属性、当前阶段和历史转化证据。
