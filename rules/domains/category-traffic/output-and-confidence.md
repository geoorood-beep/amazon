# 类目流量：输出与置信度

## 必备输出

- 类目核心词和 ABA 去重词数；
- `N_core / N_accessory / N_competitor / N_adjacent / N_uncertain`；
- 本体词 Top 排名、G 和是否可计算；
- 入口数量、流量集中度和结构类型；
- 推荐打法与不建议打法；
- 竞对词表是否使用、是否修正 ABA 判断；
- 数据置信度和不可判断项。

## 置信度

| 级别 | 条件 |
|---|---|
| 高 | `DQ_PASS`；核心词明确；ABA 排名、Top ASIN/品类、份额证据齐全；对象映射和来源哈希通过；观察期与样本满足本次结论 |
| 中 | `DQ_WARNING` 且没有阻断项；有搜索词和 ABA 排名，但缺 Top ASIN/份额、部分映射或样本只够候选判断 |
| 低 | `DQ_BLOCKED`，或核心词不明、数据混杂多类目、来源过期、关键映射缺失、大量词需人工确认 |

不得把“出现在 ABA”当作相关证据，也不得只因头部词流量大就直接推荐高预算主投。

置信度不是装饰字段：

- 高：仍需通过规则、阈值和 Validator；不自动获得执行权限。
- 中：只允许输出 `CANDIDATE / APPROVAL_REQUIRED`，不得 `AUTO_PASS` 高影响动作。
- 低：不得输出预算、Bid、Placement、暂停、否词或建组执行动作；只能列缺失数据和补数方案。
