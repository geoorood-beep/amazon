# 老品：预算、Bid 与 Placement

## Campaign 和小时节奏

小时节奏数值只读 `thresholds/rug/governance.md`。预算提前耗尽是独立 `READ_ONLY` 压力标志，不得单独生成加/降预算、Bid 或 Placement 动作。

| 节奏 | 订单/效率 | 处理 |
|---|---|---|
| 过快 | 达标 | 只在整体状态允许扩量、趋势同向、预算上限允许时列加预算候选 |
| 过快 | 不达标 | 不加预算；先查搜索词、Bid 和低效位置 |
| 正常 | 达标 | 保持 |
| 正常 | 不达标 | 节奏不是主因；查转化、流量质量和商品承接 |
| 过慢 | 达标 | 只在状态、趋势和映射全部通过时列获取流量候选 |
| 过慢 | 不达标 | 查曝光、点击率、入口规模和相关性 |

## Bid

| 数据表现 | 处理 |
|---|---|
| 曝光不足且历史转化可靠 | 可列提 Bid 候选，仍受参数上限和 Validator 约束 |
| 曝光多而点击少 | 先查相关性和 Listing，不盲目提 Bid |
| 点击无单 | 仅作风险信号，继续通过低样本、归因、停止线和映射门 |
| 订单稳定且成本达标 | 保持；是否扩量另走增长门 |
| 订单稳定但成本超目标 | 可列降 Bid 候选 |

调整幅度未在 `thresholds/rug/pending.md` 中完成确认前，不得写生产执行值。

## Placement 入口

只有 `rules/core/trend-placement-budget.md` 允许的唯一整体状态才进入广告位优劣诊断。Placement 报表必须与 Campaign 整体报表在日期、币种、归因口径和金额上对账。

| 广告位状态 | 处理 |
|---|---|
| 表现好但花费占比低 | 可列该位置溢价或基础 Bid 候选 |
| 表现好且占比正常 | 保持 |
| 表现差且占比高 | 可列降低该位置溢价候选 |
| 样本不足或未进入诊断 | 保持观察 |

基础 Bid 会同时影响多个位置，不是单一 Placement 的精准控制器。只有位置溢价能更直接控制 TOS / ROS；PP 的获取还会受基础 Bid 和其他溢价结构影响。
