## 安全结论

外部输入未来必须先进入 `ExternalDataEnvelope`，保存来源与 SHA-256，再转换为 `AdDecisionPacket / AdContext` 并经过 Data Quality。外部系统不能直接写入 `DQ_PASS`、`AUTO_PASS`、`ACTIVE` 或广告动作。

占位结构加入 V2.0 只表示后续有明确落盘位置，不表示任何连接器已经具备运行能力。
