## 已完成修复

1. 项目边界
   - `config/project_scope.json` 登记八层架构、当前规则、阈值、合同、知识、历史、兼容路径、核心运行文件、固定 Rug 数据和 V2 来源校验值。
   - `scripts/validate_project_scope.py` 检查六类真源、兼容映射、派生 TEST_ONLY 配置、固定数据、禁止路径、V2 来源 SHA-256、周报输出边界和项目外符号链接。
   - 已清除子 AGENT 和测试页中可操作的办公椅、喂水器默认数据入口；非 Rug 只保留阻断说明。

2. 固定数据适配
   - 新增 `new_product_module/src/reference_adapter.py`，Rug ABA 只读 `广告词库` sheet。
   - 跨 ABA 文件同词采用保守冲突策略：合规、广告状态、类型、层级或相关度不一致时进入隔离复核。
   - 固定历史文件来自关键词分析汇总，legacy `search_term` 明确按 `TARGETING_KEYWORD` 读取，不再冒充 Customer Search Term、实际匹配方式或独立成交日期。
   - 修复未来入库脚本：新生成文件使用 `historical_performance_keyword`、`evidence_grain=TARGETING_KEYWORD` 和 `keyword_summary`。

3. 新品模块
   - 阶段未命中时直接阻断，不再回退到第一阶段。
   - 广告组采用 `SPU-广告产品-定向维度-匹配方式-场景分类-尺寸-运营名` 七段命名；单关键词保留 ABA 大致排名。
   - `ABA<=30,000` 单词单组；`30,000<ABA<=100,000` 与更长尾词分层分组，不跨流量层混组。
   - 标准最低日预算改为对应 Rug 阈值档案的 CPA 正常线上限；只有显式提供单广告组目标订单数时才乘以该目标。
   - Excel 输出固定为 `ABA选词表`、`新广告设置表` 两张 sheet；第一张表下方保留自然段 `判断依据与设计逻辑` 和缺失数据原因。

4. V2 安全合同
   - `BusinessMode` 对齐为 `NORMAL / EVENT / ANOMALY`。
   - `RulePackageReference` 分别保存规则文件 SHA-256、阈值文件 SHA-256 和组合校验值；缺任一文件校验值时 Validator 阻断。
   - Validator 新增 Rug-only 类目门；非 Rug、SP 冷启动、SB/SD 和未激活规则源继续阻断。
   - `AUTO_PASS` 仍只表示结构校验通过，不代表允许调用 Amazon API。

5. 规则与文档同步
   - `category_rules.example.yaml` 同步 2026-07-31 已确认的 Rug CVR/ACOS/CPA 连续区间摘要及阈值原件 SHA-256。
   - 圆形阈值保持 `null`。
   - Rug O<2 点击/花费锚点因为缺少可执行 Threshold ID，固定为 `BLOCKED_PENDING_THRESHOLD_ID`。
   - 已同步更新 AGENTS 目录、Rug 固定数据 metadata、模块 README、版本说明和 V2 说明。

6. 压力测试缺陷修复
   - 生产模式增加不可由调用输入覆盖的总保险；空报表壳、父级链错配、报表周期冲突、异常指标漏斗和错误窗口统一阻断。
   - 预算/Bid 数值类型、方向、对象、动作ID、辅助相反动作和时区均增加独立校验。
   - 新品管线在尺寸识别前执行 Rug-only 边界；非正单广告组目标直接拒绝。
   - 运行时尺寸、ABA分组和Phrase/Broad门槛全部改为读取派生配置，不再保留代码阈值回退。
   - 重复历史词按点击和订单聚合并记录问题，不再末行覆盖；整数指标有小数时直接拒绝，不再截断。
   - 动作去重改为哈希索引；50,000条唯一动作压力测试通过。
